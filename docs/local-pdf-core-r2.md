## 来源与兼容

`src/sources/pdf-snapshot.ts` 定义独立的 `LocalPdfSnapshot`，与原有下载快照组成共用 PDF 来源类型。本地凭据包含原文件名、选择时间、内容大小、SHA-256、已查询的书目身份及 PDF 校验结果；不包含下载任务、PMC／Unpaywall 候选、下载地址或推断的许可证。完整本地路径不写入可迁移的原文包。

本地版本默认 `unknown`，展示为“版本未核验”。如果调用方明确选择出版版本或作者接受稿，标明依据为用户声明；标题页身份确认本身不能证明稿件版本或使用许可。后续 UI 应保持这个区别，不能默认选中出版版本。

`prepareLocalPdf` 接受明确选择的绝对路径和已核对的书目身份，通过固定文件句柄分块读取，限制 64 MiB，检查 PDF 文件头尾、读取前后大小和时间，以及 PDF.js 解析与首页身份线索。准备过程不复制、不上传、不创建持久记录。`rereadLocalPdf` 必须使用原快照和匹配的完整文件哈希，不允许用变化后的文件替换已确认快照。

原文包仍使用 `packageKind: pdf-source`。新增本地清单版本 `2`，来源凭据单独保存在 `_source/local.json`；版本 `1` 下载包保留 `_source/acquisition.json`，既有摘要、目录键和确认回执不改写。清单版本、文件清单、来源快照和内容摘要必须一致，未知来源字段及伪装成下载记录的本地凭据被拒绝。旧读取器遇到新版本应拒绝，而不是当作旧格式解释。

两个来源类型共用 `SourceIntakeService` 的标题页确认、分层查重、只增写入、最后提交清单、完整核验和索引补登记。标题页图片与身份摘要绑定，确认前不发布。恢复只补齐本事务缺失的文件，遇到修改过的文件停止并保留。索引失败时原文包已经保存，后续可以单独补登记。

相同本地内容和稿件类型再次选择会复用已保存包；同一论文的不同内容／稿件声明保留独立包。在线包和本地包保留各自来源，不用相同 PDF 字节抹掉下载来源和本地选择之间的区别。本地的 `local-sha256:` 版本标识只表示内容身份，不是出版者版本号。

同时修正共享保存器的一个关联缺口：预览后若仅元数据记录先占用该论文身份，也必须阻止旧计划继续创建另一个 paperId。原先仅检查已有原文包的情况不足以覆盖 R2 新增的书目入口。
