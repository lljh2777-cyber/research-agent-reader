# R3.8：学习摘录补充到已有笔记

更新日期：2026-09-12。开发版本：`0.76.0`。

## 使用流程

从“学习回答摘录”选择记录，点击“补充学习内容到已有笔记”。若修订稿或备注还有未保存草稿，先保存或放弃。分别勾选原始 AI 回答片段、已保存人工修订稿和个人备注；内容为空的角色不显示，所有角色默认不选。

选择已有概念、方法或综合笔记及正文插入位置，点击“预览所选学习内容”。预览展示目标、索引与日志的变化及完整前后文件。改变所选内容或位置使旧预览失效；点击“确认补充学习内容”才写入笔记。原始学习摘录、人工修订和手动整理状态保持不变，不自动标记完成。

预览阶段保存整理批次。关闭或重载插件后，可从“知识整理 → 整理批次 → 审阅建议”返回，重新预览后确认。已有修订的批次进入修订历史；写入中断可“预览并恢复”，已完成修订可“预览撤销”。目标已有后续人工编辑时，恢复和撤销不覆盖它。

## 内容与来源边界

三种内容均以“学习背景与个人理解”保存，不宣称经过原文、科学或教学核验。本入口核对已保存回答、选区和整份学习摘录版本，**不把回答版本一致当作 PDF、代码或论文主张的验证**。资料、代码和主题回答共享此规则；不运行代码，不调用回答模型、嵌入模型或外部服务。

目标限定已有 `wiki/concepts/`、`wiki/methods/`、`wiki/synthesis/` 笔记，保留其属性、标题和原有正文。不能据此补写 `wiki/sources/`，不能新建正式知识页。所选内容按固定顺序保存，并保留摘录路径、摘录摘要、回答摘要、选区、模型和会话／路线标识。一次补充后的文本块最多 40,000 字符；超过上限应缩小选择。

学习内容放在专用 `rar-learning-note` 纯文本围栏内，内部 Markdown、脚本、HTML 和链接作为文字保留。围栏长度避开原始文本里的反引号，防止内容提前结束围栏。后续如需改变所选人工文字，应先修改学习摘录并重新准备；整理面板不另行改写候选内容。同一目标已有此摘录的路径记录时，阻止重复补充，先查看已有内容或修订历史。

本插件的正式知识分块跳过这些学习文本块，原有证据仍使用原文件的字符位置和全文摘要。内置词法检索跳过块内文字；Direct API 的整页回退将其遮蔽，片段读取拒绝与其重叠的范围。助手的知识证据读取、后续模型整理证据和目标选段也排除这些块。未闭合的专用围栏从起点一直排除到文件末尾，避免损坏格式导致内容误入证据。

以上是本插件的读取约定，不控制其他插件、外部 Agent 或用户直接打开整份 Markdown 的行为。手工删除专用围栏后，其内容不再带有本入口的隔离标记；不要以此操作代替原文核验。

## 保存与恢复

新增独立 `answerExcerpt` 整理上下文，记录固定摘录、角色和插入位置，不伪造阅读会话或原文引用。使用现有 `CurationService`、`CurationWriter` 和修订存储，不另建写入事务。既有原文摘录和模型证据整理保持各自校验。

准备、保存批次、预览、应用和中断恢复均核对整份摘录及已保存回答；写入过程中逐个文件再次核对。回答、修订稿、备注、完成状态、目标、索引或日志变化时，旧操作不能覆盖最新内容。文件替换、取消和响应丢失继续使用现有全文比较与恢复记录。修改前后快照保留，可重新加载恢复；撤销保留修订历史与已有索引入口。

新批次需要 `0.76.0` 或支持该上下文的后续插件处理；旧学习摘录没有格式升级或批量迁移。预览可恢复的是已保存批次，不包括尚未预览的目标／角色选择。
