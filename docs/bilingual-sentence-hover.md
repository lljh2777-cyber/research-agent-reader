# 双语阅读：悬停句对照

在双语阅读顶部打开「悬停句对照」。默认关闭，标签恢复时记住开关；更换文件会重新判断。开启后顶部显示可对照的句对数。鼠标停在任一栏可对应的正文句上，两栏用淡琥珀色高亮整句。另一句不在视口时不改变滚动位置。移出正文、开始划选、有实际选区、滚动或关闭开关时清除；复制、批注和链接仍使用原有操作。此开关独立于「双栏联动」。

## 匹配规则

需要有有效来源版本和结构的段落配对，复用「双栏联动」已有的对应段落。两边各一句的配对正文段和明确句对记录保持支持。自 `0.90.1` 起，没有明确记录的多句段落可用段内唯一的引用号、图表链接及编号、术语和数值组合找出一对一的句对。双方有数量或引用冲突、线索指向多个候选、句子次序交叉或断句存疑时跳过；句数不同的段落要求相邻的可靠对应。两对可靠句子之间仅各剩一句、且没有矛盾或竞争候选时，可以补这一对。句数相同或滚动进度相近都不能单独用于配对。

图注及其续段、扩展图表区、表格、独立公式、列表、引用块及脚注正文不纳入。纯进度联动的手动配对和不支持文字范围高亮的桌面环境中，开关不可用。

开启功能时在本机建立索引，悬停只查内存。不写原文、配对记录或批注，不调用模型。规则提供阅读定位，不构成译文质量判定。

## 可选的明确句对记录

已有、经过核对的逐句对应可放在配对文件 `translation.json` 的可选 `sentenceAlignment` 字段。该字段不改变原有配对格式。它包含 `schemaVersion: 1`、`digests`（`en`、`zh-CN` 两份 Markdown 原始字节的 SHA-256）和 `pairs`（最多 2,000 项）。

每项包含 `blockId`（对应段落对的内部 ID，如 `p-4`）、`en` 和 `zh-CN` 两句实际显示的完整文字。ID 按已有结构配对生成，包含标题等结构块，不能用可见段落序号替代。插件核对两份文件的摘要和句子在各自段落中的唯一位置；同一句的多重对应不使用。句子文本比较时折叠空白。该字段由有明确逐句记录的资料提供，本版不新增生成器或编辑器。

## `0.90.1` 测试库验收

在 Windows / Obsidian 1.14.4 使用原有 DeepMet 全文和 Novae 摘段。首轮规则命中 179 对 DeepMet 和 2 对 Novae；逐对核对发现图注续段、缩写误断的片段和一条许可说明拆句。收紧图注、断句、句长及不等句数段落的规则后，已知误亮全部排除，最终结果是首轮已核对结果的子集。

| 原有样本 | `0.90.0` 可亮句对 | `0.90.1` 英文／中文完整句 | `0.90.1` 可亮句对 |
| --- | ---: | ---: | ---: |
| DeepMet 全文 | 8 | 576／584 | 159（约 28%／27%） |
| Novae 摘段 | 0 | 8／7 | 2（25%／约 29%） |

完整句分母按本版正文纳入和断句规则统计；DeepMet 的分母因排除图注续段、扩展图表区及不完整片段而变化。最终保留的匹配在这两份样本中未发现错配；这不等于所有论文适用，也不代表全部译句或图像通过审阅。Novae 明确记录的测试副本保留 2 对原记录，另外一个段落的本地规则命中 1 对。

两份原有样本均用实际渲染的文字范围复验双向悬停、30 px 换行、换栏、划选捕获、恢复开关和对侧不滚动。未匹配段落不亮，来源变更事件使旧索引失效，纯进度联动不启用。结束后恢复测试库原字号和布局；两篇原有样本的 Markdown 与配对文件校验值一致。未调用模型。

## `0.90.0` 历史验收

Windows / Obsidian 1.14.4，统计纳入首版范围且能断出完整句子的正文；不包含未纳入的内容。下表为这两份既有样本及其中一份的测试副本，不代表所有论文。

| 样本 | 英文完整句 | 中文完整句 | 可高亮句对 |
| --- | ---: | ---: | ---: |
| DeepMet 已有全文 | 766 | 767 | 8（约 1%） |
| Novae 已有摘段 | 8 | 7 | 0 |
| Novae 摘段测试副本，加入两条人工核对记录 | 8 | 7 | 2 |

逐对核对 DeepMet 自动命中的 8 对及 Novae 副本明确记录的 2 对，未发现错配。Novae 原样本的多句和合句段落未强行对应。首版在没有明确记录的多句正文中覆盖很低。

在实际阅读 DOM 中验证两侧鼠标坐标命中、30 px 换行、对侧不在视口时的滚动位置、真实划选和批注来源捕获、换栏、标签状态恢复、关闭清除、未配对不亮及来源变更事件失效。首次换栏发现浏览器移动节点会使已缓存的活动文字范围失效；改存文字节点和偏移并在悬停时建立范围后复验通过。恢复了测试库原字号和布局，原有样本的源文件与配对记录校验值一致。测试副本保留在独立测试库。未调用模型、未修改原始论文、未进行整篇翻译或专家审阅。
