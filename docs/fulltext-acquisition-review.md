# 全文入库与 JATS 功能检查、优化记录

检查日期：2026-09-10。基线 `0.51.0`（`9cea4a9`），修复版本 `0.51.1`。范围覆盖 M1–M6 的标识解析、来源发现、获取快照、原文保存、JATS 转换与阅读、初始 Wiki、阅读助手及既有笔记修订。

## 已复现并修复的问题

| 问题 | 原有影响 | 修复与回归依据 |
|---|---|---|
| 根级 `floats-group` 未纳入转换和媒体发现 | 部分文章的主图、图注及正文跳转目标缺失 | 新转换器读取主文章浮动图表；模拟来源从发现、获取、发布到交互阅读完整验证 |
| 段内 `disp-formula` 重复输出 | 同一公式同时出现在段落与独立公式块 | 新转换器只生成一次独立公式块，保留原 XML 位置 |
| Wiki 检查可被原有身份摘要抵消冲突标识 | 标题与来源凭据未变时，错误 DOI / PMID 仍可通过既有 Wiki 检查；独立登记入口同样存在遗漏 | Wiki 检查、独立登记和修订共用标识规范化与冲突拒绝规则；精确 PMID / PMCID 可支持没有 DOI 的旧笔记 |
| 长摘要未按 JSON 转义后的大小预算 | 概览工具超限后，模型无法通过调整参数完成必需的首次概览 | 在返回前减少片段数量；明确覆盖边界，未返回段落仍可通过目录和块工具补读 |
| 保存完成后接受框可重新启用按钮 | 已完成操作再次出现可点击状态，并重复添加打开入口 | 完成状态锁定按钮和接受框，原生测试检查结果入口只出现一次 |
| JATS 候选提示套用 PDF 回退文案 | 界面暗示会自动尝试其他 JATS 版本，且未明确区分出版版本与接受稿 | 明确只获取所选 JATS 版本，显示稿件类型和失败后的可用操作 |

前四类使用新增用例在修改前复现失败，再验证修复；身份问题另沿独立登记入口复现和修复。UI 状态与现有流程通过 Obsidian 原生测试验证。

`floats-group` 属于 JATS 主文章结构，图表可以集中放置于正文以外。转换范围依据 [NLM JATS 1.4 元素说明](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/floats-group.html)核对；这项文档核查不等于对所有出版社 XML 的兼容认证。

## 性能与历史兼容

- 新获取快照显式保存 `rar-jats-2`。旧快照缺少转换器字段时仍按 `rar-jats-1` 读取；正式包的转换器必须与其获取快照一致，未知版本拒绝加载。
- 旧转换逻辑保留。以 `0.51.0` 产出的固定投影摘要做回归，并实际验证旧快照发布、包加载及交互阅读。没有迁移或重写旧包、旧会话与历史引用。
- 已完整加载的 JATS 包再次核验时，仍逐文件检查长度、SHA-256、清单摘要和额外资源；相同字节不再重复解析 XML 和重新生成投影。首次加载仍执行全部结构、身份、确认回执和确定性投影检查。
- 图文关系按正文块建立索引，避免为每条证据扫描全部证据。未声称实测端到端延迟或模型耗时提升比例。

旧包需要利用新转换行为时，通过「重新查询 JATS 与图片」取得新快照，再核对保存；不会把旧会话悄悄绑定到新投影。
