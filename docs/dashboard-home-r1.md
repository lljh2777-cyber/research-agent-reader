# R1：首页主次入口整理

交付日期：2026-09-11，开发版本 `0.59.0`。本批整理工作台入口与当前流程文案，保留旧 action ID、命令、执行分支和历史数据。

## 已交付

首页三个主入口为 **文献库、阅读空间、知识整理**。文献库查看来源、会话和人工记录；阅读空间沿用资料阅读；知识整理打开既有的待审阅、需复查、修订记录和索引界面，不在点击入口时生成内容。

主题路线保留“预览”标记。文献入库、文献深读、知识库检索、获取全文及综合分析仍为常用操作。代码分析、代码练习、知识库体检和 OKF 导出进入可展开的 **扩展工具**；当前视图内保留展开状态，工具有任务运行时自动展开并显示提示，停止按钮仍按原任务 ID 派发。

`pdf-xray` 的显示标签改为“文献深读”；入库选项、续办提示、JATS 阅读器及交互阅读中的“文章 Wiki”入口改为“论文笔记”。知识整理弹窗使用同一名称。没有修改旧命令 ID、请求字段、技能名称、历史原文或来源校验规则。
