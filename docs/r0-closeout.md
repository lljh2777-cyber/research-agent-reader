## 本轮实际复验

```powershell
pnpm test:r0
pnpm typecheck
pnpm build
pnpm release:check
```

## R1 的开发边界

R1 首批可以开始“文献列表 → 文献详情 → 打开指定原文／继续对应会话”的只读流程。消费现有聚合接口，根据来源版本和实际能力显示动作；没有可靠身份或来源时保留独立历史入口和原因。打开、刷新和切换页面不调用模型，取消或旧查询结果不能覆盖新页面。

先验收空库、旧库、混合来源、窄窗口、缺失原文和测试会话排除；随后再接人工阅读状态与主要笔记编辑。R1 不新增科学裁决、自动选证、讲解规则或“科学已验证”状态，不把 `complete`、`answered`、讲解完成或选择主要笔记当成审阅通过。科学规则修复、翻译与跨论文综合仍需通过各自的证据与质量检查。

R0 的工程功能范围在此冻结，未关闭事项按上表继续跟踪。科学审阅要求保持有效；后续存储迁移、身份编辑和模型规则实验按各阶段的具体任务实施。
