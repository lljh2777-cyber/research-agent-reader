# R2 第七批：未核验人工条目

2026-09-12，开发版 `0.67.0`，已部署测试库 `E:\paper-test`。公开 beta 保持 `0.31.0`，R2 尚未收尾。

## 使用流程

文献库 → 添加文献 → 手工登记（未核验）→ 填写 → 预览 → 保存。原“添加文献信息”命令也保留此入口。查询无结果、暂时无法查询或尚无有效标识时，都可以由用户明确选择手工登记；网络错误不会被改写为“论文不存在”。

标题必填。作者每行一位，年份为四位数字；其余待核对标识／线索、个人备注均可留空。只保存用户填写内容，不补造作者、年份、DOI、中文译名或外部来源依据。预览单独展示待保存内容，返回修改后重新预览；保存中禁用修改和重复提交，失败保留输入供重试。

列表与详情显示“人工条目 · 未核验”，可按标题、作者、年份或线索搜索，并出现在“待关联或有缺口”筛选中。该状态不允许直接绑定原文、设置主要论文笔记或冒充已核验书目。

“重新查询书目信息”读取持久人工记录后预填线索，打开时不发送查询。用户明确查询后才使用已有解析器；结果仍需单独核对保存，原人工条目保留。当前不提供保存后修改手工书目、身份升级或人工／已核验记录合并，不把重新查询当作升级操作。

## 数据与失败边界

新增可选 `manualBibliography`，保存固定的 `unverified` 状态、作者、年份、原样线索与备注；标题仍在记录的 `title` 中。它与 `bibliography`、标准化标识、citekey 和主要笔记互斥。手填 DOI 只是文本线索，不参与来源目录的精确标识关联。

人工条目仍使用现有追加式文献记录和提交标记。新字段纳入冻结身份摘要，旧修订不改写、无需迁移；新条目需由支持此字段的版本读取。存储和投影均检查人工内容不能携带已确认身份，未核验条目即使拥有内部 paperId，也不显示为“已有标识”。

同一次预览绑定私有保存命令，重复点击、失败重试和已提交但未收到成功回执的重试复用该命令。另一次独立手工登记得到独立记录；同标题或同线索不会自动合并。跨窗口或跨设备的独立人工登记也不推断为同一论文。

关闭窗口或取消在提交前生效；已开始的追加提交不撤回。未提交文件保留并明确报告，重试不清理旧文件。重新查询前核对持久记录，记录变化或取消使迟到窗口失效。
