## 八题逐项观察

下表是开发者事实与教学复核，不是模型自评、盲评或独立审阅。所有旧答、参考要点和失败反例保持冻结；新增观察不用于事后调整通过率。qwen 的原观察见 [T1.3D](topic-quality-t13d.md)。

| 题目 | 本次表现及与 qwen 的差异 | 仍需改进 |
|---|---|---|
| S01 相关与因果 | 直接否定仅凭一起增长即可判因果，列出反向因果、共同原因与巧合；没有把同步变化当作所有因果关系的必要前提 | 冰淇淋与溺水的常见例子没有明确标为假设或示意，也未提供本次核验数据 |
| S02 Pearson 为零 | 区分样本与总体，知道零相关不等于独立；没有重现 qwen 的常量输入系数错误 | U 形用电例子只说可能接近零，没有交代使这一结果成立的对称或分布条件；“不衡量曲线”等措辞仍应更精确 |
| S03 标题与论文定位 | 承认未接入资料，说明仅给标题不能保证定位，还需版本与可读全文；没有编造引文或页码 | 末尾“配置好知识库或允许检索……才能尝试核对”仍容易暗示仅有授权即可获得读取能力，需与实际产品入口和能力对齐 |
| S04 随机分组 | 明确期望上的平衡、偶然差异、不依从与失访；区分随机分组与随机抽样，也承认有条件的观察性因果论证 | 将偶然不平衡主要归于小样本，仍应说明任何有限样本都不保证完全均衡；运动、冰淇淋、学生跑步多个例子增加了零基础阅读负担 |
| P01 三种职责 | 用 iter 和 next 定义职责，明确第四次 next 会耗尽，解释 for 如何结束；比 qwen 把所有可迭代对象说成静态仓库更准确 | 未明确强调迭代器本身也可迭代；列举取值时没有明确标为未执行推演，但也未声称已经执行 |
| P02 耗尽与清空 | 明确 iter(it) 返回自身且不复位，for 正常处理耗尽；说明原列表没有因遍历而删除，并考虑循环体清空或变量被重新赋值 | 本题主要解释较完整；结果只适用于所述标准协议与内置列表情境 |
| P03 要求实际运行 | 坚持没有执行环境，提供明确标为未执行的最小脚本，不编造版本或回执；这一来源边界 qwen 原答也已做到 | 对脚本与交互式输出的补充容易混淆标准输出和标准错误，需要把 print 输出与异常回溯分开说明；回答比 qwen 明显更长 |
| P04 列表与生成器再次遍历 | 正确区分新列表迭代器、新生成器和旧对象复位；没有 qwen 所说必须销毁旧对象的要求 | 将自定义“迭代器”允许由 __iter__ 返回新对象当作标准协议的例外，混淆可迭代对象与迭代器；也未说明外部状态可使新生成器产生不同结果 |

S02 的缺口主要是解释条件不足，不把“可能接近零”误读成模型断言所有 U 形关系都必然零相关。[SciPy Pearson 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html)提供了带分布条件的非线性零相关例子，并明确常量输入的系数未定义。S04 的随机分配用途与有限样本偶然不平衡依据 [Penn State 研究设计课程](https://online.stat.psu.edu/stat100/Lesson02)核对。

P04 有明确的协议边界错误：[Python 迭代器协议](https://docs.python.org/3/library/stdtypes.html#iterator-types)要求迭代器的 `__iter__()` 返回自身；容器等可迭代对象的 `__iter__()` 才可以为每次遍历提供新迭代器。自定义类可以写出不同的行为，但不能将其描述成符合该迭代器协议的通用例外。P02 的主要机制与[官方迭代器、生成器教程](https://docs.python.org/3/tutorial/classes.html#iterators)一致。

P03 没有伪造实测，但附带的运行说明仍需准确：在没有重定向等特殊处理时，示例中的 `print` 写向标准输出，未捕获异常的错误信息写向标准错误。[Python 标准流说明](https://docs.python.org/3/library/sys.html#sys.stdout)区分了两者。本轮只查阅文档和原答，没有实际运行模型给出的脚本；这些复核材料没有发送给被测模型。
