# 手动选择文件的双栏阅读

更新：2026-10-17，版本 `0.88.5`。双栏在同一阅读标签内显示，顶部列出两份文件，中间按钮可交换左右位置，中央分隔线可调整宽度。文件可以位于当前知识库的任意目录、使用任意文件名，不再按目录自动接管普通 Markdown 标签。

## 打开与切换

1. 在文件列表右键 Markdown 或 PDF，选择「选择阅读方式…」。已打开文件也可从页面右上角的更多选项进入；文献阅读器还提供「选择双栏文件…」按钮。
2. 选择「Markdown＋PDF」，或统一的「英文＋中文 Markdown」。双语不再分成两个入口：下一页的「当前文件是」下拉框确认英文原文／中文译文。文件名含 `zh-CN`、中文、译文或英文提示时预选，可更正；无提示或提示冲突时需要手动确认。文件名提示只用于界面预选，不证明译文或英文证据。从中文开始也会把英文放在左栏、中文放在右栏。
3. 在目录树展开文件夹，点击另一份文件，核对底部所选路径与语言配对，再点击「打开双栏」。当前文件所在目录默认展开，其他目录可折叠；行内只显示文件名，悬停查看完整路径。输入文件名或路径搜索时保留匹配文件的目录层级；清空搜索恢复之前的展开状态。上下方向键移动，左右方向键展开／折叠或进入子节点／返回父目录，Enter 选择，Tab 到确认按钮；双击文件也可确认。选择器按文件类型过滤并排除配对的另一文件；取消不会改变当前阅读页。
4. 点击两份文件名之间的「交换左右位置」图标，标题与内容一起换位；再次点击换回。初次仍默认左英文／Markdown、右中文／PDF。交换后的来源标签、批注与同步方向继续跟随文件；两份文档的宽度和阅读位置保留，显示顺序随阅读状态保存。分隔线的拖动和方向键始终按屏幕中的左右方向操作。
5. 点击双栏顶部任一文件名，可更换该文件。换位后点击左侧的「中文译文」仍选择译文，PDF 仍按 PDF 类型过滤。点击「退出双栏」回到开始时的文件；退出不删除文件，也不更改原文。可同时打开多个双栏标签。

「正文＋图片与图注」继续使用单份 Markdown 的图文阅读。MinerU 包原来的 PDF 定位、版面框及图文能力保留。手动 Markdown＋PDF 不要求转换包：初次右侧显示所选 PDF，可交换到左侧，提供页码、上一页／下一页、40%–400% 缩放和同页文字批注。

## 同步规则

两栏各有「以本栏同步另一栏」按钮，以点击所在栏为基准，单次同步不依赖联动开关。打开联动后，以用户正在操作的栏为基准同步另一栏，程序同步不会反向触发滚动循环。

点击引用、脚注返回或回到已保存摘录时，只定位所在正文栏，顶部文件栏、联动与批注按钮保持可见。开启联动时仍按既有对应规则同步；引用目标缺失时提示，不能借用另一栏的同名目标。`0.88.4` 修复主题下的外层滚动错位，见[定向验收](bilingual-citation-navigation.md)。

| 资料条件 | 同步方式 | 含义 |
| --- | --- | --- |
| 已有有效翻译记录，英文版本和段落结构一致 | 对应段落及段内位置 | 结构对应仍需核对译文语义 |
| 手动选择两份 Markdown，没有有效对应凭据 | 各自全文的阅读进度 | 不能据此确认对应段落或译文正确性 |
| 手动 Markdown＋PDF | Markdown 阅读进度与 PDF 文件页码／页内进度 | 不提供转换包中的精确段落、版面或证据定位 |

知识库工作区保存两份文件路径、模式、显示顺序、联动、栏宽和阅读位置；PDF 还保存页码与缩放。旧状态没有显示顺序字段时，沿用原来的顺序。交换只改变呈现，不对调内部英文／译文或 Markdown／PDF 的来源路径和版本凭据。已有保存状态优先于全局默认值。文件变化时停止旧同步或旧选区保存，历史批注保留，需重新打开核对；更换文件不会沿用旧文件的选区。

## 批注与证据来源

`0.88.5` 支持[含链接、引用和脚注的同段选区](linked-annotations.md)。部分链接文字扩展为完整文字并提示，保存原始源码位置，返回时在相应来源栏恢复可见选区。单次最多 600 个显示字符，含链接源码最多 2400 字符；无法唯一对应的特殊渲染提示在原文编辑器重选。

手动阅读中的批注和摘录独立保存在 `wiki/annotations/`，不改写所选 Markdown 或 PDF。双语记录保留英文和中文的实际路径、文字版本、语言和选区；PDF 记录保留文件版本、文件页码和页内文字凭据。仅核对文件与文字位置，不据此确认论文身份或科学结论。

中文摘录明确标为译文；个人备注、AI 解释和英文来源分别保留。手动把两份 Markdown 放在一起，或把两栏同步到相同进度，不会生成英文证据。没有对应英文凭据时，中文仍可保存个人批注和摘录，AI 对照解释在模型调用前停止并提示核对配对。英文侧解释只使用当前英文选区所在块，继续区分英文依据与模型一般知识／解释性推断。

如已有匹配的 `translation.json`，可沿用原来的来源与结构检查。记录放在英文文件旁，其 `sourceFile` 和 `translationFile` 必须与同目录中实际选定的文件名一致；来源版本与结构检查通过后才提供对应块。记录不能替用户选择另一个文件，损坏、不匹配或缺少版本的记录也不会自动建立依据。原来的规范双语资料保持兼容。
