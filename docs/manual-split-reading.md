# 手动选择文件的双栏阅读

更新：2026-10-12，版本 `0.85.0`。双栏在同一阅读标签内显示，顶部列出两份文件，中央分隔线可调整宽度。文件可以位于当前知识库的任意目录、使用任意文件名，不再按目录自动接管普通 Markdown 标签。

## 打开与切换

1. 在文件列表右键 Markdown 或 PDF，选择「选择阅读方式…」。已打开文件也可从页面右上角的更多选项进入；文献阅读器还提供「选择双栏文件…」按钮。
2. 选择「Markdown＋PDF」，或「英文＋中文」。双语模式需要明确当前文件作为英文原文还是中文译文；从中文开始也会把英文放在左栏、中文放在右栏。
3. 在文件选择器输入文件名或相对路径，选择另一份文件。选择器按文件类型过滤，并排除第一份文件；取消不会改变当前阅读页。
4. 点击双栏顶部任一文件名，可更换该栏文件。点击「退出双栏」回到开始时的文件；退出不删除文件，也不更改原文。可同时打开多个双栏标签。

「正文＋图片与图注」继续使用单份 Markdown 的图文阅读。MinerU 包原来的 PDF 定位、版面框及图文能力保留。手动 Markdown＋PDF 不要求转换包：右侧显示所选 PDF，提供页码、上一页／下一页、40%–400% 缩放和同页文字批注。

## 同步规则

两栏各有「以本栏同步另一栏」按钮，以点击所在栏为基准，单次同步不依赖联动开关。打开联动后，以用户正在操作的栏为基准同步另一栏，程序同步不会反向触发滚动循环。

| 资料条件 | 同步方式 | 含义 |
| --- | --- | --- |
| 已有有效翻译记录，英文版本和段落结构一致 | 对应段落及段内位置 | 结构对应仍需核对译文语义 |
| 手动选择两份 Markdown，没有有效对应凭据 | 各自全文的阅读进度 | 不能据此确认对应段落或译文正确性 |
| 手动 Markdown＋PDF | Markdown 阅读进度与 PDF 文件页码／页内进度 | 不提供转换包中的精确段落、版面或证据定位 |

知识库工作区保存两份文件路径、模式、联动、栏宽和阅读位置；PDF 还保存页码与缩放。已有保存状态优先于全局默认值。文件变化时停止旧同步或旧选区保存，历史批注保留，需重新打开核对；更换文件不会沿用旧文件的选区。

## 批注与证据来源

手动阅读中的批注和摘录独立保存在 `wiki/annotations/`，不改写所选 Markdown 或 PDF。双语记录保留英文和中文的实际路径、文字版本、语言和选区；PDF 记录保留文件版本、文件页码和页内文字凭据。仅核对文件与文字位置，不据此确认论文身份或科学结论。

中文摘录明确标为译文；个人备注、AI 解释和英文来源分别保留。手动把两份 Markdown 放在一起，或把两栏同步到相同进度，不会生成英文证据。没有对应英文凭据时，中文仍可保存个人批注和摘录，AI 对照解释在模型调用前停止并提示核对配对。英文侧解释只使用当前英文选区所在块，继续区分英文依据与模型一般知识／解释性推断。

如已有匹配的 `translation.json`，可沿用原来的来源与结构检查。记录放在英文文件旁，其 `sourceFile` 和 `translationFile` 必须与同目录中实际选定的文件名一致；来源版本与结构检查通过后才提供对应块。记录不能替用户选择另一个文件，损坏、不匹配或缺少版本的记录也不会自动建立依据。原来的规范双语资料保持兼容。
