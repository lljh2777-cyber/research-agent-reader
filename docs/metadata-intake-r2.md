# R2 首批：无需模型添加文献信息

2026-09-11，开发版本 `0.62.0`。交付「文献库 → 添加文献信息 → 查询 → 核对 → 仅保存书目信息 → 在库中查看」，也可通过命令「添加文献信息（无需模型）」进入。R2 继续开发，公开 beta 保持 `0.31.0`。

## 使用与实现

输入 DOI、PMID、PMCID 或既有解析器支持的 DOI／PubMed／PMC／Nature 链接。查询复用 `IdentityResolver`，向 Europe PMC 和 Crossref 请求元数据；预览与取消不创建获取任务，不初始化模型、阅读服务或全文获取服务。没有精确结果、输入不匹配或身份冲突时停止，保留错误说明和显式重试入口。

预览展示标题、作者、年份、文献类型、标识、查询来源和警告。用户核对后，`MetadataIntakeService` 再次执行 `SourceCatalog` 的精确关联，并通过 `JournalPaperRecordStore` 追加提交记录。文献详情显示书目信息和来源；从保存结果打开时按标识筛选并按 paperId 定位，不能用另一篇标题相似的论文替代。

`LibraryRecordObject` 增加可选 `bibliography`，复用经过验证的 `ResolvedIdentity`，与记录标题和标识严格一致。书目信息属于冻结身份快照，后续人工阅读状态和主要笔记编辑必须保留它。旧记录无需改写，旧修订摘要不变。原始大小限制和提交标记校验继续适用。

已有持久记录直接复用，不覆盖其标题、作者、阅读状态、主要笔记或并发决定。已有原文包但尚无人工记录时，首份书目记录使用包的 paperId；旧笔记按精确标识关联。此处不合并笔记正文，不为无标识旧资料猜测身份。

同一插件实例内的保存串行执行，双击和多个查询预览不会重复新建记录。不同进程／设备仍可能同时首次创建不同 paperId：提交后的关联检查尽可能及时报告冲突，保留所有版本，由文献库显示冲突；不声称具有跨设备全局锁或自动身份合并。发生写入中断时保留未提交文件，重试复用已提交记录；关闭窗口不撤回已经开始的原子提交。重启后尚未提交的尝试不冒充成功记录。
