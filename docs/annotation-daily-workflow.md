# 批注日常使用闭环核对

2026-10-22，Windows / Obsidian 1.14.4；基线 `0.89.2`，修复版本 `0.89.3`。

本轮使用测试库已有 DeepMet 中英文全文，以及[上轮真实论文节选](cli-annotation-quality-samples.md)中的胰腺癌分型和 Novae，核对个人批注、已保存 AI 解释、修改与取消、列表查找、切换论文和来源定位。未重新生成 AI 回答，不是新一轮科学或译文质量审阅。

## 发现与修复

### 连续编辑的保存与快捷键

旧编辑页把 Ctrl+Enter 处理器绑定到反复使用的小窗容器；取消或保存后重新编辑，旧处理器仍保留之前的文本框。内存事件回归复现一次快捷键提交两份草稿，包含已取消内容。保存过程中重复按键也可以启动重叠写入。

修复将 DOM 处理器绑定到当前文本框；保存期间阻止重复提交，并锁定编辑与取消控件。关闭小窗后，迟到的保存结果不再重绘已关闭界面。新建批注也阻止保存期间再次提交。

原生检查另确认宿主会先处理保存组合键，因此编辑界面现在使用 Obsidian 的快捷键作用域：Windows/Linux 使用 Ctrl+Enter，macOS 使用 Cmd+Enter；取消、保存后返回阅读界面、关闭和卸载时释放。原生 DOM 键盘事件复验从未到达批注保存处理器变为准确提交一次。没有改动用户快捷键配置。

### 按来源路径查找批注

文献库搜索原先没有包含批注自己的来源路径。已有来源条目可能命中，但仍保持独立、待关联身份的新批注会被漏掉；原生列表核对没有找到本轮新增记录，内存回归也复现了遗漏。

搜索现在包含已保存批注的来源路径，能够找到对应记录并打开批注文件。只是增加搜索字段，不按路径、同名文件或标题自动确认论文身份，不改变“待关联”状态。普通批注仍从文献库或批注目录查看，摘录列表继续只列摘录。
