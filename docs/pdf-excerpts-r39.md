# R3.9：原生 PDF 划词摘录

更新日期：2026-09-12。开发版本：`0.77.0`。

## 使用方式

在 Obsidian 原生 PDF 阅读器打开 `papers/` 或 `Clippings/` 下的 PDF，在同一页的文字层划选文字，点击“批注 → 保存摘录”。核对原句与文件页码，填写可选个人备注后确认。每次最多 600 个字符，支持跨行，当前不支持跨页、扫描图片或 OCR。个人备注最多 10,000 字符。

保存后可从摘录列表搜索原句、路径与备注。备注可以独立修改；其他窗口或同步已修改整份摘录时，旧草稿不会覆盖它，可以“重新读取（保留草稿）”后核对保存。手动整理完成及重新待整理沿用既有流程，不代表科学审阅完成。重复选择相同文件版本、页码和位置时打开同一条摘录，不覆盖已有备注。

“回到原文”重新核对 PDF 字节、页数、页内文字与位置，再打开原生 PDF 并选中保存的原句。显示的是从 1 开始的文件页码，与论文印刷页码区分；验收样本的文件第 1 页实际印刷页码为 211。文件缺失、版本变化、文字层不兼容或摘录凭据损坏时保留历史记录，明确提示并停止定位。打开后的文字层尚未加载成功时可以稍后重试，不采用相似文字搜索。

## 文件与来源约定

仍保存为 `wiki/annotations/ann-excerpt-<48 位摘要>.md`，新增可选 `pdfExcerpt` 凭据，与 Markdown `excerpt` 互斥。旧 Markdown 摘录格式不迁移；PDF 文件不写入批注，不改写提取包，也不上传或调用模型。

PDF 凭据固定 SHA-256、字节数、页码、总页数、页内文字投影摘要、页内 UTF-16 位置及上下文。`pdfjs-items-eol-v1` 使用 `getTextContent({ disableNormalization: true })` 的原始字符和显式行尾；保留 `ﬁ` 等连字及断行，不自动展开、补空格、去连字符或解释表格。摘录原文和上下文在 Markdown 中使用转义后的纯文字 `<pre>`，控制标记无法改变文档分区。

原生适配器检查文本层的 `data-idx` 与实际 PDF 文字项，校验整页可见文字项后才转换选区。捕获时同时比较阅读器当前显示的 PDF 字节与 Vault 文件，避免读取仍显示旧版本的页面。独立 PDF.js 核验任务结束后释放资源；文件上限为 64 MiB、总页数 2000、单页投影 2 MiB，页内核验超时 15 秒，打开原文等待文字层最多 8 秒。无法无交互读取的加密文件暂不提供专门密码流程。

文献库新增 `dashboard-pdf-excerpt-1` 来源类型，只能与相同路径、相同文件指纹且已核验的 PDF 来源关联。未登记 PDF 或未通过目录核验的来源保持独立，不借用转换包或论文身份。它们可以保存、编辑和回到 PDF 原页，但即使手动标记完成，待处理中心仍保留来源关联复查项。文件版本一致不等于论文证据或图表结论已审阅。

当前 PDF 摘录不显示“补充到已有笔记”及相应整理历史入口；已有 Markdown 摘录和学习摘录整理继续使用各自的适配器。PDF 页码引用、包身份验证与正式整理的预览／恢复／撤销将在下一步接入。
