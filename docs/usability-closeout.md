1. 从文献库找到资料，核对标题和来源，选择原始 PDF 或已验证的原文包，进入阅读会话。
2. 生成一个单元，再围绕一个具体问题追问。点击回答中的证据，回到原文核对；引用可点击不代表结论一定正确。
3. 保存原句时用原文摘录；保留模型讲解时用“保存回答摘录”。将自己的理解写入独立备注。
4. 需要整理成笔记时，从摘录起草，检查正文、索引及日志预览后创建。保留待审阅身份，再从摘录或笔记回看来源。

### 从主题开始

1. 打开“主题路线（预览）”，填写主题、目标和已有基础，保存目标后选择已验证模型。
2. 点击生成路线草稿，检查单元和先修关系，再确认路线并打开学习预览。
3. 生成一个单元；针对不理解的地方提出支线问题，通过导图或“返回主线位置”继续学习。
4. 手动标记“待回看／仍有疑问／已理解”，按需要预览并导出当前节点、主支线或完整记录。自评不等于事实核验。

生成失败时先查看错误和用量；重新尝试是一次新的请求，可能再次计费。日常恢复可直接打开原会话或学习记录，不必再次点击生成。主题导出属于模型一般知识学习记录，不能作为已核验论文依据。
