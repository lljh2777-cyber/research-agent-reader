# R1 首页待处理摘要与最近整理

2026-09-11，开发版本 `0.60.0`。

首页增加「待处理与最近整理」，汇总已保存任务和整理记录。用户可以打开未完成任务、待审阅建议、需复查或恢复的记录，以及最近三次修订。最近修订按保存更新时间排序，按记录 ID 定位；缺失或无法读取时明确提示，不替换成其他记录。点击「修订记录」可以解除单条筛选。

## 统计与刷新

- 未完成任务：具有任务 ID 且处于排队、运行、失败或中断状态的任务；点击后展开任务历史并筛选未完成项。
- 待审阅：处于 ready 状态且仍含 pending 建议的批次数，不是建议条数。
- 需复查／恢复：失效、失败或中断的整理批次，加上未应用或标记需复查的修订记录。两类记录分别计数，同一处理过程可能占多条。
- 生成记录待核对：保存状态为 generating 的批次数，不证明后台仍在运行。点击进入「整理批次」，同时可见仍在生成和已恢复为中断的记录。
- 最近整理：最多三条修订，区分记录标记已应用、需复查、等待恢复与已保存撤销修订；不表示当前正文通过核验。

摘要随首页加载、现有刷新流程或「刷新整理摘要」重新读取；不是实时订阅的整理状态。打开整理窗口后状态可能变化，回到首页可手动刷新。

## 只读边界

首页通过 `FileSourceStorage.read/list` 读取插件目录中的 `knowledge-reviews/reviews` 与 `knowledge-reviews/revisions`。它不初始化整理服务，不创建目录、不恢复临时文件、不改写遗留 generating 状态，不调用回答模型或索引服务。

用户明确打开整理窗口时，沿用既有服务的初始化逻辑：遗留生成任务可能被登记为中断。采用、撤销、恢复、来源检查和索引更新仍由窗口内的相应操作触发。

读取最多 256 条记录、累计 64 MiB，单条最多 8 MiB。统计检查身份、时间、状态和目标路径等摘要字段，不代替完整记录校验或科学审阅。损坏、缺失、读取异常、临时写入或达到上限时显示「统计不完整」及读取提示；最近三条只在成功读取的范围内排序。文件按名称读取，超过上限时不保证覆盖全库最新记录。
