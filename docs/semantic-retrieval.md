# BGE 知识库检索

检索层使用 `BAAI/bge-m3` 的稠密向量与 `BAAI/bge-reranker-v2-m3`，通过硅基流动 API 调用。原关键词检索仍保留；模型失败时返回明确的回退说明。高相关分只用于排序，不决定事实正确、证据充分或自动入库。

## 核心接口

`KnowledgeRetrievalService` 统一输出片段正文、文件哈希、字符位置、标题、章节、证据角色及原始来源。来源页、背景说明、导航、研究设想和来源边界分别标记。普通事实查询排除导航与设想段；每篇最多返回两个片段，保留单篇内的补充依据。

论文约束来自用户原问题中的作者＋年份、DOI、完整标题、引用键，或调用方提供的明确文件列表。限定论文时只检索对应来源笔记，不用模型扩展词改变范围；未找到指定论文则返回缺口。多篇论文明确出现时保留这些论文的范围。

## 本地索引

索引保存在插件目录 `retrieval-index/bge-v1.bin`。它是可重建的派生缓存，包含模型/结构版本、文件哈希和 Float32 向量，不包含密钥。单文件原子替换；成功批次检查点支持停止后续建。不执行任何文件清理或笔记写入。

查询读取当前笔记，只使用输入哈希一致的向量。新增与修改文本仍参加关键词匹配，界面提示更新索引；请求进行中来源变化时，旧片段会被排除。删除的来源不会因为旧向量仍在磁盘而出现在结果里。

范围为 `wiki/sources`、`concepts`、`methods`、`datasets`、`synthesis`、`mocs`、`projects`、`entities`、`code`、`r`、`linux`。不纳入原文包、批注、QA、日志及范围外索引。单库暂限 5,000 篇、20,000 片段，单篇最多 250,000 字符；超限明确报错，避免无提示地只索引一部分。

## 验证

`node tests/test_knowledge_retrieval.js` 使用内存和模拟接口，覆盖论文范围、片段角色、代码围栏、紧凑存储、损坏索引、增量更新、重复点击、失败回退、取消与请求期间来源变化。没有真实网络、磁盘写入或删除清理。

离线评估的设计与限制见 [检索基准](retrieval-benchmark.md)。本次开发以独立阶段提交：检索与存储基础、设置和问答接入、导出关联与审阅、测试库验证。
