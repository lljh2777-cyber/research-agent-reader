# R2 第六批：已保存原文的转换与初始笔记

2026-09-12，开发版 `0.66.0`，已部署 `E:\paper-test`。公开 beta 保持 `0.31.0`，R2 尚未收尾。

## 可用流程

在文献详情的已核验 PDF 原文卡片点击“转换正文 / 生成初始笔记”，选择原文 Markdown、文章 Wiki 或两者。初始笔记明确选择所选 PDF，或本次转换／可复用的 Markdown；缺少所选依据时保留错误，不静默切换。

单独转换正文无需配置模型。若选择转换，必须同意把 PDF 发送到配置的 MinerU 服务，随后核对实际 PDF 页面。复用来源目录确认的身份，模型不参与书目身份决定。已验证且来源和转换参数一致的原文包可以复用；已有笔记不会覆盖。

JATS 原文卡片的“生成 / 恢复初始笔记”打开现有 JATS Wiki 流程：核对同版本正文、生成草稿、预览内容和依据，再明确保存及登记。它不经过 MinerU，初始笔记深度最高为 `abstract-level`，不自动升级 X-Ray。

PDF 窗口展示此份原文的处理记录，可查看结果并续办。续办保留上次输出、转换参数、关注点和笔记依据；上传同意重新确认，重载和打开窗口不自动执行。这里只显示最近 100 条入库任务中凭据精确一致的记录，读取失败和范围限制明确提示。

## 来源与恢复约束

`SavedPdfRef` 固定原文包、清单摘要、paperId、PDF SHA-256 和字节数。本地保存和在线保存的 PDF 共用它，处理不依赖旧获取任务或临时下载文件。来源读取通过共用校验器确认包、字节和当前归属，路径只从当前库与受管包推导。

任务与请求分别保存凭据；查看、继续与执行均校验一致性。修改或移除请求中的来源绑定不能把旧任务转成另一份原文。凭据字段顺序不影响判断，旧请求保持兼容。

开始处理、远程转换前、转换完成后的发布前，以及 Wiki 保存前，重新核对原文。JATS 在卡片交接和正文检查之间也比较清单摘要；取消的异步打开不能迟到显示窗口。已保存原文、旧笔记和旧任务输出保留，失败不撤销此前的来源保存。

纯转换跳过模型解析和生成，仅运行确定性的来源确认与转换阶段。授权副本、转换暂存和绑定任务保留；读取处理历史不创建记录目录。该路径不执行批量清理。

- 来源身份、请求解码、任务生命周期、全文入库保留策略、PDF 草稿、登记和 JATS Wiki 定向回归通过。
- `pnpm typecheck`、`pnpm build`、`pnpm release:check` 通过。

新增来源与提取测试使用内存存储和模拟边界，未调用外部服务。既有全量及部分 MinerU 测试含清理路径，本批采用已核对的定向回归，不宣称全量通过。
