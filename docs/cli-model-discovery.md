# CLI 批注模型目录与 Qoder CN 额度

更新：2026-10-18，版本 `0.89.0`。入口为「设置 → Research Agent Reader → 批注 AI」。

## 操作

1. 选择 CodeBuddy、Qoder CLI CN，或官方配置且关闭浅层联网的 OpenCode，核对本机程序路径。
2. 点击「刷新模型列表」；Qoder 点击「刷新模型与额度」。显示查询状态、来源、时间及固定模型候选数。页面打开不自动联网查询。
3. 在「模型」选择条目，或填写准确自定义 ID。刷新不更改已选 ID；已选但未在最新目录中的 ID 保留并标出。查询失败时只显示预设与已选 ID，不能据此认定当前可用。
4. Qoder 账号额度按套餐、附加额度、可用组织共享额度分别展示。没有有效 `remaining`、接口不支持、查询失败或超时均显示「未知」；真实 0 仍显示 0。不会用会话消耗估算余额，也不把各额度相加为免费模型调用次数。

目录不等于免费模型清单或调用可用性检测。Qoder 的 Auto 自动路由不作为固定模型候选；同名自定义条目在标签中显示 modelID，调用使用该 ID。OpenCode 使用完整 `provider/model`。新目录并不改变各后端既有的模型参数和批注完成／来源核对规则。某模型不支持当前文字批注参数时显示调用失败，不自动换模型。

结果只保留于当前插件内存，重载需重新刷新，登录切换后也应刷新。程序路径变化不复用原路径的目录或账号快照；失败刷新清除旧成功快照，避免把过期余额显示为当前值。额度只反映标注时间的账号快照，不保证某免费模型的速率或每日限额。

## 查询方式与边界

| 后端 | 模型目录 | 账号剩余额度 |
| --- | --- | --- |
| CodeBuddy | `-p` 双向流 JSON 的 `initialize` 控制回复中 `models`，无用户消息，`hasPrompt: false` | 本轮不查询 |
| Qoder CLI CN | `qoderclicn --list-models`，自定义模型解析为 modelID | 流 JSON `initialize` 与 `get_usage_info` 控制请求，读取 `usage` 下各额度桶的 `remaining` |
| OpenCode | `opencode models --pure --refresh`，沿用登录并使用隔离配置，刷新目录缓存 | 本轮不查询；`stats` 是消耗统计 |

每次查询在独立空目录执行，不传 Vault 正文，不发送用户／助手消息，不生成 AI 回答。控制查询关闭工具、MCP、Hooks 和会话持久化；OpenCode 沿用已有配置隔离与关闭插件／共享／自动升级规则。直接启动程序，不使用 Shell。45 秒总上限、重复刷新合并、插件卸载等待进程树关闭。不会安装新 SDK、读取或复制 CLI 凭据；CLI 可能请求自身账号／目录服务，临时目录和启动描述保留。只留模型 ID／标签和额度字段，不保存账号身份或原始查询输出。

接口依据：[CodeBuddy SDK](https://www.codebuddy.cn/docs/cli/sdk-typescript)、[Qoder 模型选择](https://docs.qoder.com/cli/model)、[Qoder SDK 额度](https://docs.qoder.com/cli/sdk/cost-usage)、[OpenCode CLI](https://opencode.ai/docs/cli/)。SDK 文档只用于协议核对，插件不引入 SDK 依赖。

## 验收

Windows 本机使用 CodeBuddy `2.164.0`、Qoder CN `1.1.69`、OpenCode `1.19.0`。生产查询层实际返回 18／15／10 个固定候选；Qoder 返回了有效套餐和附加剩余额度。数量与额度是当次快照，不写成产品固定配置。OpenCode 当次目录不含 `opencode/step-5-preview-free`，该旧选择仍保留，已知不可用边界继续有效。

新增定向回归核对准确 ID、自定义／同名条目、去重、查询协议中没有用户消息、有效零额度、缺失／非法额度、模型与额度独立失败、刷新清除旧数据、路径隔离、重复请求合并、取消和卸载。类型检查、构建及既有三个 CLI 批注、共用进程、设置、供应商与公开运行边界回归通过。

Windows / Obsidian `1.14.4` 的测试库通过 30 项原生 DOM 检查：进入页面不查询、实际点击刷新、查询中按钮禁用、三份目录进入下拉框、Qoder CN 真实额度显示、BYOK 准确 ID、已下架 OpenCode Step 选择保留、自定义输入与下拉值同步，以及程序路径改变后目录待查／额度未知。界面测试使用临时设置副本，真实插件设置保持不变；未将 DOM 事件核对报告为物理鼠标完整自动化。插件重载已确认查询缓存清空。

初次原生准备因宿主缓存旧 manifest 版本被中止，重新读取清单后继续；后续驱动误把当前 mimo 选择当作旧 Step，并在一次修正后受模块缓存影响再次失败，清除驱动模块缓存、显式设置临时旧 ID 后通过。这些是准备／测试断言失败，无 AI 任务。首次屏幕捕获只得到主窗口旧帧，不计作设置页视觉验收。私有留档保留失败与最终结果，未批量清理。

初次发布未重新生成论文解释、改写原文或批注记录，也未重做完整宿主退出重启、其他平台原生桌面或独立科学／翻译／教学审阅。主题学习保持预览，迁移、完整翻译、跨论文对照及主题资料辅助继续暂缓。本地旧全量入口含批量清理，未运行；完整公开检查由三平台 CI 和标签工作流执行。私有查询留档在本机测试目录，不进入仓库。
