## 1. 最小范围与现有流程

用户已确认“双屏”指同一个阅读标签内的左右两栏：左英文、右中文。首版闭环为：

**打开已有资料 → 双栏对照阅读 → 划选批注／摘录 → 回看来源 → 预览后选择性整理。**

首版包括两栏独立滚动、双向联动开关、两栏各自的单次同步按钮、现有批注功能适配，以及正常退出后的阅读状态恢复。初始左右各半，沿用可调整的分隔线。

本方案不包含翻译生成、章节／全文重译、术语库、译文人工修订管理、整篇译文导出、批量处理、外部目录直接读取或独立窗口／多显示器同步。译文状态来自已有记录，不新增翻译任务系统。

普通 Markdown 目前可进入文献阅读器，但不具备完整的论文交互深读契约。首版接通划选 AI 解释，不把这类文件自动变成主线讲解、追问和导图的来源。已有 PDF／MinerU／JATS 会话继续使用原有证据与定位；如需将双语 Markdown 接入完整交互深读，应另行明确来源契约。

## 2. 输入约定与配对检查

采用 `E:/Literature_translation/AGENTS.md` 规定的布局，内部路径保持原样：

```text
<论文目录>/
  paper.md
  paper.zh-CN.md
  images/
  translation.json
```

- `paper.md` 是英语来源，`paper.zh-CN.md` 是中文译文，两份文件共享相对图片路径。
- 规范要求保持章节顺序、标题层级、段落对应、图表位置与编号；公式、代码、DOI、作者、链接目标和参考文献保留原样。
- 首版识别同目录的上述文件和 `translation.json` 的 `sourceFile`、`translationFile`；字段必须与实际配对一致。只解析必要元数据，文件引用限定在该资料目录内，不接受绝对路径或越界路径。
- 显示 `status`、`humanReview` 与来源是否过期。`needs-review` 可以用于对照阅读；结构检查和 AI 检查通过不能显示成人工审阅通过。
- 根据实际英语文件字节核对 `sourceVersion`。原文已变化时，即使记录中的 `stale` 为 `false`，也应显示译文来源已过期。缺少或无法核对版本时明确显示未确认，不假定当前配对可靠。
- DOI、标题等只辅助识别，不凭目录名或元数据自动登记文献身份，也不借用同名论文的 PDF 页码。

当前加载器依赖当前 Vault 的文件接口。首版支持 Vault 的 `Clippings/` 下规范双语目录，沿用已有剪藏与独立批注边界。未来首轮原生验收建议在 `E:/paper-test/Clippings/<论文目录>/` 使用完整样本副本，保留内部布局；复制夹具是后续实施步骤，本次没有执行。首版不改动原始 `E:/Literature_translation/` 资料，也不将其当作 MinerU 包。

从任一 Markdown 进入阅读器后，提供明确的“双语对照”动作；从中文入口进入时仍按左英文、右中文布局。缺文件、元数据无效或版本无法确认时，保留普通单份阅读能力，不自动猜配对。

## 3. 双栏显示与同步规则

双语模式中，图片、图注和表格保留在各自正文位置；图片共用原文件，点击可放大。现有正文＋图表参考栏模式继续保留。双语模式不能沿用将图片移出正文的投影，否则对应块和阅读位置会发生偏移。

每栏具有明确的语言标签、批注入口和“以本栏同步另一栏”按钮。脚注、章节内链接应在所属栏定位，避免两份文档的同名锚点跳到另一栏；外部链接沿用现有行为。

### 对应表

加载时从两份原始 Markdown 构建对应表，记录章节、块类型、两侧原始字符范围及渲染锚点。首版支持规范内的一对一块对应，不做模型语义匹配、词语逐一对应或任意文档的模糊配对。

标题层级／顺序、章节内块类型／数量、共用图片路径和脚注标识用于检查结构。公式、代码、列表和表格作为完整块处理。标题文字已经翻译，不能以标题字符串相同作为对应条件。前置信息不参与阅读同步，但必须保留它在原始文件中的偏移，不能用去除前置信息或渲染后的偏移保存批注。

对应表绑定两份文件的当前版本，仅作为可重建的阅读数据；不向原 Markdown 插入 ID，也不改写 `translation.json`。结构对应不代表译文含义已核验。

同类型段落换序、等量漏段与增段可能通过类型／数量检查；首版依赖输入规范的一对一对应约定，不能声称自动识别所有错配。界面以“结构对应”说明定位依据，保留译文待复核状态和独立阅读能力；语义对应仍需读者核对英文。

### 交互规则

| 操作 | 行为 |
| --- | --- |
| 首次打开有效配对 | 左右各半；成功建立对应表后默认开启联动，原文与译文状态始终可见 |
| 联动关闭 | 两栏完全独立滚动，各自保留阅读位置 |
| 联动开启时滚动任一栏 | 用户实际操作的一栏成为基准，另一栏跟随；支持滚轮、拖动滚动条和键盘滚动，单纯悬停不改变基准 |
| 点击英文侧同步按钮 | 只移动中文侧，以英文侧当前阅读位置为基准 |
| 点击中文侧同步按钮 | 只移动英文侧，以中文侧当前阅读位置为基准 |
| 关闭联动时点击同步 | 执行一次同步，开关仍保持关闭 |
| 重新开启联动 | 以当前操作栏执行一次对齐；没有操作栏记录时以英文栏为基准 |
| 图片加载、字号／窗口／分栏变化 | 重新测量锚点，保留当前阅读块，避免回到顶部或逐步漂移 |
| 插件重载或正常完整重启 | 核对文件版本后恢复开关、分栏比例和两栏块位置；恢复过程不触发模型请求或额外同步跳转 |

同步基准是正文可视区上沿的对应块，扣除固定栏头；长段落可按块内相对位置辅助调整。单次同步与自动联动共用定位规则。相对位置只表示块内阅读进度，不宣称同一句或同一词语精确对齐；不使用整篇滚动百分比替代段落对应。

程序引起的目标栏滚动不得反向成为新的同步输入。连续滚动按绘制帧合并处理，避免往返跳动；切换资料、关闭视图或失效的异步回调不能继续控制旧视图。

结构异常、原文版本过期或配对变化时，暂停联动和单次同步，并说明原因。仍可独立阅读可用文件、查看历史批注；不得凭相同滚动比例或相似文字猜测新位置。重新加载、核对配对后再建立当前对应表，旧批注不会自动迁移。

## 4. 批注、摘录与来源区分

复用现有批注弹窗、个人备注、AI 解释、摘录列表、草稿和整理预览。每栏选区必须绑定自己的文件路径、实际选中文字、准确字符范围及保存时版本；点击工具栏时保留原选区，不能被另一栏选区或联动滚动替换。

| 保存内容 | 身份与定位要求 |
| --- | --- |
| 英文选句 | 英文来源摘录，精确定位到 `paper.md`；剪藏来源仍保留其外部资料身份 |
| 中文选句 | 译文摘录，精确定位到 `paper.zh-CN.md`；保留译文审阅状态和英语来源版本 |
| 英文对应段落 | 只有配对有效且实际读取、核对过时才附带；保存英文段落快照和范围，不将中文选句冒充其逐字译文 |
| 个人备注 | 独立用户记录，保留原句与译文，不覆盖它们 |
| AI 解释 | 独立模型内容，保留模型身份；背景知识、联网补充与读取的本文材料区分 |

两种语言的选句分别保存，不按段落对应自动去重、合并或覆盖批注。重复选择同一文件版本的同一位置可以复用已有记录。回看时先定位当时选择的语言；有效配对下可另外查看对应英文／中文段落。

双语资料使用独立批注文件，沿用 `wiki/annotations/` 保存职责；英语、中文、元数据和图片都只读。首版不扩大现有选区限制：同一段落内、可唯一定位的文字，沿用当前字符上限和受保护内容限制。

### AI 解释

AI 解释仍由用户明确发起，复用已有模型选择、取消和用量机制。中文侧可提供中文选区、上下文及已确认的英文对应段落，明确标注“译文”和“英文来源”，不能仅因中文表述就断言作者原意。配对失效时先提示并停止这条双语请求；用户仍可通过明确的单份阅读操作解释当前文件。

请求只包含实际读取的材料，不承诺已经读取 PDF、图像或整篇论文。模型一般知识不能变成论文证据；联网补充沿用现有配置和来源标记，不新增自动搜索。打开资料、滚动、同步、手动保存摘录和恢复均不调用模型。

### 向后传递内容角色

中文内容不能继续使用现有通用“原文摘录／原句”标签。批注详情、列表、待处理返回、文献聚合、草稿材料、补充已有笔记的预览及保存正文必须传递译文身份；这些适配属于首版必要工作。

整理时分别展示译文摘录、可核对的英文对应段落、个人备注和 AI 解释。英文对应段落也只表示实际保存的来源文字，不自动获得出版方身份或科学审阅结论。译文与 AI 解释不得作为作者英文原句进入正式证据检索；涉及检索的保存出口应沿用学习内容隔离并补齐角色检查。

首版不凭这类配对文件补写论文来源笔记或升级 `x-ray` 深度；选择性整理限于现有允许的概念、方法或综合笔记与草稿流程，保留待审阅身份。角色传播未完成时，不开放译文的整理出口，不能先把它当普通原文写入。

源文件变化时保留历史选句、解释和个人备注；暂停旧定位及依赖旧对应关系的操作。中文单独修改同样使旧译文摘录需要复查；不能因为英文未变就把中文历史视为当前版本。旧批注保持原格式可读，不批量推断语言或补造配对凭据。
