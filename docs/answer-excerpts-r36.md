# R3.6：学习回答摘录

更新日期：2026-09-12。开发版本：`0.74.0`。本增量支持从已保存的资料阅读和主题学习回答中保留全文或片段，独立编辑个人备注，并回到准确回答节点。保存、浏览和版本核对均无需调用模型。

## 使用入口

1. 在资料阅读或主题学习的已完成回答中点击“保存回答摘录”。资料阅读还支持划选显示文字后点击“保存选中文字为学习摘录”。
2. 弹窗展示固定回答，可在原始 Markdown 文本框选择部分文字，或使用整条回答；个人备注单独填写。
3. 核对保存预览后点击“确认保存学习摘录”。更换选区或备注会使旧预览失效。
4. 保存后点击“在学习摘录中查看”。也可从原文摘录窗口的“学习回答摘录”、主题学习工具栏或命令“打开学习回答摘录（AI 内容）”进入。
5. 列表可搜索回答、主题、来源路径和备注。详情支持编辑备注、查看保存时的完整回答和版本，以及“回到回答节点”。

列表每页显示 25 条；单次最多扫描 500 个文件，依据文件大小限制总读取量为 32 MiB，每文件不超过 2 MiB。超限和损坏记录给出读取提示，不删除文件。

## 内容身份与保存结构

学习摘录保存到现有学习记录根下的 `wiki/qa/answer-excerpts/answer-<摘要>.md`，使用 `type: learning-answer-excerpt`、`evidence_basis: ai-answer`。不会迁移旧批注或更改原文摘录的格式。

- **AI 回答：** 保留完整回答快照、所选片段及原始 UTF-16 起止位置。保留原始 Markdown、换行及 Unicode 字符，禁止从字符代理对中间切开。
- **回答位置：** 资料阅读保留会话、节点、来源路径、实际记录的供应商与模型，以及来源、引用、网络补充和核对状态的摘要；主题学习额外固定路线、请求和教学规则版本。未记录的模型不会用当前配置补填。
- **个人备注：** 作为独立内容保存，修改备注不会改变 AI 回答。当前没有编辑 AI 正文的入口；未来人工修订应保留原回答并明确标记人工内容。
- **文件凭据：** 隐藏 JSON 保存完整快照和备注，正文使用长度足够的纯文本围栏，避免把回答中的脚本、HTML 或链接作为可执行内容渲染。

同一回答版本与选区对应固定文件名；重复保存、并发保存和重载后保存复用已有文件并保留已编辑备注。新回答版本或新选区形成不同摘录。

此处“版本一致”只表示与已保存的 AI 回答记录一致，**没有重新核验原文或科学结论**。阅读会话的 UI 和理解自评不改变回答身份；正文、引用、模型或核对状态变化会使旧保存预览和返回操作失效。

## 冲突、取消与证据范围

保存前只读核对记录，不初始化生成、任务恢复或原文加载；写入前再次核对。重复会话、缺失节点、演示／测试会话、未完成回答和不完整主题历史均不能作为新的学习摘录来源。保存已经提交后如果回答无法再次确认，保留历史文件并提示复查，不回滚删除。

备注写入通过 `Vault.process` 比较完整文件和文件身份。并发修改时保留草稿；“重新读取（保留草稿）”展示最新备注供对照，用户再次保存才提交。存在草稿时不能切换记录、导航或普通关闭；可以保存或放弃草稿。插件卸载会关闭窗口，未保存草稿不保证跨卸载恢复。

文件应通过摘录界面修改备注。直接编辑生成文件、改变可见 AI 正文、追加段落、改写凭据或改变路径，会使完整一致性检查失败；插件保留文件并阻止覆盖。损坏文件需在 Obsidian 文件列表中直接打开检查。本版没有自动修复或合并手工 Markdown 的功能。

新目录和内容类型均从通用词法检索、学习索引和正式知识检索中排除。正式知识读取额外检查文本中的类型标记，避免仅因移动目录就成为论文依据。原文摘录的补充、修订、撤销和完成标记仍使用 R3.4／R3.5 的原流程；学习回答摘录暂未接入这些写入及待处理动作。
