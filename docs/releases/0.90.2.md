# 0.90.2（受限试用）：双语悬停段落对照

双语阅读顶部改为「悬停段落对照」，复用双栏联动已有的结构配对。从任一栏悬停到可对应的正文段落，两栏高亮整段。默认关闭，已开启旧句子悬停的标签保留开启状态。此次暂停逐句匹配；悬停不调用模型、不改源文件、不滚动，也不干扰原生划选。

在现有 DeepMet 全文（216／216）和 Novae 摘段（3／3）中，纳入范围的正文段落均可双向定位。100% 是这两份样本的结构覆盖；没有可靠配对或无法唯一定位的段落仍跳过。[规则与验收](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.90.2/docs/bilingual-paragraph-hover.md)

类型检查、生产构建及双语、双栏定向回归通过。Windows 原生测试库核对了悬停、换行、换栏、不滚动、划选批注、开关恢复和失效清除；原有文件校验值一致。完整自动检查由发布流程执行，本地未运行含批量清理的旧全量入口。未重做完整宿主重启、其他平台原生桌面验收或独立科学、整篇翻译与教学审阅。既有 OpenCode mimo 新生成待额度恢复、偶发读取停顿及暂缓范围保持。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
