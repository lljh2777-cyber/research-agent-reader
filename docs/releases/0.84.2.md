# Research Agent Reader 0.84.2（受限试用）

发布日期：2026-10-12。本次在 `0.84.1` 基础上补齐文献阅读器的双栏设置与布局选择，继续保持受限试用身份。

## 主要更新

- **默认双栏模式**：设置中可选择「正文＋原始 PDF」「正文＋图片与图注」或「英文＋中文（已有双语资料）」，并将双语与图文／PDF 设置分别分组。
- **独立双语默认值**：新增双语滚动联动开关及英文栏宽设置，默认联动开启、两栏各占 50%。关闭联动后，仍可点击任一栏的单次同步按钮，以该栏位置对齐另一栏。
- **当前布局选择**：阅读器顶部可切换图文／PDF 与英文／中文布局；普通资料禁用不支持的双语选项，配对加载失败时保留普通阅读能力。
- **续读与旧设置兼容**：新文献采用默认值，已有文献优先沿用保存的布局、联动、栏宽与阅读位置；升级保留原有 PDF／图片默认值。设置搜索支持双语、英文、中文、联动与同步相关词。

操作说明见[双栏设置](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.84.2/docs/settings.md#文献阅读器双栏设置0842)和[双语阅读指引](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.84.2/docs/bilingual-reading-minimal.md#简短使用指引)，历史变更见[CHANGELOG](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.84.2/CHANGELOG.md)。

## 安装

需要 **Obsidian Desktop 1.11.4 或更新版本**。

1. 从此 Release 的 Assets 分别下载 `main.js`、`manifest.json`、`styles.css`。
2. 将三个文件放入 `<vault>/.obsidian/plugins/research-agent-reader/`。
3. 在「设置 → 社区插件」启用 **Research Agent Reader**。升级已有安装时，先禁用插件，替换三个文件，再重新启用。

也可在 BRAT 中添加 `https://github.com/lljh2777-cyber/research-agent-reader` 并选择最新 Release。标签为 `0.84.2`，与插件版本一致，不带 `v` 前缀。尚未上架 Obsidian 社区插件目录。可选依赖和数据发送边界见 [README](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.84.2/README.md)。
