# 0.89.4（受限试用）：批注质量复核与上下标保留

修复 CLI 批注引句丢失上下标的问题。例如，原文技术名后的上标文献号曾被拼成 `Xenium5`。现在证据文本保留上下标位置，模型引句按同一文本核对，保存后可显示原有格式；不把所有上标数字当作文献号，也不改变原文和历史来源凭据。

完成三篇论文、八个既有选区的第二遍模型辅助复核，逐项核对中英对应、数值与限定、关联和因果、背景扩展。未发现八条最终释义新增数值或因果错误；四条历史批注补充译文歧义、中文用词和文献号说明，原模型回答和回执保留。详见[独立质量复核记录](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.89.4/docs/annotation-independent-review.md)。

类型检查、生产构建及相关回归通过；三平台 CI、标签工作流、三个安装文件与来源证明按发布清单核验。本地未运行含批量清理的旧全量测试入口。

Windows 原生复验中，CodeBuddy 和 Qoder 的含上标选区完成生成、保存、回读和定位；八条旧答及两条新答逐一定位，最终 56 份记录和原始资料核对通过，设置与布局恢复。OpenCode mimo 的新生成受免费额度耗尽阻断，首次超时、复测取消均保留，没有保存或切换模型；其已有批注的质量复核与回读通过，不将新生成计为通过。本轮没有重做完整宿主重启。

这是限定选句的模型辅助复核，不等同于领域专家审阅，未认证整篇翻译、原图、研究设计或教学质量。偶发读取停顿仍未定位。主题学习保持预览，迁移、全文翻译、跨论文对照和主题资料辅助继续暂缓。

安装使用本 Release 的 `main.js`、`manifest.json`、`styles.css`。
