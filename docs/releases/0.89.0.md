# Research Agent Reader 0.89.0（受限试用）

发布日期：2026-10-18。批注 AI 支持手动刷新 CodeBuddy、Qoder CLI CN 与 OpenCode 的模型目录，并查询 Qoder CN 剩余额度。

- 「批注 AI」选择对应后端后点击刷新；模型采用 CLI 返回的准确 ID，保留已选和自定义 ID，查询失败不自动换模型。
- Qoder CN 分别显示套餐、附加及可用组织额度；取不到有效余额时显示未知，真实零余额仍显示 0，不从 Token／费用推算。
- 目录和额度只在插件内存保留；切换程序路径不复用旧结果，卸载停止查询。刷新不发送 AI 任务或 Vault 正文，沿用本机登录。

本机三个 CLI 目录查询及 Qoder CN 额度接口通过生产调用层核验，类型检查、构建与相关回归通过。模型目录不保证免费或实时可调用；OpenCode Step 免费 ID 当次仍未在目录中，旧选择保留。操作、接口和验收边界见[查询说明](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.89.0/docs/cli-model-discovery.md)。

Windows / Obsidian 测试库通过 30 项原生 DOM 检查，覆盖实际刷新、模型选择、额度显示、失效 ID 保留、路径变化与未知回退；临时设置副本验证未改写真实偏好。

需要 **Obsidian Desktop 1.11.4 或更新版本**。下载 `main.js`、`manifest.json`、`styles.css`，禁用插件后替换到 `<vault>/.obsidian/plugins/research-agent-reader/`，再启用。BRAT 可更新最新 Release，标签 `0.89.0` 不带 `v`。尚未上架社区插件目录。

本轮无新的 AI 批注生成、完整宿主重启或其他平台原生桌面验收。已有回答质量问题与独立科学／翻译／教学审阅继续保留，主题学习保持预览，暂缓阶段不恢复。
