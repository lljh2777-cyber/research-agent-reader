# 0.90.4（受限试用）· 双语联动对齐修复

Geneformer 的中英文图注在同一结构块中使用了相同的两个脚注，但先后顺序不同。旧版因此拒绝整篇的结构配对，改按全文阅读进度同步，把两栏停在了不同段落。

新版在每个结构块内核对脚注编号和出现次数，允许随语序调整脚注顺序。对应检查仍要求有效的翻译记录、匹配的英文版本及一致的段落和图片结构。对应检查通过后，两栏按结构块及块内位置同步。

Windows / Obsidian 1.15.0 测试库使用 Geneformer 的原始文件副本和 ITS Theme。旧版复现「Geneformer 架构与预训练」跳到英文前一段的问题。新版配对全部 486 个结构块。中文在左时，两栏的单次同步均定位到相应的架构与预训练小节，滚动联动也定位到对应的情境感知与批次整合小节。原文、译文和翻译记录的校验值一致。

类型检查、生产构建、双语和双栏定向回归通过。完整自动检查由发布流程执行。本次原生回归限于 Windows，未做完整宿主重启或模型生成。段落结构对应仍需结合原文核对译文语义，独立科学与教学审阅仍待完成。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
