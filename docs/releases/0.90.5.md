# 0.90.5（受限试用）· 双栏大纲

在双栏阅读器顶部点击「双栏大纲」，即可打开左侧标题目录。双语模式默认跟随最近操作的正文栏，也可手动切换「中文／English」。目录按标题层级显示，各处同名标题可以分别跳转，换栏后目录仍跟随所选语言。

点击标题以目录所属文档为基准。联动开启且有有效的对应标题时，两栏跳到相应小节；联动关闭或无对应标题时只移动该文档。Markdown＋PDF 使用 Markdown 的标题，跳转时 PDF 保持当前页和阅读位置。

Windows / Obsidian 1.15.0 测试库使用 ITS Theme 验证 Geneformer 正文和方法中的两个同名标题、语言跟随与手动切换、换栏后的双栏跳转，以及缺少配对时的单栏跳转。DeepMet 的 Markdown＋PDF 验证了联动开启时跳转目录仍保留 PDF 第 3 页和页内位置，并验证切换普通笔记和双栏标签时大纲随标签更新。中英文、翻译记录和 PDF 的校验值一致。

类型检查、生产构建及双语、双栏定向回归通过。原生验收限于 Windows 测试库，完整自动检查由发布流程执行。本次未调用模型或重做完整宿主重启，独立科学和教学审阅仍待完成。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
