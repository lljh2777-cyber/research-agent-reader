# 0.93.11（受限试用）· 从批注开始带读

在 Markdown 批注中选择“从这条批注开始带读”，Codex 会围绕选句和读者问题讲一个要点。Reader 从当前论文选取相关段落，逐字核对批注附带的引句，并在讲解后附上引用的原句。有双语配对时可返回中文原段。来源变动导致位置或引句无法核对时，Reader 会提示重新核对。

这一步在批注窗口中完成。支持新划选和已保存的 Markdown 批注。本次带读依据正文和图注，图像以及 PDF 摘录不在此次交接范围。段句匹配只验证出处，科学解释仍需对照原文判断。

测试库使用 Geneformer 论文验证了图 1a 的迁移学习问题。Codex 回答附带的 10 条引句均能在本地英文 Markdown 中逐字找到，返回按钮定位到原中文标签页的同一段，并保留了批注草稿。
