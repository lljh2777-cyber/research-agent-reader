# Research Agent Reader 0.87.0（受限试用）

发布日期：2026-10-12。批注新增 Qoder CLI CN 的 Qwen3.8-Flash。

## 更新

- 在「设置 → Research Agent Reader → 批注 AI」选择 Qoder CLI CN；使用本机 `qoderclicn`，支持常见安装位置检测和手动填写路径。
- 每次明确传入 `--model Qwen3.8-Flash`，名称取自本机模型列表；沿用本机登录，CLI 自动重试设为 0，不自动切换模型。
- 独立无头请求关闭工具、MCP、Hooks 与会话持久化；正文作为显式查询参数传入，复用超时、取消、模型核对和批注来源记录。费用汇总键与实际模型分开处理。
- 保存继续使用原生“保留”入口，中文缺少对应英文依据时仍在调用前停止；当前新 CLI 后端提供文字解释，浅层联网需关闭。

## 安装与边界

需要 Obsidian Desktop 1.11.4 或更新版本。分别下载 `main.js`、`manifest.json`、`styles.css`，禁用插件后替换三个文件再启用。标签与 manifest 一致，不带 `v`；尚未上架社区插件目录。

验收与失败记录见[本机 CLI 批注](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.87.0/docs/cli-annotation-backends.md)。两次标准输入请求超时，显式参数请求返回成功；修正费用汇总键误判后复用已生成回答完成保存及重载，没有重复请求。Windows 私有启动描述会保留本次提示词和上下文。完整宿主重启、其他平台原生桌面及独立科学／教学审阅仍未进行；主题学习保持预览。免费权益采用用户当前清单，费用缺失保持未知。

发布使用三平台 CI、标签重建、来源证明及三个独立安装文件。本地旧全量入口含批量清理而未运行，可选私有 MinerU 夹具未配置；迁移、完整翻译、跨论文对照和主题资料辅助继续暂缓。
