# 0.89.6（受限试用）：修复双栏正文行重叠

双栏正文随 Obsidian「设置 → 外观 → 字体大小」调整时，行高也按正文的实际字号计算。修复覆盖中英两栏和 Markdown＋PDF 的 Markdown 栏；PDF 继续使用独立缩放。

`0.89.5` 已使正文字号跟随设置，但正文仍可继承外层界面已经计算好的行高。在 ITS Theme 下，放大到 30 px 时行高仍是 19.5 px，相邻文字行因此重叠。现在直接在正文容器应用宿主的正文行高设置。

Windows / Obsidian 1.14.4 测试库：默认主题和 ITS Theme 下，中英正文在 16、24、30 px 三档的行高分别为 24、36、45 px，所测多行文本无重叠；Markdown＋PDF 在默认主题下的 Markdown 栏通过 16 和 30 px 两档验证。通过宿主设置方法即时调节并测量实际正文，未重开阅读页；结束后恢复原字号、主题和布局，源文件校验值一致。

类型检查、生产构建、双语及手动双栏相关回归通过。本地未运行含批量清理的旧全量入口，完整自动检查由发布流程执行。未重做模型生成、完整宿主重启或所有主题和平台的原生验收。OpenCode mimo 新生成待额度恢复、偶发读取停顿及独立审阅边界沿用 [0.89.4 重启验收](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.89.6/docs/cli-0894-restart-validation.md)。主题学习保持预览，迁移、全文翻译、跨论文对照与主题资料辅助继续暂缓。
