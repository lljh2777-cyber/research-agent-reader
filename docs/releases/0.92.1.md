# 0.92.1（受限试用）· 批注颜色含义

五种批注颜色默认表示黄色「主要结论」、蓝色「方法与设计」、绿色「数据与证据」、紫色「概念与定义」、红色「疑点与限制」。悬停面板底部的色块可查看当前含义。

在「设置 → Research Agent Reader → 批注 → 颜色含义」修改对应文字后保存，留空使用该色的默认值，也可以恢复全部默认值。这个设置应用于当前知识库的色块提示，已有批注仍按记录中的颜色显示。

类型检查、生产构建、设置搜索及批注相关回归通过。Windows / Obsidian 1.15.0 测试库验证实际悬停提示、内容保存、空白回退、插件重载后的自定义回读，以及恢复默认。提示出现时面板高度一致，已有批注文件经字节校验。键盘焦点提示和无障碍名称通过定向回归。

本轮没有模型调用、完整宿主重启或其他平台原生桌面验收。PDF 原页高亮、mimo 新生成、偶发读取停顿及独立科学／翻译／教学审阅沿用既有待办。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
