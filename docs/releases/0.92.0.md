# 0.92.0（受限试用）· 统一批注面板

划选正文后打开「批注」。在小窗里直接填写个人备注、展开 AI 解释或选择「收录摘录」，底部可选颜色，最后一起保存。重选相同范围即可继续修改。AI 解释支持渲染预览和文字编辑，人工修改后会标明，已有模型回执仍可追溯。

同一 Markdown 文件版本的同一选区使用同一条记录。单页和双栏可以回读同一处批注，两处重复文字分别保存，左右交换后仍归属原来的文件。取消收录会从摘录列表移出，批注仍可编辑。旧批注可以就地修改；同一处已有多条历史记录时可在面板切换，不自动合并冲突的内容。PDF 继续支持摘录和个人备注。

类型检查、生产构建、批注、摘录、双栏和 PDF 定向回归通过。Windows / Obsidian 1.15.0 测试库测得初始面板约 352 × 220 CSS 像素，验证底部色块、单页先标色后在换栏状态补写、编辑解释、收录、来源定位及插件重载回读。两处相同文字各保存一条，来源文件及既有批注的字节校验值一致。AI 面板验收使用模拟返回。未进行真实模型生成、完整宿主重启、其他平台原生验收或新的独立科学／翻译／教学审阅。PDF 原页高亮、mimo 新生成及偶发读取停顿沿用既有边界。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
