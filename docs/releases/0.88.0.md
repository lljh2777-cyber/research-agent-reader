# Research Agent Reader 0.88.0（受限试用）

发布日期：2026-10-13。OpenCode 批注接入 Step-5-Preview 与 mimo-v2.6-flash。

## 更新

- 在「设置 → Research Agent Reader → 批注 AI」选择 OpenCode，使用官方 OpenCode 配置并关闭浅层联网；模型列表增加两个用户指定候选。
- 模型准确 ID 为 `opencode/step-5-preview-free` 与 `opencode/mimo-v2.6-flash-free`，每次显式传入 `--model`。保留已有模型，不因升级自动切换。
- 官方离线文字批注使用共用进程层、独立工作目录及会话，隔离配置中的 MCP 为空，并关闭外部插件、自动升级和共享。工具需要权限的请求由非交互 CLI 自动拒绝，插件拒绝交付含工具调用的结果。联网与 CC Switch 沿用已有路径。
- 完整结果、来源、取消和超时检查继续有效；实际模型未在 JSON 事件中报告时明确显示未知，用量与费用缺失保持未知。当前文字批注使用模型默认推理参数。
- Windows 上将未使用的标准输入连接系统空设备；配置缓存按宿主进程复用，每次工作目录和会话保持独立。提示词明确只解释已提供文字，原文依据和一般知识分段标注。

## 安装与边界

需要 Obsidian Desktop 1.11.4 或更新版本。分别下载 `main.js`、`manifest.json`、`styles.css`，禁用插件后替换三个文件再启用。标签与 manifest 一致，不带 `v`；尚未上架社区插件目录。

OpenCode 会保留本机会话及提供的上下文，插件不清理 CLI 历史或私有临时目录。免费权益与限额以当前账号为准。

两个模型在 Windows 原生测试库完成生成、原生“保留”保存、来源不变和插件重载，额外读取本机会话确认准确模型 ID。先前超时、免费层 403、上游 401、被拒工具调用及步骤限制输出均留档；最终请求成功，没有自动换模型。验收与已知问题见[本机 CLI 批注](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.88.0/docs/cli-annotation-backends.md)。Step 回答仍把组间高低比较扩写为连续趋势，部分一般知识表述过宽；工程验收不等于科学审阅。完整宿主重启、其他平台原生桌面及独立科学／教学审阅仍未进行；主题学习保持预览。

发布使用三平台 CI、标签重建、来源证明及三个独立安装文件。本地旧全量入口含批量清理而未运行，可选私有 MinerU 夹具未配置；迁移、完整翻译、跨论文对照和主题资料辅助继续暂缓。
