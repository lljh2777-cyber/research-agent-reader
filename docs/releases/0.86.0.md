# Research Agent Reader 0.86.0（受限试用）

发布日期：2026-10-12。批注新增 CodeBuddy 的 Step-5-Preview。

## 更新

- 在「设置 → Research Agent Reader → 批注 AI」选择 CodeBuddy，界面显示 Step-5-Preview，进程明确传入 `--model step-5-preview`。支持自动检测、手动路径和自定义模型 ID，沿用本机 CLI 登录。
- 插件直接启动独立的无头请求，通过 UTF-8 标准输入发送选句与语境；关闭内置工具、MCP、Hooks、后台任务及会话持久化，单次生成受超时和取消控制。官方 npm 安装需要可用的独立 Node.js。
- 只有完整成功结果可以保存。模型身份不符、失败、截断或联网设置尚未关闭时阻止交付；批注保留请求模型、CLI 报告的模型及其提供的用量／费用字段，未报告的字段保持未知。
- 英文依据、译文、个人备注与模型一般知识继续区分；中文缺少对应英文时仍在模型调用前停止。当前 CodeBuddy 批注提供文字解释，联网能力尚未开放。

## 安装

需要 Obsidian Desktop 1.11.4 或更新版本。从 Assets 分别下载 `main.js`、`manifest.json`、`styles.css`，放入 `<vault>/.obsidian/plugins/research-agent-reader/`，禁用插件后替换三个文件再启用。标签与 manifest 版本一致，不带 `v`；尚未上架社区插件目录。

## 验证与边界

- 类型检查、生产构建、共用层／CodeBuddy 定向测试及既有批注、来源、联网、双语和设置回归通过。
- Windows 测试库核对准确模型选择、原生解释与保留按钮、模型／用量保存、来源不变和插件重载恢复。前两次真实生成被工具面检查拦下，Windows 启动长度失败及驱动错误保留；最终模型身份和空工具列表通过。
- 固定样本中，模型仍将高低比较扩写为连续趋势，需人工复核；不宣称独立科学内容质量通过。

验收详情见[本机 CLI 批注](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.86.0/docs/cli-annotation-backends.md)。本轮不重新验收整篇翻译、全部模型回答质量、完整宿主重启或其他平台的原生桌面。主题学习保持预览，独立科学／教学审阅仍待完成，迁移、完整翻译、跨论文对照和主题资料辅助继续暂缓。

模型的当前免费权益由用户提供，插件不承诺永久免费或自动切换模型。发布安装文件采用标签工作流构建及来源证明；三平台 CI 和公开 Release 核验后才公开发布。本地旧全量入口含批量清理而未执行，可选私有 MinerU 夹具未配置。
