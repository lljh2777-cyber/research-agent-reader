# 0.89.2（受限试用）：中英合句与批注引句修复

三篇论文、八个选区的[批注质量抽查](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.89.2/docs/cli-annotation-quality-samples.md)发现并修复三处问题：

- 中文合句可以对应最多两句连续英文，避免正确对应因两种语言句号数量不同而被拒绝。
- 明确英文引句只能复制实际 `evidence`，避免 CodeBuddy 将中文选区当作英文引用；逐字核验保持。
- 将 `markedly different` 的释义收紧为“明显差异”，避免在没有明确统计显著性依据时写成“显著差异”。

八个选区涉及 CodeBuddy Step-5-Preview、Qoder CN Qwen3.8-Flash 与 OpenCode mimo；三个问题选区修复后定向复验通过。插件重载后 52 份新旧记录和回执一致，八处最终来源定位通过，原始资料与用户设置保持。首次失败和旧答案保留。

类型检查、生产构建及相关回归通过；发布按三平台 CI、标签工作流、三个安装文件和来源证明核验执行。没有在本地运行含批量清理的旧全量入口。

中英候选仍需人工核对，短释义不代表独立科学、全文翻译或教学审阅通过。后两篇只制作测试节选译文。准备阶段的间歇性来源读取停顿保留为未定位问题；没有宣称修复完成后的完整宿主重启通过。OpenCode Step 未复验。主题学习保持预览，迁移、完整翻译、跨论文对照与主题资料辅助继续暂缓。

安装使用本 Release 的 `main.js`、`manifest.json`、`styles.css`。
