# 0.89.5（受限试用）：双栏正文字号

双栏 Markdown 正文现在即时跟随 Obsidian「设置 → 外观 → 字体大小」，无需重开阅读标签。修复覆盖英文、中文两栏及 Markdown＋PDF 的 Markdown 栏。工具栏继续使用界面字号；标题遵循主题样式，PDF 沿用本栏缩放。

原因：双栏正文渲染在插件自己的容器中，未应用 Obsidian 的正文变量 `--font-text-size`，因此继承了界面字号。现在将该变量应用到共用的 Markdown 正文容器。

Windows / Obsidian 1.14.4 测试库：默认主题和 ITS Theme 下，旧版的设置从 14 调到 24，双语正文仍为 15 px；新版的两栏正文均从 14 px 调到 24 px，工具栏字号未变。Markdown＋PDF 在默认主题下的 Markdown 栏也通过相同检查。检查由 CLI 调用宿主字号设置并读取实际渲染尺寸，未覆盖所有主题或平台的原生界面。

类型检查、生产构建、双语及手动双栏相关回归通过。本地未运行含批量清理的旧全量入口；完整自动检查由发布流程执行。本次没有模型生成或完整宿主重启；既有批注复核、OpenCode mimo 新生成待额度恢复、偶发读取停顿和独立审阅边界沿用 [0.89.4 重启验收](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.89.5/docs/cli-0894-restart-validation.md)。主题学习保持预览，迁移、全文翻译、跨论文对照与主题资料辅助继续暂缓。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
