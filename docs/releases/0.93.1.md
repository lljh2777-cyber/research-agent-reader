# 0.93.1（受限试用）· 双栏滚动与续读

外部论文的双栏现在使用标签页的可见高度。顺着中文滚动时，英文可跟到对应段落。关闭联动后，可以把英文留在原处，单独阅读中文。

在 Windows 的 Obsidian 测试库中，用实际剪藏论文打开独立阅读窗口，将中文滚到正文中段，确认两栏处在同一配对段落。关闭联动后继续滚动中文，关闭并重开论文，英文与中文分别恢复到各自停留的段落，联动保持关闭。测试沿用了本地原文，没有调用模型。

本版沿用 [0.93.0 的功能、适用范围与试用边界](0.93.0.md)。安装文件为 `main.js`、`manifest.json` 和 `styles.css`。
