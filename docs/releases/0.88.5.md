# Research Agent Reader 0.88.5（受限试用）

发布日期：2026-10-17。修复选中含链接或脚注的段落后无法批注的问题。

- 支持常见 Markdown 链接、内部链接、引用式链接及脚注所在段落的批注与摘录，保存准确的原文源码位置。
- 部分链接文字会扩展为完整链接并提示；批注独立保存，原文链接不改写。单次最多 600 个显示字符、2400 个源码字符，继续限定同段选区。
- 双语记录重建对应来源栏的选区，保留交换后的语言身份和栏内滚动；原文、译文、个人备注与 AI 内容的来源规则保持。

类型检查、生产构建、五组新增回归与相关批注／摘录／双语／双栏检查通过。Windows / Obsidian `1.14.4` 测试库核对实际含链接划选、保存按钮、重复段落、脚注、部分链接、准确返回、交换和插件重载；七份新记录读回，来源与设置保持。初始预览及测试驱动问题留档，详情见[功能与验收](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.88.5/docs/linked-annotations.md)。原生 DOM 验证不代表物理鼠标完整自动化。

发布核对三平台 CI、标签构建、来源证明及三个独立安装文件。需要 **Obsidian Desktop 1.11.4 或更新版本**；从 Assets 下载 `main.js`、`manifest.json`、`styles.css`，禁用插件后替换到 `<vault>/.obsidian/plugins/research-agent-reader/`，再启用。BRAT 用户可更新最新 Release，标签 `0.88.5` 不带 `v`。尚未上架社区插件目录。

特殊 Markdown 渲染无法唯一定位时仍会停止并提示重选。本轮无新真实模型调用、完整宿主重启或其他平台原生桌面验收，独立科学／翻译／教学审阅仍待完成。主题学习保持预览，迁移、完整翻译、跨论文对照和资料辅助继续暂缓。
