# 0.90.0（受限试用）：双语悬停句对照

双语阅读顶部新增「悬停句对照」，默认关闭。开启后，从中英任一栏悬停到可对应的正文句，两侧同时以淡琥珀色高亮整句。高亮与原生鼠标选区独立，拖选时让位，不驱动滚动。顶部显示可对照的句对数。

首版不猜测多句段落中的句序。已有测试样本中，DeepMet 自动命中 8 对（约 1%），Novae 摘段自动命中 0 对；为 Novae 测试副本提供两条明确记录后，命中 2 对。逐对核对未见错配，结果不代表翻译审阅。实际 Obsidian 验收覆盖双向、放大换行、换栏、拖选批注、不滚动、开关恢复和失效回退。详见[规则与验收](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.90.0/docs/bilingual-sentence-hover.md)。

类型检查、生产构建、双语及手动双栏定向回归通过。完整自动检查由发布流程执行；本地未运行含批量清理的旧全量入口。未调用模型，未重做完整宿主重启或 macOS、Linux 原生桌面验收。OpenCode mimo 新生成待额度恢复、偶发读取停顿及独立审阅边界沿用 [0.89.4 重启验收](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.90.0/docs/cli-0894-restart-validation.md)。主题学习保持预览，迁移、全文翻译、跨论文对照和主题资料辅助继续暂缓。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
