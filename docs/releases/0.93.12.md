# 0.93.12（受限试用）· 单篇论文阅读空间

保存 Markdown 批注时，批注留在原段。选择“从这条批注开始带读”后，Reader 保存当前批注，在这篇论文的阅读空间中创建 Codex 追问分支。已有主线节点引用选段时，分支挂到该节点。首次阅读也可以直接从批注开始，稍后再启动全文主线。

再次从同一条批注进入，会打开原分支的最近一轮。也可以从阅读空间的导图打开分支，继续追问，或点“返回中文原段”。正文版本和返回位置分别核对；原文变化后，先保留历史记录供核对。旧版手动建立的多个会话仍可从历史列表查看。跨论文关联和 PDF 选区接入导图留待以后处理。

测试库使用 Geneformer 论文，从中文选段发起真实 Codex 讲解，重载后在同一分支继续追问，再跳回中文原段。
