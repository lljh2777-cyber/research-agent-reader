# 0.94.2 受限试用 · 论文阅读与续读

- 文献库逐条核对摘录。异常提示包含批注文档和记录标识，其他论文仍可打开。剪藏译文的来源核对同时使用中英文版本。
- 重开论文后，正文会定位到上次选中的主线或分支回答。桌面端保存阅读进度时先完整写入新配置，再替换原文件。已有配置无法解析时会保留现场。
- 论文首轮规划被截断时，Reader 在原节点用同一模型请求较短的完整路线。再次截断时显示原因，可在本轮重试。
- 正文回答中的配图引用可直接点击。能从原图说明核对图号时显示图号，缺少可核对编号时显示「原图」。

桌面试用覆盖 Perturb-seq 双语剪藏论文、已有四节点会话和独立的截断恢复会话。图片按整张主图定位，分面仍需在图内辨认。其他格式、模型和论文的教学质量需另行验证。
