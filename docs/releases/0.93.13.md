# 0.93.13（受限试用）· 在原段旁讨论论文

打开有中英配对正文的论文，划选一句话，选择「写批注」保存个人备注，或选择「开分支」向 Codex 提问。回答和原文依据在该段下方展开。「继续追问」沿用当前分支，「另开子分支」从点选的那一轮回答开始新的讨论。

「收起，回原句」收拢讨论并定位原选区。「本文思路」可切换本篇的讨论。关闭论文后重新打开，会恢复此前展开的分支。批注仍使用原有批注笔记，讨论存入该论文的阅读会话。原文发生变化时，需要重新核对位置。

测试库使用 Geneformer 论文，核对了中文选句、普通批注、真实 Codex 回答、分支层级和重开续读。本次交互适用于中英对照的 Markdown 正文。
