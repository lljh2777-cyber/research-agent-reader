# 0.90.3（受限试用）：双栏顶部笔记属性

双栏阅读顶部显示文章标题。点击「显示属性」展开当前笔记已有的属性，如作者、来源、日期、描述与标签；收起时保留标题。双语阅读可用「中文／English」在两份笔记的属性间切换，选择独立于左右栏顺序和滚动联动。Markdown＋PDF 显示 Markdown 笔记的属性。

默认收起详情；手动双语配对首次按入口文件选语言。工作区记住语言和展开状态。标题优先使用所选笔记已有的标题字段，无标题时使用开头的一级标题或文件名。属性只读，不改写 YAML 或补译字段，详细区可以独立滚动。

在 Windows / Obsidian 1.15.0 测试库临时加载 ITS Theme，使用已有双语样本核对中英文标题、原有属性、来源链接、展开／收起、换栏、阅读位置和状态恢复。纯进度联动的双语组合及 Markdown＋PDF 属性也通过实测。原工作区与外观恢复，原有文件校验值一致。

类型检查、生产构建及双语、双栏定向回归通过。完整自动检查由发布流程执行，本地未运行含批量清理的旧全量入口。未调用模型，未重做完整宿主重启或其他平台原生桌面验收。悬停仍按段落对照；既有偶发读取停顿、独立科学／教学审阅及暂缓范围沿用。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
