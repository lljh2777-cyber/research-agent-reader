# 0.90.6（受限试用）· 双栏大纲外观

双栏大纲顶部可直接点击「跟随」「中文」或「English」，跟随模式显示当前语言。标题行更紧凑，子标题通过缩进和细导线分层，长标题自动换行，目录区使用细滚动条。键盘切换和跳转时可看到焦点。

在 Windows / Obsidian 1.15.0 测试库使用 ITS Theme 检查了浅色与深色外观。Geneformer 复验了同名标题、语言跟随与手动切换、换栏和无配对跳转。DeepMet 的 Markdown＋PDF 复验了点击目录时 PDF 保持第 3 页和原位置。原文、译文、翻译记录与 PDF 校验值一致。

类型检查、生产构建及双语、双栏定向回归通过。原生验收限于 Windows 测试库，完整自动检查由发布流程执行。独立科学和教学审阅仍待完成。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
