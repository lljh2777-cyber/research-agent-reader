# 0.90.7（受限试用）· 双栏大纲折叠

每份双栏大纲首次只显示一级标题。点击有子标题的条目旁的箭头，可以逐层展开或折叠。点击标题文字仍可跳转正文。中英文各自记住当前展开状态，重新展开父章节可恢复已展开的子章节。

Windows / Obsidian 1.15.0 测试库用 Geneformer 核对了一级目录默认状态、逐层折叠、中英文状态恢复、同名标题定位、换栏和无配对跳转。Markdown＋PDF 的折叠与标题定位通过复验。类型检查、生产构建和双语、双栏定向回归均通过。

原生验收限于 Windows 测试库，三平台自动检查由发布流程执行。独立科学和教学审阅仍待完成。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
