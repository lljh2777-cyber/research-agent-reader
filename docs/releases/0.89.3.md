# 0.89.3（受限试用）：批注编辑与来源路径查找修复

修复日常批注中的两个问题：

- 取消或保存后再次编辑，旧快捷键处理器可能重复提交先前草稿。编辑器现在只提交当前内容，保存期间阻止重复提交；保存组合键接入宿主快捷键作用域，退出编辑时释放。
- 文献库按原文路径搜索时，可能漏掉尚未关联论文的批注。现在搜索包含批注的实际来源路径，保留原有待关联状态。

Windows 原生核对 DeepMet 全文的个人批注与摘录，以及 CodeBuddy、Qoder、OpenCode 三个后端已有解释的查看、取消修改、切换论文后回读与来源定位。新增两份记录，原有 52 份批注、回执和来源保持；设置与布局恢复。详见[日常闭环验收](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.89.3/docs/annotation-daily-workflow.md)。

类型检查、构建及相关回归通过；三平台 CI、标签工作流、三个安装文件与来源证明按发布清单核验。本地未运行含批量清理的旧全量入口。

本轮没有新 AI 生成，也不代表独立科学、翻译或教学审阅通过。此前偶发读取停顿仍未定位。主题学习保持预览，暂缓范围保持。

安装使用本 Release 的 `main.js`、`manifest.json`、`styles.css`。
