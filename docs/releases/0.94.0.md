# 0.94.0 受限试用 · 论文按需补读

在论文页面顶部选择已验证的模型 API。原段批注、展开解释、全文带读和已有分支的续问由 Reader 调用所选 API。旧回答保留生成时的模型、引文和分叉位置。

简短释义读取选句、所在段和已核对的对应英文。展开解释和带读先向模型提供一批本文材料。模型可以直接回答，或在同一轮请求具体段落、方法、图表和图注。Reader 记录每批取回的位置、实际提供的文字范围与摘要值、图片 ID 和最终引用。最多补读三批。证据缺失时显示缺口，连接错误可以在原节点重试。用户可在批注中选择思考强度、速度和联网选项。

Geneformer 的桌面试用使用 gpt-6.2-sol。关于下游权重用途的问题仅凭图注作答。追问图 1a 是否支持准确性时，模型看完设计段后两次请求新材料，并引用图注和报告 ROC AUC 的结果段。重开测试库后回到新增回答，返回主线可定位原分叉点。模型调用和 CLI 启动均在测试边界记录。

图像观察受接口视觉能力与本文资源可用性限制。图注、文字结果和实际传入的图像分别记录。上述试用覆盖指定论文与模型，其他论文的教学质量及科学准确性仍需独立审阅。
