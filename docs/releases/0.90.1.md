# 0.90.1（受限试用）：提高双语悬停句对照覆盖率

「悬停句对照」复用双栏联动已有的段落对应，开启时在本机为多句段落建立句对索引。只有线索足够且无冲突的一对一句子才高亮；遇到句序冲突、合拆句或不完整边界时跳过。开关默认关闭，悬停不滚动、不干扰原生划选、不写原文或配对记录，也不调用模型。

现有 DeepMet 全文从 8 对增至 159 对（本版纳入的 576 个英文完整句和 584 个中文完整句中，约 28% 和 27%）；Novae 摘段从 0 对增至 2 对。逐对核对首轮结果后排除了图注续段、断句片段和拆句误亮，保留的两份样本句对未发现错配。详细分母、样本限制与原生验收见[匹配规则与验收](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.90.1/docs/bilingual-sentence-hover.md)。

类型检查、生产构建、双语及手动双栏回归通过。Windows 原生验收覆盖双向高亮、换栏、放大换行、划选批注与对侧不滚动；原样本校验值一致。完整自动检查由发布流程执行；本地未运行含批量清理的旧全量入口。未重做完整宿主重启、其他平台原生桌面验收或独立科学、整篇翻译和教学审阅。既有 OpenCode mimo 新生成待额度恢复、偶发读取停顿及暂缓功能范围保持。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
