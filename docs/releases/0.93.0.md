# 0.93.0（受限试用）· 直接读剪藏论文

在「设置 → Research Agent Reader → 文献阅读器」指定 Paper Clipper 的输出目录。在文献库中按标题或 DOI 找到论文，打开英文原文和本地配图。译文生成后从同一条目打开双栏。可靠配对的段落可以联动，用户可以随时关闭。阅读位置保存在当前知识库的插件数据里，批注和摘录保存在知识库笔记中。

首页优先展示本周阅读与上次阅读位置。「查知识点」先找个人读过、标过或问过的片段，也能检索库内笔记，包括 R 和 Linux。需要综合回答时，可主动选择库内文献问答并回到引文。

批注支持简短释义、自由提问和按需展开的上下文解释。论文带读按研究问题、方法、关键图表和结论边界组织讲解。可以展开思维导图，从选中概念开始主题学习，或在论文详情中打开相关代码笔记。

代码练习执行、单篇带读记录导出、跨论文综合写页和独立待处理中心已移除。旧学习记录及笔记可以继续阅读。「需处理」位于文献库，手动体检和 Wiki 的 OKF 导出位于「数据与诊断 → 维护与导出」。

Windows 上使用 Obsidian 实测外部目录发现、英中文正文与图片、选取中文、首页阅读记录、关键词检索和返回英文段落。回归检查覆盖来源改名、重复身份、双语批注、主题草稿及带读路线。本次未向真实模型发送论文内容，生成答案质量及 macOS、Linux 的原生 Obsidian 操作仍待使用反馈。缺少译文时可读英文，无法核对段落对应时可独立滚动双栏。

安装文件为 `main.js`、`manifest.json` 和 `styles.css`。
