# 0.91.0（受限试用）· 颜色批注

Markdown 批注新增黄、绿、蓝、紫、红五种颜色。选择文字后点击「批注 → 颜色标注」，可以只保存颜色，也可以附加文字；已有批注可在「修改」中改色或取消颜色。手动批注与 AI 解释保留页同样可以选择颜色。

支持普通 Markdown 阅读和中英文双栏，Markdown＋PDF 只标记 Markdown 一侧。颜色随实际来源文件保存，换栏后保持；原文、链接、上下标、AI 解释及回执保持。颜色记录仍存放在 `wiki/annotations/`，不调用模型，也不表示证据核验通过。

类型检查、生产构建及相关定向回归通过。Windows / Obsidian 1.15.0 测试库核对五色、文字与颜色组合、改色与取消、来源定位、插件重载恢复及浅深色显示；原有 58 个批注文件、插件设置和测试源文件保持，原布局已恢复。三平台自动检查由发布流程执行。

检测到另一个 Obsidian 窗口，本轮未执行完整宿主退出重启。PDF 原页高亮、mimo 新生成及独立科学／翻译／教学审阅仍待后续安排；偶发读取停顿尚未定位。详细范围和验收见[颜色批注说明](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.91.0/docs/annotation-colors.md)。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
