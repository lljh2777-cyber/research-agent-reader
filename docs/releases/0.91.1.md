# 0.91.1（受限试用）· 修复单页译文批注

单独打开 `paper.zh-CN.md` 后，可以直接划选文字，保存手动批注、颜色或摘录。过去，这些操作也会触发旧双语阅读器的 `Clippings/` 目录限制。批注保存到 `wiki/annotations/`，来源定位使用当前译文路径和选区。

同目录的 `paper.md`、`paper.zh-CN.md` 和 `translation.json` 经文件名、源版本和段落结构核对后，单页译文可沿用双栏的 AI 对照解释和来源凭据。缺少有效配对时，手动批注、颜色和摘录仍可使用；AI 对照在调用模型前提示核对英文对应段落。

Windows 的 CRLF 文件从摘录返回时在阅读视图恢复可唯一匹配的选区，避免打开编辑器导致宿主保存换行转换。无法在阅读视图唯一定位的选区会提示。编辑器划选仍按原始文件的字符位置记录。

类型检查、生产构建及批注、双语、双栏、摘录定向回归通过。Windows / Obsidian 1.15.0 测试库用报告中的论文选区复现旧版错误，修复版核对标色和备注、单页与双栏回读、无配对译文的手动批注、摘录回跳和插件重载。首次回跳发现宿主编辑器转换换行，恢复合成夹具后以最终实现复验，论文副本、测试来源、已有记录和设置的校验值一致。测试库布局已恢复。

本次验证了 AI 对照来源与缺少凭据时的拦截。真实模型生成、完整宿主重启、macOS／Linux 原生桌面及独立科学／翻译／教学审阅未重做。PDF 原页高亮、mimo 新生成和偶发读取停顿沿用既有待办。

安装使用本 Release 的 `main.js`、`manifest.json` 和 `styles.css`。
