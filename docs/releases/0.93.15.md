# 0.93.15（受限试用）· 从带读结论查看原文证据

在中英对照页点「AI 带读全文」，或在「本文思路」中打开全文带读。主线按论文的论证顺序推进，一轮讲一个结论。打开结论可读讲解，也可以点其下的依据核对英文原句、段落或图表。正文明确指向某个分图时，入口显示分图编号并打开原图。现有译文对应关系可用时，结论显示在中文证据段下。

在结论或证据旁点「从这轮提问」，问题挂到该轮。用「回到主线」返回分叉处，查看已有的下一轮或继续生成。由划选原句发起的讨论仍挂在原句下。再次打开论文，Reader 记住已选轮次。

证据跳转按照本轮保存的引用与当前英文正文逐字定位。只有段落证据时可打开整段；无法核对的位置不生成快捷入口。分图共用整图时打开整图；链接到图表不表示模型已单独核验所有分图。

测试库使用 Geneformer 论文和真实 Codex 检查主线、图 1、原文、从结论追问、返回后推进，以及关闭重开后恢复同一轮。其余论文版式依赖各自 Markdown 的结构和配对质量。
