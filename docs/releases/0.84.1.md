# Research Agent Reader 0.84.1（受限试用）

发布日期：2026-10-12。本次汇总上一个公开版本 `0.31.0` 之后的开发交付，面向桌面 Obsidian 的论文阅读、对话、思维导图与知识沉淀。主题学习继续保持预览，独立科学／教学审阅仍待完成。

## 主要更新

- **已有双语 Markdown 对照阅读**：同一标签左英文、右中文，滚动联动可开关；两侧都有单次同步按钮，以点击所在栏的位置对齐另一栏。批注、摘录、返回定位和续读保留语言、配对与版本信息。见[使用说明](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.84.1/docs/bilingual-reading-minimal.md)。
- **双语 AI 批注来源收紧**：仅使用已复核的当前配对块，明确区分中文译文、英文论文依据、模型一般知识与解释性推断；明确截断的输出不能保存为解释。四个固定选句的最后一轮真实回答通过开发者定向核对，历轮错误、失败和用量仍留存。见[真实 AI 验收记录](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.84.1/docs/bilingual-ai-acceptance.md)。
- **论文阅读与学习闭环**：文献详情关联原文、阅读会话和主要笔记；主线讲解、支线追问、证据返回、导图和学习导出接通。修复连续证据引用丢失，并保留会话与产物的恢复记录。
- **无资料主题学习预览**：保存学习目标，确认路线后逐单元讲解与追问，手动标记理解状态，预览并导出学习记录；模型一般知识保留独立身份。修复路线生成的字段约定缺失。
- **文献与知识整理**：统一添加文献、书目查询、人工条目、本地 PDF 和可用全文获取入口，按所选来源继续转换与初始笔记。原文／学习摘录、个人备注、人工修订、待处理记录、已有笔记补充与新知识页草稿支持预览、冲突保护和恢复；AI 学习内容与正式论文证据分开管理。

完整开发历史见[CHANGELOG](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.84.1/CHANGELOG.md)。

## 安装

需要 **Obsidian Desktop 1.11.4 或更新版本**。

1. 从此 Release 的 Assets 分别下载 `main.js`、`manifest.json`、`styles.css`。
2. 将三个文件放入 `<vault>/.obsidian/plugins/research-agent-reader/`。
3. 在 Obsidian 的「设置 → 社区插件」启用 **Research Agent Reader**。升级已有安装时，先禁用插件，替换这三个文件，再重新启用。

也可在 BRAT 中添加 `https://github.com/lljh2777-cyber/research-agent-reader` 并选择最新 Release。标签为 `0.84.1`，与插件版本一致，不带 `v` 前缀。尚未上架 Obsidian 社区插件目录。

基础阅读与本地批注无需模型账户；模型、联网查询、MinerU 和外部 CLI 按需配置。具体依赖与数据发送边界见 [README](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.84.1/README.md)。
