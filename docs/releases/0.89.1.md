# Research Agent Reader 0.89.1（受限试用）

发布日期：2026-10-18。本机 CLI 批注收紧上下文扩展和未经核对的图示推断。

- 英文只提供选区所在句；中文先定位最少候选英文句，再通过独立调用生成释义，最终输入不含整段和邻句背景。
- 保留引句中的指代；不从图号补出图中内容，不把候选句定位当作译文准确或无歧义的结论。新增限定检查仍不能替代语义审阅。
- 两步使用同一所选模型，共享总超时和取消状态，分别保留回执；中文调用可能增加时间与用量。失败停止，不自动重试、换模型或扩大上下文，旧批注保持。

CodeBuddy、Qoder 与 mimo 的三份含链接选区通过实际刷新选模、生成、保存、回读和来源定位，共五次 CLI 调用；正常完整宿主重启后 43 份新旧记录与回执一致，模型及布局恢复。Qoder 额度显示、未知回退和刷新恢复通过。类型检查、生产构建与相关回归通过；首次重启的插件启用准备问题与修正过程保留在验收记录中。

实现与验收边界见[证据范围说明](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.89.1/docs/cli-evidence-boundary.md)。OpenCode Step 免费 ID 此前不可用，本轮验证使用 mimo；独立科学／翻译／教学审阅仍待完成，主题学习保持预览，暂缓阶段不恢复。

需要 **Obsidian Desktop 1.11.4 或更新版本**。下载 `main.js`、`manifest.json`、`styles.css`，禁用插件后替换到 `<vault>/.obsidian/plugins/research-agent-reader/`，再启用。BRAT 可更新最新 Release，标签 `0.89.1` 不带 `v`。尚未上架社区插件目录。
