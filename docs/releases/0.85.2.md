# Research Agent Reader 0.85.2（受限试用）

发布日期：2026-10-12。本次为手动双栏增加交换位置按钮。

## 更新

- 两份文件名之间的「交换左右位置」图标让标题和内容一起换位，可左中文／右英文或左 PDF／右 Markdown；再次点击换回。
- 交换保留文件语言、批注来源、同步对应、各文档宽度与阅读位置，PDF 保留页码与缩放。显示顺序随阅读状态保存，旧状态保持原顺序。
- 换位后的更换文件继续选择该文档角色，分隔线拖动和方向键按视觉左右方向工作。修正交换过程中临时栏宽重算造成的位置跳动。

操作与验收记录见[手动双栏阅读](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.85.2/docs/manual-split-reading.md)。交换只改变显示位置，不重新分配英文、译文或 PDF 证据。

## 安装

需要 **Obsidian Desktop 1.11.4 或更新版本**。从 Assets 分别下载 `main.js`、`manifest.json`、`styles.css`，放入 `<vault>/.obsidian/plugins/research-agent-reader/`，禁用插件后替换三个文件，再启用。BRAT 用户可更新到最新 Release。标签 `0.85.2` 与 manifest 一致，不带 `v`；尚未上架社区插件目录。

## 验证与边界

- 类型检查、生产构建、三组交换回归以及目录树、手动配对、双语、PDF 摘录、批注和普通 Markdown 定向检查通过。发布流程核对三平台 CI、标签重新构建、来源证明与三个独立安装文件。
- Windows / Obsidian `1.14.4` 测试库核对中间按钮、换位与位置保留、重复交换、分隔线键盘方向、中文侧同步、换位后的更换文件／取消、两侧原生划选摘录、PDF 第 3 页与 120% 缩放、两种模式插件重载恢复。来源经哈希确认未改写，原工作区恢复。DOM 事件验证不代表物理鼠标完整自动化；初始位置失败及修复、测试侧栏和驱动失败记录保留。
- 本轮没有新真实 AI 请求、完整宿主重启、独立翻译／科学／教学审阅或 macOS／Linux 原生桌面验收。本地旧全量入口含批量清理而未运行，完整公开检查由 CI 执行，可选私有 MinerU 夹具未配置。
- 未确认对应英文时仍在中文 AI 对照调用前停止；手动批注和摘录可保存。主题学习保持预览，不恢复完整翻译、迁移、跨论文对照或主题资料辅助阶段。
