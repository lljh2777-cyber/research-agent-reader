# Research Agent Reader 0.85.0（受限试用）

发布日期：2026-10-12。本次将双栏阅读改为由用户手动选择文件，不再按固定目录自动接管 Markdown。

## 主要更新

- **从菜单选择打开方式**：右键当前知识库任意 Markdown／PDF，或从内容页右上角进入「选择阅读方式…」，先选 Markdown＋PDF 或英文＋中文，再选择另一份文件。不限制目录与文件名；双语模式明确当前文件作为英文还是中文。
- **同一标签的拆分阅读**：顶部显示两份文件名，点击可更换文件，支持退出双栏、拖动分隔线、分别批注与单次同步、联动开关和续读。可同时打开多个双栏标签。
- **手动 PDF 阅读**：无需转换包即可配对 Markdown 与 PDF，支持分页、40%–400% 缩放、同页文字层批注，并保存文件、页码和缩放。
- **来源继续区分**：有效翻译记录通过来源版本与结构检查后按段落同步；没有对应凭据时仅按阅读进度同步，不能据此确认译文或英文证据。中文仍可保存个人批注和摘录；对应英文未确认时，AI 对照解释在模型调用前停止。

使用步骤、同步规则与验收记录见[手动双栏阅读](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.85.0/docs/manual-split-reading.md)，默认值见[设置说明](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.85.0/docs/settings.md#手动双栏设置0850)。

## 安装

需要 **Obsidian Desktop 1.11.4 或更新版本**。从 Assets 分别下载 `main.js`、`manifest.json`、`styles.css`，放入 `<vault>/.obsidian/plugins/research-agent-reader/`，再在社区插件设置中启用。升级时先禁用插件，替换三个文件，再重新启用。

也可在 BRAT 中添加 `https://github.com/lljh2777-cyber/research-agent-reader` 并选择最新 Release。标签 `0.85.0` 与插件版本一致，不带 `v` 前缀；尚未上架 Obsidian 社区插件目录。

## 验证与边界

- 类型检查、生产构建、手动配对及既有双语／PDF／批注／设置／阅读器定向回归通过；发布流程核对三平台 CI，并由标签工作流重新构建、校验版本、生成来源证明和三个独立安装文件。
- Windows / Obsidian `1.14.4` 测试库核对实际页面更多选项、文件列表右键菜单事件、模式与文件选择器、任意目录的双语与 PDF 打开、原生文字划选和独立摘录、双向同步、取消选择、缩放和插件重载恢复。事件验证未冒充物理鼠标完整自动化；原文经哈希读回保持不变。初始模拟菜单产生的驱动异常与复验过程已留档，不宣称控制台全程无错误。
- 本轮没有新真实模型调用、完整宿主退出重启或 macOS／Linux 原生桌面验收。可选私有 MinerU 夹具未配置。未把此前版本的测试视为本轮未执行步骤已经通过，历次已知宿主异常与验收限制仍保留。
- 手动配对不证明论文身份、语义对应或科学结论；PDF 扫描图片和跨页选区不支持文字摘录。独立翻译、科学与教学审阅仍待完成，主题学习保持预览。
- 不恢复 R4 剩余迁移、R5 完整翻译生成／修订／导出、R6 跨论文对照或 T2 主题资料辅助，安排以[开发路线顶部](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.85.0/docs/development-roadmap.md)为准。
