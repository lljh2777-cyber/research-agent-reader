# Research Agent Reader 0.85.1（受限试用）

发布日期：2026-10-12。本次整理手动双栏的模式选项与文件选择界面。

## 更新

- **双语仅一个选项**：「英文＋中文 Markdown」统一从英文或中文开始。在第二份文件的选择页确认当前语言，文件名有提示时预选，可手动更正；不明确时需要确认。打开前预览两份来源，保持左英文、右中文。
- **目录树选择文件**：展开／折叠知识库文件夹，行内显示简短文件名。支持文件名／路径搜索并保留目录层级、文件类型过滤、所选路径预览、键盘导航与取消。Markdown＋PDF 和双栏顶部更换文件共用该界面。
- **原生样式修正**：目录行靠左并按层级缩进，覆盖宿主默认按钮的底色和对齐，选中文件单独高亮。

操作、同步与验收记录见[手动双栏阅读](https://github.com/lljh2777-cyber/research-agent-reader/blob/0.85.1/docs/manual-split-reading.md)。文件可放在知识库任意目录，语言提示与手动配对不会建立段落对应或论文证据。

## 安装

需要 **Obsidian Desktop 1.11.4 或更新版本**。从 Assets 分别下载 `main.js`、`manifest.json`、`styles.css`，放入 `<vault>/.obsidian/plugins/research-agent-reader/`，禁用插件后替换三个文件，再启用。BRAT 用户可更新到最新 Release。标签 `0.85.1` 与 manifest 一致，不带 `v`；尚未上架社区插件目录。

## 验证与边界

- 类型检查、生产构建、四组目录树／语言回归以及手动配对、双语、PDF 摘录、批注、设置和普通 Markdown 定向检查通过；发布流程核对三平台 CI、标签重新构建、来源证明与三个独立安装文件。
- Windows / Obsidian `1.14.4` 测试库核对实际更多选项、目录树、搜索、语言预选／更正、未知语言阻止确认、中文起读、取消、更换文件与 19 页 PDF 打开。原始资料经哈希核对未改写，原工作区已恢复。原生 DOM 事件检查不代表物理鼠标完整自动化；驱动失败与修复过程留档。
- 本轮没有新真实模型调用、完整宿主重启或 macOS／Linux 原生桌面验收。本地全量旧入口包含批量清理而未运行，公开全量检查由 CI 执行；可选私有 MinerU 夹具未配置。
- 既有来源边界保留：对应英文未确认时，中文 AI 对照解释在模型调用前停止，个人批注与摘录可保存。独立翻译／科学／教学审阅仍待完成，主题学习仍为预览。不恢复完整翻译、迁移、跨论文对照或主题资料辅助阶段。
