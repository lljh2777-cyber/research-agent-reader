## 入口与使用

在研究工作台点击 **文献库**，或运行命令 **Research Agent Reader: 打开文献库**。

1. 首次打开读取本地记录，显示等待状态，可取消；重复点击不会同时发起多次扫描。
2. 按标题、DOI、citekey 或路径搜索，筛选全部、有原文、有阅读会话、待关联或有缺口的记录。首屏最多 40 行，可继续显示更多；筛选与选中详情只消费已读取数据。
3. 详情展示现有标识、用户阅读状态、来源格式／版本、阅读进度、笔记和批注。生成单元数、用户理解标记、来源校验和笔记审阅分别显示。
4. 点击“打开原文”时重新读取并比较所选来源的指纹和版本；已变化时要求刷新重选。“开始／继续阅读”把指定来源带入已有阅读设置，打开设置本身不调用模型。
5. “继续此会话”或“查看历史会话”使用指定会话 ID。缺少当前原文仍能打开历史；继续生成由旧阅读引擎重新核验。ID 缺失时停止，不跳到其他最近会话。
6. “打开笔记”和“打开批注文件”打开各自真实文件。批注文件位置与原文位置分开记录，不通过拆分包含 `#` 的 ID 推测路径。

未完整核验的旧 MinerU 包保留“核验此原文”动作，仅完整检查用户选择的单个包。核验结果只属于本次读取；重新打开或普通刷新后仍按实际检查范围展示，不把旧成功结果当永久凭据。核验引发关联变化时依据稳定的来源对象重新定位详情，不按标题猜测。

列表中的数量是“文献及待关联记录”，不能直接当成已确认论文数。多个缺乏可靠关联依据的笔记或批注仍独立展示；同名条目增加内容类型与来源提示。本批不自动分配文献身份、合并或改名。

## 实现分工

| 文件 | 职责 |
|---|---|
| [`library/browser.ts`](../src/library/browser.ts) | 单扫描控制、取消与迟到结果隔离、过滤、来源标签及精确导航检查 |
| [`views/paper-library.ts`](../src/views/paper-library.ts) | 列表／详情、搜索筛选、空库／失败／缺口、按需核验、布局状态 |
| [`learning/entry.ts`](../src/learning/entry.ts) | 区分资料与主题入口；尚未开放的主题不能回落成论文会话 |
| [`plugin.ts`](../src/plugin.ts) | 注册视图和命令、复用标签页、打开前核验、交接到原有阅读器 |
| [`views/dashboard.ts`](../src/views/dashboard.ts) | 工作台新增文献库按钮，旧命令和操作继续可用 |
| [`styles.css`](../styles.css) | 按面板宽度布局；窄面板上下排列，隐藏按钮不受 Obsidian 按钮样式覆盖 |

R0 聚合结构只补充批注所属文件路径，没有修改正式笔记、原文或历史会话格式。扫描和详情不初始化阅读恢复、不调用模型、不查询网络、不写入人工状态；显式进入既有阅读空间后，仍沿用它的会话恢复和布局保存行为。视图的搜索、筛选和选中项保存在 Obsidian 布局中，不存入论文记录。

原阅读器的标签页交接顺序也做了调整：先显示已有或新建标签页，再等待其正文与图像加载，避免在隐藏面板中完成整套渲染后才展示。测试环境若把整个 Obsidian 窗口置于后台，PDF.js 的绘制仍可能被系统暂停；这属于窗口可见性条件，不表示来源丢失或验证失败。
