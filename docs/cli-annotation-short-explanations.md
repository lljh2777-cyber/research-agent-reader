# CLI 批注短释义与调整信息边界

日期：2026-10-13。版本：`0.88.2`。本轮继续处理 [0.88.1 定向收尾](cli-annotation-closeout.md)留下的 Step 越界及拦截边界，历史回答和失败记录保留。

## 改动

本机文字批注通常只解释选句的对象、关系与限定，用一个短段落完成。不主动补充通用研究设计评议；只有所选术语确实需要定义时才添加最小一般知识段。原文给出的样本、分母、检验与方法留在原文依据中；双语调用保留译文对照与实际英文依据。已有联网和 CC Switch 路径保持原有方式。

限定拦截修复两个已复现问题：原文明说未调整时，另一处否认因果不再误当作否认调整；模型在前一分句表示疑问或可能性时，不能掩盖后一分句肯定未经调整的断言。源证据的缺失／否定与模型断言的条件语气分开检查，不将整个段落中的任意否定词当作调整证据。

该检查仍仅覆盖已复现的未调整断言，不能保证所有表述正确。模型指令与文字匹配不能代替科学审阅，也不自动重试、更换模型或改写历史回答。

## 有限验证

共五次实际调用：OpenCode Step 两道相反条件题，Qoder 一段已有 Bailey 论文文字，mimo 首次论文选段回答暴露目的扩写后，收紧范围并将选句扩大至作者目的短语，仅针对这一处复验一次。没有空结果、模型换用或自动重试；不重跑全部旧题，不为排版或测试驱动追加请求。

两道 Step 题使用相同的 96 人高／低表达组夹具：一题没有报告调整信息，另一题明确估计值未调整协变量且不能证明因果。判断两组比较、未知与明确未调整是否各自保留，防止只把“未知”当作固定答案。

真实选句沿用测试库已有 Markdown 的同一段落，并以此前核对过的原 PDF 第 1、2 页为依据：Qoder 选择鳞状亚型与腺鳞癌的比较及 6/25、1/71；mimo 选择 96 例高上皮含量肿瘤的初始无监督聚类。选句扩大以区别已有批注，来源文件不变；不声称查看了所引图或补充材料，也不将片段核对计作整篇 X-Ray。

## 结果与残留

| 材料 | 开发者核对结果 |
| --- | --- |
| Step：调整信息未知 | 正确保留两组比较、96 人及“片段不足以判断是否调整”，没有再断言未经调整；首次配置缓存调用成功 |
| Step：原文明说未调整 | 正确保留未调整协变量与不能证明因果，未被拦截器误伤；仍有多余的术语释义与缺失信息说明 |
| Qoder：6/25 与 1/71 | 比较对象、分母、P 值和 Fisher 检验留在原文依据段；“较强关联”是额外程度概括，未计作作者的直接用语 |
| mimo：初次样本选句 | 数字保持，但将目的扩写为上皮与间质比例均衡、避免信号主导，未认定该项质量通过；原回答照样留档 |
| mimo：含作者目的的复验 | 原文依据段改为转述“平衡间质基因表达”，不再声称两种细胞比例均衡；一般知识段仍推演提高门槛的作用，未独立核验，不能计作全部质量通过 |

前四次使用首轮短释义指令；mimo 的最后一次使用进一步收紧选句范围与目的转述的规则。最后规则没有重复全部真实调用。CodeBuddy 本轮只作路由及协议回归，未重新生成，旧样本不能外推为新规则的科学质量保证。

五次均通过原生设置、批注弹窗的 AI 解释／保留控件，选区由文件原文与偏移构造，属于 DOM 事件验收。五份正文及 CLI 回执保存回读一致、原文摘要与布局保持；最终插件重载后，五份新记录与此前九份记录共十四份逐字恢复，原后端设置恢复，没有新增模型请求。失败内容没有人工改写或移除。
