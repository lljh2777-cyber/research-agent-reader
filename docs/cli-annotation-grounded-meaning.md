# CLI 批注的引句与释义绑定

日期：2026-10-13。版本：`0.88.3`。继续处理 [0.88.2](cli-annotation-short-explanations.md)留下的 Qoder 程度概括和 mimo 背景推演问题。

## 返回约束

三个本机文字后端共用一次请求的结构化返回：一至两条实际原文引句与对应短释义。插件检查引句是否在本轮提供的原文中、是否覆盖所选范围，再渲染原文依据和对应引句。只统一行尾，原文用词与标点须匹配；中文双语选择的引句仅来自实际英文，译文核对单独保留。

这条本机批注路径专注原文释义，不生成一般知识段或背景定义；额外背景字段、无效结构、虚构或无关引句均拒绝交付，不自动重试或换模型。既有对话、主题学习、Direct API、联网与 CC Switch 路径保持原有方式。模型一般知识与论文证据仍需分别对待。

每条释义按其绑定引句检查：未调整断言须有对应依据；关联强弱或效应大小不能仅从比例或 P 值补出；研究目的不能扩写成细胞比例均衡或已实现的阈值／信号作用。原文明确报告的程度判断、比例或作用仍可转述，不把有原文依据的内容一律禁止。

统计规则依据是 ASA 关于 P 值与效应大小的区分；该外部规范不是本论文的原文证据。[ASA 声明](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)指出统计显著性不能用来衡量效应大小或结果的重要性。

引句匹配与限定断言检查不是完整的语义证明或科学审阅。它们覆盖本次已复现错误，不能据此保证所有措辞、其他研究方法或全部模型回答正确。旧批注不通过新格式重新解析，不改写或删除旧答。

## 验证范围

使用留存的 Qoder 程度概括和 mimo 阈值推演作为回归，并加入作者明确强关联、明确阈值作用及明确比例相等的正向对照。检查实际引句、所选范围、禁止额外背景字段、否定语气、中文双语英文依据和一次调用后拒绝交付。

本机原有依赖链接指向的共享目录不可用，因此在独立验证副本中按原锁文件从本地缓存安装既有依赖，关闭安装脚本，未下载新包；主仓库依赖目录保持原状。代码与元数据同步到该副本执行检查，构建产物再用于测试库。验证副本与原始记录保留，没有清理或递归删除。

真实调用限定为 Qoder 与 mimo 各一个已有论文选段和一个有明确依据的合成对照。使用准确的 `Qwen3.8-Flash` 与 `opencode/mimo-v2.6-flash-free`，保留原文、用量和首份输出；不重跑所有旧题，不将片段核对计作整篇科学／翻译审阅。
