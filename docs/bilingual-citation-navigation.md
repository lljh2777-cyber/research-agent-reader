# 双栏引用跳转错位修复

日期：2026-10-16。版本：`0.88.4`。用户报告双栏阅读点击引用后，文件选择栏、联动栏及正文标题被滚出视区，正文显示位置异常。

## 原因与修复

原实现对引用目标和已保存摘录调用 `scrollIntoView`，浏览器会滚动目标的多个祖先容器。ITS Theme 下，外层阅读视图和隐藏溢出的容器也会移动，影响固定工具栏；Obsidian 自带脚注处理还可能在阅读器的链接冒泡监听之前执行。

改为使用目标相对所在正文滚动区的坐标，仅设置该栏的 `scrollTop`，并限制在合法范围。摘录返回使用同一方法居中。引用点击由正文捕获监听接管，在宿主脚注处理前阻止默认导航与后续处理；目标只从本栏已渲染的 ID 映射取出。外部链接保持原行为；缺失引用提示“当前文档未找到该引用位置”，不向外层或其他栏目寻找同名目标。

文件内容、选区偏移、语言和来源凭据不变。开启联动时，跳转后仍按已有对应规则同步另一栏，交换显示顺序不改变引用归属。

## 定向验证

三组模拟 DOM 回归覆盖编码引用、嵌套点击、脚注返回、捕获先于宿主处理、所在栏滚动与另一栏隔离、开启联动的语言方向、摘录居中、上下边界、缺失引用、外部链接及失效／关闭后的定位阻止。相关双语、手动配对、交换、PDF 摘录、批注和普通 Markdown 定向检查通过；类型检查与生产构建通过。

独立测试库生成器为两份手动阅读样本加入合成脚注及对应操作指引，生成检查通过；合成引用明确用于导航，不作为论文证据。该新生成目录未另行打开作原生验收，下述原生结果来自已有双语样本。

Windows / Obsidian `1.14.4` 测试库使用已有 DeepMet 双语样本。正式资料库只读检查了当前主题名称与主题 CSS，在测试窗口临时加载相同的 ITS Theme 和浅色样式，没有修改正式资料库或测试库的外观设置文件。

- `0.88.3` 默认主题的首次尝试未出现外层错位，不能作为用户问题的复现；加载 ITS Theme 后，原版点击引用使顶部文件栏由视区内移至视区外，原始几何数据与截图留存。
- `0.88.4` 核对中文在左、关闭联动时的引用与脚注返回，仅改变中文正文位置；核对英文在左、开启联动时的英文引用与返回。两种情况下外层容器的横纵位置、文件栏与两侧正文工具栏位置保持。
- 由实际英文 DOM 选区保存一份独立摘录，再从远处返回原文：选中文字准确，外层和工具栏保持位置，不改写原文。
- 插件重载后两侧来源位置与显示顺序恢复。英文、中文及配对文件经哈希确认未改变；最终恢复原工作区和临时主题，测试摘录保留。

原生检查由 CLI 操作实际 DOM 控件与生产来源捕获完成，不代表全流程物理鼠标操作或所有主题／平台验收。首次 CLI 目标初始化未识别 `plugin` 命令，随后只读确认测试库及空闲状态才开始操作；默认主题未复现的断言失败也保留，不计为复现成功。初始文件搜索的 PowerShell 通配路径错误已改为 `rg -g` 过滤，未改动文件。
