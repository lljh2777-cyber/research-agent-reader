# R3 工程收尾：摘录、待处理与选择性整理

2026-10-05，开发版本 `0.81.1`。R3 在 Windows 测试库范围内完成工程收尾：原文与学习摘录可以保存、独立编辑、找回并定位，通过待处理返回，明确选择后补充已有笔记或创建单个知识页，失败后保留记录并继续。

本结论依据生产代码、分项验收、原生界面检查及真实磁盘跨进程测试。它不包含对论文或模型回答的科学判定，不提升资料阅读深度，也不解除主题学习预览限制。R0 独立科学审阅与 T1 独立教学审阅仍待完成。

## 本轮发现与修复

原文摘录手动标记“整理完成”后，修改个人备注仍保持完成状态。如果来源匹配，待处理中心会继续隐藏这条记录，新备注容易漏掉后续整理。学习回答摘录已实现内容变化后重新待整理，两条流程此前不一致。

`ExcerptLibraryService` 现在在个人备注实际改变时，将没有归档任务关联的手动完成标记重新设为待整理，同时更新可见状态。无变化保存保留完成标记；有关联任务、目标或错误的旧归档记录继续由原归档流程管理。修复同时适用于 Markdown 和 PDF 摘录，保留原句、定位凭据、独立 AI 区域、额外正文及 LF/CRLF 换行。界面说明和保存反馈已同步更新。

新回归先复现了旧行为：预期待整理，实际仍为 `completed`；修复后通过。PDF 备注测试也明确验证重新待整理，并保持原 PDF 凭据不变。

## 新增跨进程验证

`tests/test_r3_persistence.js` 在保留的临时目录中依次启动五个全新的 Node 进程，分别执行：

1. 保存原文摘录、学习摘录和人工修订历史。
2. 从磁盘找回记录，修改已完成摘录的备注，保存固定材料草稿；补充已有笔记时在索引写入前注入失败。
3. 新进程读取真实整理日志并继续，随后撤销；修改当前人工稿，再按旧草稿预览建页，并在索引前注入失败。
4. 新进程读取建页计划并继续，页面、索引、日志逐项匹配；正式检索分块排除人工学习材料。
5. 再次从磁盘验证原句、位置、人工历史、固定草稿、撤销结果和建页完成记录。

使用实际 `FileSourceStorage`、`FileCurationStore`、`VaultPageFiles` 和生产服务。Obsidian 的文件对象及 `vault` 接口由磁盘测试适配器提供，不能将它等同原生宿主的文件系统原子性或跨设备同步测试。保留夹具、不执行清理，不调用模型或网络。套件输出各进程 PID 和保留路径，纳入 `pnpm test:r3`。

## 原生完整流程验收

环境为 Windows、Obsidian 1.13.7、`E:/paper-test`，桌面 1707×1019 和窄视口 430×900。Browser 插件不可用，项目未配置 Playwright，沿用 Obsidian CLI、DOM 与 CDP，没有新增依赖。

| 原生操作 | 结果 |
| --- | --- |
| Markdown 编辑器选中第二处重复句 → 批注 → 保存摘录 | 原句与字符位置正确，个人备注单独保留 |
| 标记完成 → 修改备注 → 再次选择同一片段 | 重新待整理，待处理可见；重复选择返回原记录，保留新备注 |
| 原文摘录 → 已有笔记 → 内容选择与预览 | 默认不选；未勾选时拒绝预览，明确勾选后预览不写正文 |
| 预览后修改原文 | 确认被拒绝，目标保持原样；恢复验收源并重新预览后补充成功 |
| 修订历史 → 预览撤销 → 确认撤销 | 目标逐字恢复已有正文，修订日志保留 |
| 人工稿固定草稿 → 新页预览 → 注入索引失败 | 已创建页面和计划保留，索引尚未改变，失败可见 |
| 插件重载 → 待处理 → 准确草稿 → 确认继续建页 | 页面、索引和日志匹配固定计划；完成项从待处理移出 |
| 430 px 窄屏恢复 | 内容区 371 px，滚动宽度 371 px，确认和状态显示可用 |
| 回到原文 | 返回正确文件、第二处同文和准确字符偏移 |
| 视觉与运行检查 | 桌面与窄屏内容非空、标题正确，无错误覆盖层；最终宿主错误捕获为空 |

本轮原生新增源文件明确写为软件验收样本，没有将其视为论文证据。原生 PDF 的真实文字层、页码及恢复证据沿用 [R3.9](pdf-excerpts-r39.md) 和 [R3.10](pdf-excerpt-curation-r310.md)；本轮追加 PDF 备注状态回归，没有重新做一套 PDF 视觉阅读或远程生成。

“回到原文”的第一次辅助等待达到 18 秒后停止，随后确认操作已完成；重新前台绘制并独立核对文件、选区和偏移通过。插件重载时，既有单阅读器归并逻辑替换了原有的一份阅读标签，未改变其文档。验收结束按保存的文章路径和完整视图状态重开，原有 14 个标签内容恢复，其中 13 个保留原 ID、1 个使用新 ID；未声称布局 ID 全部不变。新建的验收标签、窄屏模拟及调试已关闭。

## 保留限制与下一步

本次工程收尾覆盖单机 Windows、当前宿主版本与明确边界内的来源、摘录和单页写入。跨设备真实同步、磁盘断电／系统崩溃、其他平台／宿主版本、大规模接近上限的原生性能仍未验收。跨页 PDF、扫描图像 OCR 选区、多材料自动合并、历史自动裁剪不在当前交付范围内。宿主进程完整退出重启未在本轮重做；本轮证据为原生插件重载和真实记录的五进程恢复。

下一步进入 R4 的**只读存储盘点与迁移预览设计**：确定持久记录、唯一副本、可重建缓存及其引用依赖，再在保留副本上演练迁移、恢复和回退。按照开发路线，正式 Vault 路由切换须先提供具体预览并取得用户批准；当前没有执行数据迁移。科学与教学质量继续分别推进 R0、T1 审阅。
