# 研究工作台

## 统计与更新分布（0.40.3）

论文统计按 `depth`、`analysis_depth`、旧 `status` 的顺序识别明确的处理深度，缺少明确值时兼容旧标签。显式元数据深度不会因历史 x-ray 标签而升级。统计、深度分布和待深读候选使用同一规则，不修改笔记。仅元数据、摘要级和全文深读为互斥分类；代码静态阅读在独立统计中展示，不混入论文分布。

笔记更新分布显示当前月及前两个月，按周补齐边界。数据来自文件最后修改时间，是当前文件的更新时间分布，不是完整操作历史，也不代表阅读时长。

任务优先展示运行中、排队中和失败待处理的记录。任务标题优先取产出笔记的标题，原路径保留在详情。数据层保留全部已有历史，视图可按需展开。无任务时使用真实空状态。

内存测试覆盖新旧深度字段、冲突优先级、跨年日期边界、历史任务排序和标题解析，不删除文件、不调用模型。

## 首页布局（0.41.0）

三个常用入口为文献入库、PDF 深读和知识库检索，五个辅助工具保留直接入口。按钮默认说明用途，只在运行或不可用时突出状态。「本地」改为普通状态文字。首页依次显示最近三条正式阅读、任务与结果、紧凑统计和最近三个月的笔记更新分布；宽屏下最近阅读与任务并排，窄侧栏按列展开。

任务默认显示五条，可以筛选、查看全部和打开结果；长路径只保留在悬停说明和详情里。窄侧栏默认显示一条最近阅读，另外两条可展开查看。详细维护区默认收起，展开后仍可使用问题处理、论文深度、方法覆盖和 OKF 就绪度。页面更新保留滚动与当前展开状态。

界面使用独立作用域的青绿强调色、主题背景和界面字体，不影响阅读器或其他设置页。热力图按实际周数排列，说明文件修改日期统计的局限；普通空状态不显示成异常警告。

`tests/obsidian-dashboard-workbench.js` 在实际 Obsidian 中检查八个入口、任务筛选与展开、维护折叠恢复、1180/800/540/360 像素宽度和主题适配。该脚本只临时修改界面样式，不启动任务、调用模型或修改用户设置。含递归清理的旧完整测试入口不执行，使用 `test:dashboard`、阅读回归和原生界面检查替代。

验收时实际检查了深色宽屏、深色窄侧栏和浅色宽屏；30 项导航与布局检查通过，任务结果另行核对。旧静态测试中三处过时的入库说明断言已对齐当前文案，其来源隔离检查保持有效。
