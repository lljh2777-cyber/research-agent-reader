## 集成中修复的问题

- Obsidian 自定义视图默认禁止文字选择，导致划选追问无法触发。
- Direct API 的 20 秒默认超时不适合长文，阅读请求改用 120 秒并保留独立取消。
- 后台 PDF 图像渲染等待前台动画帧，停止无法及时取消；改用离屏渲染方式并传播取消信号。
- 主输入框草稿未按主线节点隔离；切换支线会影响主输入目标；滚动与未发送选区缺少恢复。
- 主线视图恢复时平滑滚动依赖动画帧；恢复位置改为立即设置。
- 长文目录截断可能遗漏后半篇证据；改为保留全部位置并压缩预览，超出目录容量明确拒绝。
- 已选图像超量、未加载或模型没有视觉能力时，禁止将文字解释记录为图像读取。
- 生成结束后再次核对原文指纹，避免请求期间文件变化仍写入完成结果。
- 存储失败恢复时保留可读历史；界面监听器异常不再误报已经完成的磁盘保存失败。
- Wiki 检索排除操作日志及自动学习记录，减少循环引用。
- 图表模式的原文阅读器跳转新增明确页码导航。

## 已记录的限制与后续验收

- 某些 MinerU 段落不能唯一匹配页码或跨越多页；显示章节、原文片段和字符范围，保留页码缺口。
- Codex CLI 正文在最终消息完成时显示；具备流式能力的 Direct API 支持逐步显示。生成阶段和停止状态均可见。
- 每轮最多 3 张图像，较大的多面板图需要分次提问。本文事实仍需读者对照证据判断。
- 这次验证覆盖程序流程和实际界面操作，不能代替用户对长时间阅读舒适度、讲解质量和布局偏好的验收。
- 首版未加入联网检索、Claude/OpenCode 阅读适配器或正式论文 `x-ray` 状态自动升级，符合约定范围。
