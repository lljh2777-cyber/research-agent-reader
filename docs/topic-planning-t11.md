# T1.1：主题创建、历史与路线编辑器

交付日期：2026-09-11。开发版本 `0.54.0`，部署至测试库 `paper-test`。本批将 T0 的独立主题服务接入原生 Obsidian 界面，开放 **主题路线（预览）**。用户现在可以安排学习目标和路线；单元讲解、对话与思维导图仍待 T1.2，不能将路线确认视为已经学习或教学质量通过。

## 使用流程

在研究工作台辅助入口点击 **主题路线（预览）**，或运行命令 **Research Agent Reader: 打开主题路线（预览）**。

1. 填写主题、目标和可选基础，点击“保存目标”。无需 PDF、代码文件、知识库资料或模型配置。
2. 手动添加 2–12 个单元，填写标题、中心问题、学习目标与先修关系。可移除、上下移动；先修关系不允许指向后面的单元，移除单元时清除对它的先修选择。
3. 如需模型规划，选择已经通过连接测试的 Direct API，明确点击“生成路线草稿”。只发送已保存的主题、目标和基础，一次操作一次请求；页面打开、切换、重载和手动编辑不自动请求模型。
4. 检查并保存路线，再点击“确认路线”。修改目标会重置当前路线，按钮明确说明；修改路线后确认失效。已经保存的版本继续保留。
5. 从左侧历史选取主题；同名主题显示目标摘要与更新时间。初始读取最多 40 个主题，可逐批读取更多；搜索只覆盖已经读取的主题，匹配标题、目标和 ID。
6. 发生外部修改时，原编辑凭据不能覆盖新版本。可保留本地草稿、恢复已保存内容，或把本地目标另存为新主题，再检查并保存带入的路线。
7. “查看已保存版本”展示目标、基础、单元和先修关系。用户可从指定有效版本创建独立副本；旧历史不改写，副本清除路线确认。并发冲突不会按时间自动选胜者。

“从资料开始”仍进入原有资料阅读空间。主题历史不作为文献或正式 Wiki 内容进入文献库；没有虚构 `source.path`、论文 ID、引用锚点或科学处理深度。

## 实现与保存边界

| 文件 | 职责 |
|---|---|
| [`topic-learning/workspace.ts`](../src/topic-learning/workspace.ts) | 编辑缓冲、修订凭据、历史读取、取消、用量展示状态、明确复制与关闭守卫 |
| [`views/topic-learning.ts`](../src/views/topic-learning.ts) | 原生目标表单、单元编辑、先修关系、模型选择、历史版本、窄面板 |
| [`topic-learning/service.ts`](../src/topic-learning/service.ts) | 复用 T0 保存／规划契约，补充指定版本复制和用量回调 |
| [`topic-learning/planning.ts`](../src/topic-learning/planning.ts) | 原有单次结构化请求，传递接口用量报告 |
| [`plugin.ts`](../src/plugin.ts) | 独立视图、命令和会话域路由，按需创建服务与已验证的模型后端 |

主题记录使用插件目录下的 `topic-learning-sessions/<t-id>/`，继续沿用 T0 的追加修订与 `.ready` 提交标记，没有修改已有主题或资料会话的文件格式。只读打开不会创建该目录。确认、复制和保存都必须由用户明确操作。

正在编辑的表单、选中的接口 ID 和搜索词随当前 Obsidian 标签页布局保存；未完成字段也能恢复。切换主题前要求保存或明确恢复，防止意外丢弃草稿。关闭标签页不等于持久保存表单，应先点击保存；插件重载保留仍在布局中的草稿。正文输入过程中不重建输入框，保留中文组合输入和浏览器原生编辑状态。

本批仅展示当前打开期间一次路线请求的供应商报告用量，输入、输出或缓存缺失时标为“未报告”，不计为零，也不估算费用。用量未写入路线修订，重载后不展示旧的请求状态；持续会话账本留到后续步骤。首版规划仅使用已验证 Direct API，未新增 CLI 规划入口、联网、检索或自动工具调用。

生成可取消，超时仍使用 T0 的 3 分钟上限；取消后的迟到正文和用量不会更新草稿。若取消到达前提交已开始，显示已保存结果，不通过删除修订回滚。失败保留旧路线，必须显式重试。损坏和并发历史只展示可核验版本；复制只从重新读取后仍有效的版本发起，不能修复已损坏的正文。

原生 Obsidian 验收通过工作台真实入口和 DOM 事件操作完成，使用独立真实文件存储与模拟模型：

- 空历史打开不创建记录，不调用模型；目标、手动路线、先修顺序和确认可操作。
- 目标变更、路线编辑和历史副本正确保留旧版本；同 ID 外部更新不会被旧表单覆盖。
- 每次完整场景包含 3 次模拟请求：成功、连接失败和取消后迟到响应；没有真实供应商请求。
- 中文组合输入事件保留同一个输入节点；输入后的焦点、校验失败后的正文和未保存草稿恢复通过。
- 430 px 面板上下排列且没有横向溢出；没有配置模型时仍可手动编辑。
- 重新创建视图与插件重载后，布局状态保持一致；将独立验收存储重新注入新控制器后，恢复同一修订摘要。没有向测试库默认主题目录写入模拟主题。
- `paper-test` 的 897 个受保护文件哈希不变，未新增研究内容文件；部署仅更新插件运行文件，验收后恢复原布局并退出调试。

脚本、截图、独立主题存储、重载观察和文件保护清单保留在仓库外的 `E:/research-reader/topic-t11-20260911/`。这些工程验证没有调用真实教学模型，不能证明路线教学质量或学习效果；没有进行新的论文科学审阅。
