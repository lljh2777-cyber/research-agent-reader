# 主线导读质量

教学规则保持简短：一个中心问题、解释方法理由、区分事实与解释、保留指标与图表含义、连贯推进。正文结构、篇幅和例子由模型按内容决定，不要求固定章节或填满检查清单。

`skills/paper-guided-reading/SKILL.md` 随构建嵌入两个阅读后端。程序另行提供当前任务、输出协议及来源边界；编号、状态、存储和学习标记由插件管理。

## 质量对照

下面是人工评估场景，不是已经通过的模型实验。比较讲解内容，不按小标题数量评分；自动化检查负责引用、顺序及保存等可判定约束。

| 场景 | 观察重点 |
| --- | --- |
| 同时报告 Top-1、Top-k 与实验验证率 | 保留各自任务与分母，避免直接当作同一种准确率比较 |
| 工作流示意图与结果图相邻 | 区分设计说明与实验证据；读图说明有用的坐标轴、对照和不确定性 |
| 正文引用未提供的补充表 | 指出具体缺口，继续解释有证据的部分，不补造表格内容 |
| 下一模块沿用上一讲概念 | 简短衔接后回答新问题，避免换标题重复前文 |
| 从旧回答划选公式追问 | 聚焦选区与必要例子，保持支线背景及主线位置 |
| 最后一个综合单元 | 综合已讲的论点与证据，保留未解决缺口，不把讲完等同于掌握或 X-Ray |

后续仅针对反复出现且可复现的问题增加约束，避免将某篇论文的特殊情况写成所有论文的要求。
