# R1：主要笔记选择

交付日期：2026-09-11。开发版本 `0.58.0`。文献详情现在可以选择、更换、清除和打开主要笔记。首页与次级入口整理、关联代码导航和 R1 整体验收仍待后续步骤。

## 使用

在 **文献库 → 文献详情 → 主要笔记** 点击 **选择主要笔记**。重新核对记录后，候选列表显示同一文献的笔记标题和完整路径；同名笔记不会按标题混同。选好后点击 **保存主要笔记**。选择 **不设主要笔记（清除选择）** 并保存，可以撤回原选择；取消或关闭页面不会保存未提交草稿。仅有一份候选时也不会自动选中。

已选择的有效主要笔记提供 **打开主要笔记**，并在下方笔记卡片显示标签。该选择只用于导航，不合并笔记、不修改正文、不改变人工阅读状态，也不赋予笔记审阅或 `x-ray` 状态。原有 JATS／PDF／MinerU 来源版本及写入规则保持不变。

人工阅读状态与主要笔记编辑同一时间只能进行一项，避免一项保存让另一项编辑凭据过期。保存或取消后可以切换文献、刷新或打开原文；输入过程中保留原生选择控件。

## 失效选择与保存守卫

普通投影不会把失联的主要笔记当成有效导航。本次编辑从原始人工决定读取旧路径，在下拉列表中保留禁用的“旧选择已失效”项；用户必须明确选择另一份笔记或清除。没有可靠候选时，失效选择仍可清除；没有旧选择也没有候选时，不制造空写入。

编辑只接受当前文献的候选路径或明确的空选择。保存使用开始编辑时的文献、笔记内容和人工决定摘要凭据，再由现有 `PaperRecordService` 重新核对。正文、身份关联或外部人工决定变化会拒绝旧编辑，保留草稿及旧记录，不自动刷新凭据后重写。用户可以取消、刷新、核对后重新选择。

身份不明、关联冲突、损坏记录和并发版本继续阻止保存。页面不自动修复身份或选择并发版本。写入失败保留草稿供明确重试，提交成功后的目录刷新失败单独提示；刷新完成不会抢回用户刚选择的其他文献。准备取消和关闭后的迟到回调不更新视图，已进入保存的操作仍可能写入完成，不承诺关闭即回滚。

保存只提交主要笔记字段，保留阅读状态及其他人工决定；继续追加到插件目录 `paper-records/<paperId>/`，不删除旧修订，不变更存储格式。R4 仍负责后续可见目录迁移。

## 实现和验证

- `src/library/reading-state-editor.ts` 提取通用的人工决定编辑过程，原阅读状态编辑保留五态校验与原接口。
- `src/library/primary-note-editor.ts` 负责候选、原始主要笔记选择和限定字段的保存命令。
- `src/views/paper-library.ts` 接入主要笔记表单、指定笔记打开、双编辑互斥和保存后的展示；复用已有自适应表单样式。
- `tests/test_library_primary_note.js` 新增七组测试：同名候选／跨文献拒绝、选择替换清除、失效旧选择、正文／身份／人工决定变化、保存冻结及错误、取消与并发准备、刷新与关闭。
