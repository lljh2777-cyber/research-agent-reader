# R3.12：从保存草稿创建单个知识页

更新日期：2026-10-05。开发版本：`0.80.0`。

## 使用流程

在「知识整理 → 新知识页草稿」打开已保存草稿，先保存或放弃尚未保存的输入，再点击“创建知识页／查看建页记录”。选择文件名，点击“查重并预览创建”，查看页面、索引和日志三项变化，确认后保存。页面类型沿用草稿中的概念、方法或综合，对应 `wiki/concepts/`、`wiki/methods/`、`wiki/synthesis/`；本版只支持该目录下的单个 Markdown 文件，不接受自定义目录或论文来源笔记。

查重覆盖三个知识目录内的路径、文件名、标题与草稿身份；比较时处理 Unicode 规范化、空白和大小写。文件名修改使旧预览失效。预览不创建目录、页面或恢复记录；同名文件不覆盖，也不自动加后缀绕开重复。标题相同的独立页面需用户先回到草稿核对命名。

概念与综合页面追加「研究主题索引」，方法页面追加「研究方法索引」，并在 `wiki/log.md` 记录创建操作。缺失的目标目录、对应索引与日志会列入预览，只有确认后才创建。索引、日志已有内容纳入完整预览，保存前变化会拒绝旧确认。

## 内容与证据边界

创建的是可在 Obsidian 打开和编辑的正式 Markdown 文件，内容状态为待审阅。页面保留草稿身份与版本；正文和附带材料使用已有 `rar-learning-note` 原样文本块，Markdown、HTML、脚本和链接不会执行，既有正式证据检索会排除这些块。当前功能不提供将这些块自动升级为已核验知识的操作。

手写正文保留为个人草稿；原文摘录保留保存时的句子、位置与来源版本；AI 回答、人工修订稿和备注保持各自标签。原样块内的原句和备注不额外转义符号。建页使用明确预览过的历史快照，不因当前来源变化替换材料，也不据建页成功宣布当前原文或科学结论已经核验。若需要核对当前来源，可先在草稿中使用“核对附带材料”。已有论文来源笔记的严格写入契约保持不变。

每份草稿只建立一份创建记录。创建完成后，再编辑草稿不会同步修改页面；重复确认只返回原创建结果。需要另一个页面时可复制草稿，但仍须通过路径和标题查重。

## 保存与恢复

保存记录位于插件目录 `knowledge-pages/<draft-id>.json`，完成后追加 `<draft-id>.complete`。记录固定当时的草稿版本、目标页面、目录及每个文件的前后内容，不覆盖或删除旧记录。已有草稿历史不迁移。

确认时先重新核对草稿、查重、目标与索引／日志，随后保存创建意图，再依次写入页面、索引和日志。页面只创建，已有索引／日志使用 Obsidian `process` 核对后修改。每步前核对预览内容；中断时保留已写入部分，窗口关闭或取消也不回删文件。响应丢失和完成标记失败可通过原记录重试，不重复追加相同内容。

“建页待恢复”显示于草稿列表和待处理中心。重载后打开记录、核对固定预览，再点击“确认继续建页”；已完成的文件只按准确内容复用。固定版本仍保留在草稿历史时，即使用户后来编辑草稿，也可继续完成原计划。若页面、索引或日志有后续人工改动，则停止恢复并保留它们，本版不自动合并这些冲突。

完成后提供“打开已创建页面”，草稿不再作为未完成建页事项显示。已完成页面缺失会重新显示复查提示，不自动重建。已创建页面的后续内容审阅不等于草稿建页状态，也不由本功能自动完成。没有自动删除页面或撤销建页的按钮。

## 实现范围与限制

新增 `src/curation/page.ts`、`page-files.ts` 和 `src/views/knowledge-page.ts`，连接原草稿窗口、插件服务及待处理中心。复用固定根存储、原有草稿验证、学习块隔离和 Obsidian 文件接口；已有笔记修订器仍只负责其原先的更新契约。

生产查重直接读取三个知识目录，不依赖陈旧的标题缓存；最多 500 个目录、5,000 项，候选文本读取预算 16 MiB。单个页面／索引／日志上限 1 MiB，创建计划上限 8 MiB。路径包含链接或特殊文件、目录被文件占用、损坏计划或异常完成标记均停止处理。未完成意图不提供删除重置；没有任何页面被写入时仍需按原计划恢复，或复制成新草稿后重新预览。

本轮未做跨设备同步实测、大库性能验收、批量建页、多材料组合、自动合并或正式研究 Vault 迁移。新页面暂以原样文本块保存草稿内容，后续正文审阅和编排是独立工作。
