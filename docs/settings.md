# 设置使用说明

设置首页默认展示六个常用入口。可以按「阅读与批注」「模型与连接」「文献与知识库」「系统与数据」筛选；「更多设置」收纳本地 CLI、任务策略与运行环境。

顶部搜索始终覆盖全部设置，不受当前分类限制。支持中文功能名和常见术语，例如 `密钥`、`PDF`、`embedding`、`Codex 路径`、`导出`。搜索多个词时，入口需要同时匹配这些词；清除后回到之前的分类。

## 常见配置路径

| 要做什么 | 入口 |
| --- | --- |
| 调整文章目录、图文双栏和阅读版式 | 文献阅读器 |
| 配置 AI 服务、凭据与模型 | Direct API |
| 调整划选解释的模型和回答长度 | 批注 AI |
| 配置 BGE 凭据、检索方式或更新索引 | 知识库检索 |
| 配置 PDF 转换与 MinerU | 文献解析 |
| 配置 Unpaywall 联系邮箱和开放 PDF 回退 | 全文来源 |
| 调整查询历史、笔记目录或查看诊断 | 数据与诊断 |
| 选择 Codex、Claude 或 OpenCode 的配置来源与模型 | 模型与连接分类下的对应 CLI |
| 指定 CLI、Python、R 或工具包路径 | 工具链与运行环境；各 CLI 页也有路径入口 |

PDF 交互深读的后端、模型和讲解偏好在阅读会话中选择；设置页的任务默认策略不代替会话设置。

「全文来源」中的 PMC 获取无需模型配置。Unpaywall 回退默认关闭，明确填写联系邮箱并启用后，查询会发送 DOI 和邮箱至该服务。邮箱只保存在插件本地设置，不进入获取记录；清空后需要重新配置。已保存任务保留创建时的来源开关，修改配置后可从入口发起新查询。完整使用流程见[全文获取 M3](fulltext-acquisition-m3.md)。

## Direct API 配置顺序

选择或新增供应商配置 → 填写连接信息 → 选择模型 → 测试连接。当前配置的联网方式与连接测试超时、通用请求参数、Tavily 设置和 Agent 参数都放在下方的折叠区。

「已验证」表示保存过成功的连接测试结果，并非实时在线监测。「已检测到程序」只代表本地 CLI 已找到，仍可进入对应页面测试。已指定检索凭据也不等于模型连接已验证。

## Direct API 联网批注（0.38.1）

在「批注 AI → 执行后端」选择已验证的 Direct API，再启用「浅层联网解释」。联网开启时仍可选择 Direct API；开关切换和重载保留所选配置。

联网问答与批注遵循同一份供应商设置：

- **自动**：识别到原生联网协议时使用原生联网，否则使用 Tavily。
- **仅供应商原生**：使用已支持的供应商联网请求参数；不能识别时提示调整配置。
- **仅 Tavily**：即使供应商支持原生联网，也使用 Tavily。Key 在「Direct API → 联网搜索」配置。
- **关闭**：该配置只能做不联网的批注；若批注要求联网，会提示原因。

显式选择 Direct API 后，凭据不足或请求失败都提示原因，不自动换到 CLI。批注后端选择「自动」时，则优先使用已就绪的默认 Direct API，没有可用配置时使用 Codex CLI；设置页显示当前会采用哪一种方式。

Tavily 使用选中文字与章节做一次浅层检索，最多把三个来源送给解释模型，不额外调用模型规划检索词。解释正文后保留实际检索链接；没有结果会标明尚未经联网核验，无效引用编号或未检索到的链接会提示重试。取消和总时间上限覆盖检索与解释两个阶段。

原生联网由供应商执行，插件传入范围约束并显示回答中的来源链接。供应商回答给出的网址不等同于插件独立读取的证据；阿里云的 OpenAI 兼容接口也不返回结构化搜索来源，参见[官方联网搜索说明](https://www.alibabacloud.com/help/en/model-studio/web-search)。因此界面保留来源未独立核验的提示。

0.38.1 验证：原生请求参数、Tavily、无结果、引用校验、停止、超时和后端选择回归通过；原文完整性、现有问答和阅读回归通过。实际 Obsidian 中用独立设置副本验证了 Direct API 下拉可选、联网开关、缺少凭据提示及自动选择，真实设置未变。现有阿里云配置完成一次实际解释请求（约 18 秒），返回了论文网址；本机未配置 Tavily Key，Tavily 使用模拟接口验证，未进行真实 Tavily 调用。没有保存测试批注或修改论文原文。

## 导航与数据

详情页左上返回设置首页，右上可直接切换页面。返回保留首页的搜索、分类与滚动位置；同页刷新保留滚动和高级区展开状态。这些界面状态只在当前插件实例内保存。

历史保留上限适用于任务与知识库查询。PDF 交互深读会话独立保存，不受这些数量限制。知识库问答的笔记目录可以在「数据与诊断」修改；交互深读的学习笔记仍导出到 `wiki/qa/`。
