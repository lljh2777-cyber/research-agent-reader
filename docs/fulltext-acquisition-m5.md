# 全文获取 M5：JATS 原文保存与普通阅读

实现版本：`0.48.0`。本阶段在既有全文获取与来源目录上增加 PMC XML / JATS，不需要模型或 MinerU。

## 使用流程

1. 在工作台选择「获取全文」，输入 DOI、PMID 或 PMCID。
2. 「获取内容」选择「JATS XML 图文原文」，按需勾选同版本图片，选择出版版本或允许作者接受稿。
3. 核对候选版本、许可及撤稿标记，获取 XML 和引用媒体。
4. 选择「查看 XML 并保存原文」，核对来源记录与 XML 主文章的标题、作者和标识。可展开原始 XML 元数据及正文投影预览。
5. 有正文降级、缺图或未展开内容时，明确接受部分结果后保存。只选择正文时，未请求图片本身不会导致部分结果。
6. 保存完成后打开图文阅读器；章节、图像、结构表格和参考文献通过源块跳转。登记失败可再次进入补登记。

「重新查询 JATS 与图片」创建新获取任务，保留原有快照和原文包，重新显示候选供选择。同一请求的正常再次打开优先核验并复用本地缓存，不自动连接来源。

## 来源与版本

元数据识别沿用 Europe PMC / Crossref；JATS 字节使用 PMC 开放数据桶的同版本 XML 和媒体清单。本阶段不把另一入口的 XML 与同 PMCID 的任意 PDF 或图片拼接。当前 PMC 数据分发契约和文件布局已核对 [PMC AWS 文档](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/) 与[开放数据桶 README](https://pmc-oa-opendata.s3.amazonaws.com/README.txt)。

候选绑定 `PMC<id>.<version>`、稿件类型、原始元数据 SHA-256 和每个文件的 MD5。下载前重查清单，变化则重新选择。获取后的 XML、元数据和媒体另存 SHA-256；缓存恢复与正式包读取逐一核验。相同 PMC 版本内的清单更新也会形成独立原文包，保留当时许可和来源记录。

JATS 只查询 PMC，当前不支持预印本、付费全文或 Unpaywall XML 回退。这里不使用 Unpaywall 联系邮箱，也不向模型、MinerU 上传全文。原始媒体只获取文章实际引用且可定位到同版本清单的项目，不下载未请求的补充表格或压缩包。

## 转换与阅读契约

主要实现位于 `src/jats/`，正式包验证位于 `src/sources/jats-package.ts`，阅读适配位于 `src/reader/`。既有 AcquisitionService 继续负责获取任务；JatsIntakeService 只负责确认、正式保存和登记。没有新建另一套全文任务管理器。

解析器只读取单篇 `article`，主文章身份来自 `front/article-meta`，不会拿参考文献中的 DOI 补充主文章身份。UTF-8 XML 解析受字节、深度、节点与属性预算限制；外部 DTD 仅允许作为不解析的声明，内部 DTD、实体定义与未定义实体均拒绝。

确定性转换器 `rar-jats-1` 生成标题、作者、许可、摘要、章节、段落、列表、图形摘要、图注、表格、公式和参考文献。源块保留 XML 路径、原节点 ID、XML 与 Markdown 的 UTF-16 字符范围；块 ID 由原 XML 哈希与节点路径确定。投影 ID 同时绑定转换器、资源映射、正文与缺口。

简单表格生成 Markdown；复杂表格在阅读器中用固定 DOM 标签保留跨行跨列，纯 Markdown 同时保留按行降级结果。表注、上下标按文本保留。允许的 TeX 指令可渲染；未支持指令、MathML 布局和表格内公式等降级明确记入缺口，原 XML 保持原样。附属文章、补充材料不展开，并明确报告。

PNG / JPEG / WebP 按格式头及像素上限检查，阅读时从已核验字节创建 Blob；图片未能在浏览器解码时显示错误。头部校验不是视觉阅读或完整像素解码证明。TIFF / SVG 或像素超限的媒体保留原始文件，当前不转换或嵌入。未请求或缺失的图片保留占位说明。

ReaderDocument 描述正文、资源、缺口和显示能力。旧 MinerU 与普通 Markdown 适配到该契约；JATS 提供章节与图表导航，PDF / 页码 / 布局框能力均为否。`_source` 包优先严格分派；损坏、未提交或未知类型不会降级为普通 Markdown。显示层的图片身份与图注取自 JATS 源块，不从图片文件名猜测原文图号。

## 正式包与恢复

```text
papers/<citekey>--jats--<digest>/
  article.md
  images/<sha256>.<ext>
  _source/
    article.xml
    metadata.json
    acquisition.json
    source-map.json
    validation.json
    transaction.json
    original-assets/m<ordinal>.<ext>
    manifest.json
```

获取缓存位于插件目录的 `jats/<attemptId>/`，获取任务与 schema 3 快照沿用 `fulltext/production/`。私有保存计划位于 `jats-intake/<requestId>/plan.json`。正式包不用 `_extraction` 冒充 MinerU 产物，也不附带无同版本证明的 PDF。

确认模式是 `human-structured`，绑定请求、快照、XML SHA-256、来源身份、实际展示的主文章元数据及部分结果接受状态。原始元数据预览最多 20000 字符，截断时注明；回执不声称已逐字看过整篇 XML、检查全部图片或完成 X-Ray。旧 PDF v1 / v2 视觉确认契约不因此放宽。

保存前重新核验快照和共享目录。所有文件独占创建，先写所有权事务，逐个验证内容，最后写提交清单。读取时除哈希校验外，还从原始 XML 和媒体重新构建正文、能力与缺口；采用规范 JSON 编码，避免字段顺序变化造成假冲突。

中断后只接受本设备、本事务、哈希未变的完整文件。未知目录、额外文件、截断内容或用户修改会停止恢复，不覆盖或删除。尚未写出所有权事务的空目录不会自动接管。已完成的获取文件保留；尚在内存中的部分下载不保证保留。当前没有自动清理。

提交与 `papers/index.md` 登记分开。索引采用内容比较更新，保留已有文字；用户编辑了本条记录时停止自动补登记。SourceCatalog 统一发现 PDF、JATS、旧 MinerU 与 Wiki，按精确标识关联同一 citekey，同时分别保留稿件类型、来源版本和内容投影。

主要上限：XML 8 MiB、单媒体 16 MiB、每次 JATS 获取 64 MiB、引用媒体 64 项、原清单媒体 256 项；节点 100000、深度 96、单节点属性 64、正文块 20000；正文投影 8 MiB；图像长边 16000 像素且面积不超过 4000 万像素；正式包 128 MiB、文件数 135；私有计划 / 清单 256 KiB、原文索引 64 KiB。沿用来源 HTTPS、公网地址、超时及总尝试预算。关闭保存窗口或完成保存会释放持有的原文字节和投影正文。

## 验收与边界

- 四组 `pnpm test:jats`：解析、获取状态机、保存恢复、实际文件系统；覆盖主文章身份、恶意 XML / 公式、图形摘要、上下标、表格、无图请求、部分接受、MD5 不一致、设备归属、取消后迟到结果、断点恢复、用户修改、清单变化和严格阅读分派。文件系统测试使用保留的独立临时目录，无清理操作。
- 公开样本 `PMC10009416.1`：实际通过来源传输层下载 111310 字节 XML、46032 字节 JPEG 和 1056 字节元数据，并核对清单 MD5。原始获取在库外保留的开发目录；后续转换和界面测试复用这些字节，不再下载。
- `tests/obsidian-jats.cjs` 在真实 Obsidian 通过 28 项检查：无模型入口、360 / 680 宽度、XML 身份显示、部分接受、重复点击、登记失败、重启补登记、章节和引用导航、复杂表格、同版本图片实际解码及解码错误提示。最终投影含 150 个块、3 个结构表格、1 张图形摘要图片；样本补充材料未展开，按部分结果处理。
- 原生测试的正式包、人工确认、获取关联与原文索引全部在内存；浏览器使用真实公开图片字节，生产阅读器执行实际渲染。没有真实模型或 MinerU 调用。截图用于检查排版和资源显示，不构成科学图像解读。
- 现有全文获取六组、PDF 来源三组、入库五组、阅读 22 组、工作台两组回归，以及旧 MinerU 阅读 / PDF 限额专项通过。旧 MinerU 阅读测试的可选私有样本缺失，脚本明确跳过。类型检查、生产构建和发布审计 28 项通过。
- 最终构建重载后，JATS 原生 28 项再次通过；PDF 来源保存 21 项、获取后入库 27 项、旧入库续办 28 项回归通过，模型后端使用模拟实现。PMC PDF 恢复 / 预览 13 项及 JOSS OA 复用通过，均未重新下载。原生读取既有 MinerU 包确认保留 14 个视觉资源、PDF、页映射与布局框；普通 Markdown 仍按原类型读取。
- 未运行含禁止清理行为的旧全量测试入口，不宣称全量测试通过。最终 Obsidian 未捕获错误；测试窗口已关闭，临时展开 / 折叠状态与焦点模拟已恢复。

三个构建文件已备份并部署到测试库，部署哈希与最终构建一致。155 个非构建插件文件（含设置、历史和原有获取记录）保持不变；测试库其余 724 个文件内容与文件集合均未变化。联系邮箱未进入代码仓库或获取日志。

本次更新代码、测试、README、CHANGELOG、SECURITY 和阶段设计记录。没有修改原始架构提案，没有生成正式科学笔记；Vault 的科学索引、CSV、BibTeX 和研究日志不在本次开发范围。证据为代码执行、公开文件完整性与普通阅读显示，深度为 `metadata-only` / `conversion-only`，不是 `x-ray`。

JATS 的交互深读、模型证据引用和 Wiki 输出留给 M6；Zotero、RIS、BibTeX、本地 JATS 导入及批量处理仍未接入。实际范围以本文为准，不把设计基线中的后续能力当作已完成。
