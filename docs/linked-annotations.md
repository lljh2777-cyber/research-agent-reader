# 含链接段落的批注与摘录

2026-10-17，版本 `0.88.5`。

后续 `0.88.6` 补[含链接选区的真实 AI 与完整宿主重启](linked-annotation-ai-validation.md)，修复可见图号与链接源码的引句误拦；37 份记录重启读回一致。OpenCode Step 上游不可用，以及 mimo 的重复标签／上下文扩展分别留档。下文为 `0.88.5` 首轮交付边界。

在 Markdown 阅读视图或双栏中划选同一段落，段内含普通链接、内部链接、引用式链接、脚注或方括号引用时，可以选择手动批注、AI 解释或保存摘录。选中链接文字的一部分时，选区扩展为完整链接文字，弹窗会提示；格式文字也保持完整。编辑器沿用单行源码划选，多行软换行段落请使用阅读视图。

涉及链接或格式的批注独立保存在 `wiki/annotations/`，不把已有链接嵌套到另一个批注链接里，不改写原文。普通 Wiki 的纯文字批注保留原来的行内入口。重新划选相同范围可查看独立批注，摘录也可从摘录列表打开。

## 位置与来源

插件将整段实际渲染文字与所在原文块对应，再把选区映射到原始 Markdown 的准确字符范围。脚注按原文标识保存，不把宿主自动生成的显示编号当作原文文字；脚注正文不包含自动生成的返回箭头。重复整段无法在来源块内唯一定位、或渲染结果无法与源码对应时，停止并提示在原文编辑器重选。

隐藏记录保留完整的原始源码、位置与既有来源凭据，界面将常见链接显示为文字；未能独立解释的引用式语法按文字保留。摘录上下文仍有 3200 字符预算。单次最多 600 个显示字符，链接等源码总长最多 2400 字符；超长地址会提示缩小选区。

双语返回依据保存的来源路径、语言、块与字符位置，在相应栏中重建选区；交换位置不改变来源。保留 `0.88.4` 的栏内滚动规则。中文 AI 解释仍须有实际英文对应凭据，个人批注、译文与模型解释继续区分。CLI 模型参数、引句核对与短释义规则不变；不加载或访问选区里的链接。
