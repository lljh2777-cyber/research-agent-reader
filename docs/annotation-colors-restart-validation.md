# 0.91.0 颜色批注完整宿主重启补验

2026-11-12，Windows / Obsidian 1.15.0。使用公开 Release 的 `0.91.0` 安装文件，未修改产品代码、版本或模型设置。

## 重启与保护范围

重启前同时存在测试库与翻译库两个窗口，均无运行任务、未保存 Markdown 或非空编辑输入。保存两边布局、设置文件校验值，以及测试库批注、来源和三个插件安装文件的快照后，调用宿主正常退出。确认 Obsidian 进程数降为零，再重新启动并打开原来的两个知识库。

主进程由 `6328` 变为 `25644`，测试库渲染进程由 `25284` 变为 `22892`。此为完整宿主退出重启，不是插件重载。没有强制终止进程。

## 样本与结果

原有 61 个批注文档中读取到 109 条本插件格式记录。沿用上一轮的七条颜色功能测试记录，保留改色和取消颜色后的原状；为了覆盖当前缺少的黄色与红色，在已有非论文测试段落上新增两条人工批注，不改写来源文件。最终核对 111 条插件记录，旧格式文件也纳入文档字节校验。

九条目标记录包括八条双语批注和一条普通 Markdown 批注，覆盖五种颜色、无颜色、仅标色、附加文字、链接与上下标。
