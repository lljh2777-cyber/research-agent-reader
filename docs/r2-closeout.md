# R2 工程收尾与转换包来源关联

2026-09-12，开发版本 `0.68.0`。R2 的统一添加、原文保存、后续处理与恢复工程链路已收尾。最后补齐新 MinerU 转换正文的文献关联：无需给忠实转换正文添加属性，即可和对应 PDF、书目信息、Wiki 一起展示。

科学与教学质量仍分别沿用 R0、T1 的独立审阅门槛。工程收尾不提高初始笔记的 `abstract-level` 深度，也不解除主题学习预览限制。

## 本次关联规则

库读取器从已保存 PDF 包建立 SHA-256 与文件大小索引。只为 `schema_version: 1`、`extractor: mineru-open-api` 且带输入哈希和大小的提取清单尝试新关联；缺少凭据的旧包继续使用原有属性读取方式，不按标题、目录前缀或文件名猜测归属，也不读取清单声明的外部输入路径。

建立关联前检查实际 `article.md` 与清单输出的哈希和大小。若声明附带 PDF，其输出凭据也须与输入一致。所有匹配的已保存 PDF 必须通过现有完整包验证，且属于相同论文、citekey 与相容标识；转换正文已有属性不能与其冲突。正文被修改、附带 PDF 凭据不一致或正文输出重复时拒绝继承；匹配失败、归属歧义或 PDF 损坏会显示关联缺口。

相同内容可以同时来自本地与在线包。文献详情保留全部匹配 PDF 路径，不挑选其中一个来代表转换包的来源版本，不改变各 PDF 的版本或用户声明。继承的论文身份仅用于当前只读投影，不修改正文、清单、索引或持久记录。

**关联与内容核验分开。** 清单是项目转换流程留下的输入凭据，并非独立签名的来源证明。关联时的正文校验不能代替 JSON、图片、链接与其他包资源的完整核验；用户点击“核验此原文”后，原有完整验证器通过，才开放原文和阅读入口。历史会话继续使用原有正文加清单指纹，不改变指纹算法。打开前重新扫描；即使正文未变，PDF 关联或论文身份变化也会阻止旧卡片继续导航。

## 本次验收

| 场景 | 实测结果 |
|---|---|
| 升级前后对照 | `0.67.1` 的 DESeq2 详情有书目、两份 PDF、Wiki 共四项；`0.68.0` 加入已存在的转换正文，共五项，两个 PDF 保持独立 |
| 普通扫描 | 转换正文归到同一论文，显示两份匹配 PDF；仍处于未完整核验状态，没有自动开放阅读 |
| 单独核验 | 点击实际按钮，使用测试库真实 21 页 MinerU 包完成正文、JSON 和资源验证，然后显示“打开原文”和“开始／继续阅读” |
| 原文与阅读入口 | 点击打开进入准确的转换路径，标题和正文实际显示；当前视图三个图片元素均成功解码。阅读设置绑定同一路径，关闭后没有启动模型 |
| 重载 | 插件重载后仍是五项、同一论文和两份匹配 PDF；普通扫描仍要求显式完整核验，再次核验通过 |
| 窄面板 | 430 px 样式宽度下实际内容区 418 px、卡片 393 px，各自滚动宽度相等，按钮和来源说明可见 |
| 失败与兼容反例 | 六组专项覆盖损坏 PDF、改写正文、缺失或错误凭据、重复输出、跨论文相同内容、单独 DOI 冲突、citekey 冲突、旧包兼容、过期导航、取消和预算限制 |

专项使用内存包与真实 PDF 包验证器，完整转换核验回调在专项中模拟；原生验收使用现有测试库真实转换包及实际完整验证器。没有重新上传 MinerU、查询书目、调用模型或生成科学结论。Playwright 在项目中不可用，使用 Obsidian `1.13.7` 原生 CLI 验收；没有安装依赖。QA 初次读取设置弹窗时误用正文文本检查输入框值，修正为实际输入值后通过，不将脚本断言失败算作产品失败。

恢复布局时，直接把完整布局 JSON 作为 CLI 参数传入，触发 Obsidian 主进程 IPC 的 JSON 解析错误弹窗，后续 CLI 请求超时。关闭已确认的错误窗口，改为短命令调用外部脚本读取同一布局文件后恢复成功。原有 13 个标签页 ID 与类型核对通过，最终控制台没有捕获错误，调试已关闭；这次宿主工具异常保留在验收记录中。

`pnpm test:r2` 的 17 组、`pnpm test:r1` 的 13 组均通过；类型检查、生产构建、`pnpm release:check` 的 28 项检查及 `git diff --check` 通过。专项纳入 R2 回归入口。测试夹具保留，不执行批量清理。

测试库 `E:\paper-test` 的 982 个受保护文件中 981 个哈希不变，无新增资料。唯一变化是插件 `data.json`：既有启动检测更新本机 Codex 可执行路径，既有规范化为一条历史任务补齐空的 `modelSource` / `reasoningSource`；其余设置、任务内容、16 条任务 ID 与原文文件保持不变。本轮没有新任务，阅读设置仅打开后关闭。部署的三个插件文件与仓库构建一致。脚本、截图与详细快照保留在 `E:\research-reader\mineru-origin-r2-20260912`，不进入 Git。

## 保留边界

- 本轮只验证软件关联、文件保真与界面，不逐图分析论文或提升科学处理深度。R0 科学审阅、T1 教学审阅继续待完成。
- R2 真实远程服务链覆盖 PDF → MinerU → 初始 Wiki；JATS 使用已有原生证据与回归，本次没有重复付费生成。
- 跨平台实际启动、同步盘长期运行和外部 CSV／BibTeX 真实登记仍未覆盖。当前工程收尾基于 Windows 测试库和已有各批证据，不等同所有运行环境验收。
- 正式知识库、Zotero 和已转换内容不修改；本次无需论文索引或 Wiki 日志更新，开发记录保存在项目文档中。
