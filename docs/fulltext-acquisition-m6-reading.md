# M6 第一步：JATS 交互阅读

实现版本：`0.49.0`，2026-09-10。此步骤完成 JATS 的交互阅读与学习记录导出。正式文章 Wiki、阅读助手及知识整理仍待 M6 后续步骤；本文件不将整个 M6 标记为完成。

## 使用入口

1. 在「获取全文」选择 JATS，核对并保存正式原文包。
2. 打开图文阅读器，点击「交互深读」；也可在新建阅读时选择「已保存 JATS article.md」。该文件必须属于当前 Vault 中已经提交的 JATS 包。
3. 选择后端，点击「打开并继续阅读」。也可「仅打开来源，不调用模型」。相同来源和指纹默认复用已有阅读会话。
4. 沿主线继续讲解、从任意已完成回答建立支线；点击数字引用可查看正文片段、图像与原文块。学习记录可导出为独立 QA 笔记。

## 来源和证据

- `ReadingSource.kind = structured`，格式固定为 JATS，仍属于 `domain: paper`。旧 `pdf/article/code` 解码和存储目录不变。
- 会话保存完整来源清单，包含 packageKey、sourceVersionId、projectionId、转换器版本及每个文件的 SHA-256。来源指纹覆盖整个固定清单。
- 打开和继续生成时，重新校验包内 XML、正文、图像、映射与确认凭据。缺少正式包或验证失败时不会转入 MinerU / PDF 路线。
- 正文证据最多 4500 个 UTF-16 字符，保存实际投影范围、正文块 ID 和 XML 节点范围。长块按范围分段；图像引用另外绑定包内资源路径，资源摘要保存在清单中。
- 图注正文和交叉引用关联对应的图像资源，不使用虚构页码。图像在本地实际解码，最长边缩放到 1600 像素后按现有后端接口提供；解码失败、取消、来源变化或必要视觉能力缺失会停止生成。
- 正文目录保留投影缺口；复杂表格的模型片段使用已验证投影中的按行表示，不能据此推测缺失布局。图文阅读器仍提供保留跨行跨列的表格。
- 主线、支线、回答引用及学习标记沿用现有状态机。没有自动生成文章结论、升级 `x-ray` 或调用 MinerU。

实现入口：`src/reading/structured-source.ts`、`structured-document.ts`；会话、引擎、导出、来源选择和证据窗口调用这些接口。

## 恢复和导出

会话恢复根据保存的清单校验来源。源文件缺失或变化时，历史回答仍可查看与导出，新增回答和来源核对停止。不能以新版本重新绑定旧证据。

学习记录导出只使用会话快照：保留固定清单、投影 ID、XML 节点、字符范围、资源 ID 和生成当时的证据片段，不读取当前文件替换历史。来源路径和资源位置保持普通代码路径，不生成 `papers/` 与 `wiki/` 的跨根链接。

## 验证

- 新增 `tests/test_jats_reading.js`：全部使用内存包和模拟模型，覆盖显式来源类型、正文与图像绑定、主线/支线、视觉门禁、重试、序列化恢复、来源篡改拦截和离线历史导出。
- `pnpm test:jats`：5 组；`test:reading`：22 组；`test:code-reading`：3 组。
- `test:fulltext`：6 组；`test:sources`：3 组；`test:ingest`：5 组；`test:dashboard`：2 组。
- `pnpm typecheck`、`pnpm build`、`pnpm release:check`（28 项）通过。
- 原生脚本 `tests/obsidian-jats-reading.cjs` 使用此前缓存的 PMC XML 与同版本图片：150 个投影块、151 条阅读证据，验证来源选择、真实图像解码、引用对话框、固定对照窗、原文块导航、普通阅读器入口、恢复和历史导出。18 项检查通过；模拟回答不包含科学结论，真实模型、MinerU 和网络调用均为 0。
- 原生脚本需先在普通 Node 进程将 `tests/jats-reading-api.ts` 打包为 CJS，保留 `obsidian` 为 external、`.md` 使用 text loader。外部测试辅助模块禁止调用 Obsidian 模块；实际界面由已安装插件提供。不能在 Obsidian renderer 中运行 esbuild。
- 测试部署仅替换 `main.js`、`manifest.json`、`styles.css`，旧文件先备份。核对 155 个其他插件文件及 724 个文献库文件，内容均未变化；测试会话、原文包和导出保存在内存。测试视图关闭后恢复原有活动文档，Obsidian 窗口保持可见。

没有运行包含递归清理的全局 `pnpm test` / `verify` 入口，也没有真实模型质量或付费接口验收。没有向用户文献库写入论文、索引或科研结论。

## 下一步：正式 Wiki

后续接入受限的 JATS 正文读取工具和草稿流程：绑定既有原文凭据与规范论文身份，要求实际读取证据后生成 `title/title_zh` 和正文，沿用 create-only 写入与登记，并检验重复、失败续办和用户改动保留。该步骤完成前，JATS 会话不开放阅读助手和正式知识整理入口。
