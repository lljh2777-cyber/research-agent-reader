# 双语阅读：悬停段落对照

自 `0.90.2` 起，双语阅读顶部使用「悬停段落对照」。默认关闭；曾主动开启句子悬停的标签会沿用开启状态。开启后，在任一栏悬停到可对应的正文段落，两栏用浅色底纹标出整段。功能独立于滚动联动开关；另一段在视口外时仍不跳转。开始划选、移出、滚动、换栏、关闭或来源失效时清除高亮。

使用「双栏联动」已建立的段落对应，两侧均须有唯一可定位的正文段落。图注、扩展图表区、标题、脚注正文、表格、列表及独立公式不纳入。没有有效段落配对时，进度联动仍可用，段落悬停不开启。此处的对应只核对结构，不能保证译文语义；同样也不能保证任意两份文件都能逐段对齐。

当前不运行[此前的句子匹配](bilingual-sentence-hover.md)。不调用模型、不改 Markdown 或 `translation.json`；原生选区和批注来源保持独立。

## 测试库验收

Windows / Obsidian 1.14.4；按两侧均属于可对照范围的原文结构段落统计，分母不会因为渲染未定位而减少。

| 原有样本 | 已配对结构块（含标题等） | 可高亮正文段落 |
| --- | ---: | ---: |
| DeepMet 全文 | 417／417 | 216／216 |
| Novae 摘段 | 4／4 | 3／3 |

逐一核对了两侧渲染目标的结构 ID、唯一性及双向索引。两份样本纳入范围内的正文段落覆盖率均为 100%；这是结构定位验收，未对整篇译文做语义审阅。首轮发现补充表目录在两侧的标题识别不同，统一排除后重新统计。原生悬停复验使用可见的测试标签，避免同一资料在后台打开的副本影响指针命中。

实际阅读界面验证默认关闭、双向整段高亮、30 px 换行、对侧不滚动、拖选与批注捕获、换栏与状态恢复、失效清除，以及只有进度联动时不亮。测试结束后恢复原字号和工作区，原有样本的英文、中文及配对文件校验值一致。未调用模型或进行独立译文审阅。
