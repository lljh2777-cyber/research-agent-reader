后续 mimo 准备停在选区捕获，期间观察到活动标签切换，尚未请求模型。取消这份准备，重载原发布文件后固定准备前的标签；最终调用从实际渲染选区调用生产 DOM 捕获分支，保留正常双语来源验证，没有手填或绕过凭据。mimo 此次直接保存准确后端和模型配置，未再打开设置窗口验证下拉选择；其他三次已核对实际设置控件。没有确认活动标签切换与捕获停顿的因果关系，也没有将其作为已修复的产品缺陷。

私有验收脚本中的二进制散列转换和工作区状态层级问题也已修正，没有模型请求。记录保留这些准备问题，不能把它们计为模型生成失败、成功或额外推理用量。此轮未改运行时代码，原生准备停顿仍需在后续实际使用中复查。
