# 颜色批注

更新：2026-11-12，版本 `0.91.0`。

在 Markdown 中选中文字，点击「批注 → 颜色标注」，选择黄色、绿色、蓝色、紫色或红色后点击「保留」。文字可留空，也可以附加自己的理解或疑问。「手动批注」和新 AI 解释的保留页也提供颜色选择。

重新划选相同范围打开批注，点击「修改」可以改色、补充文字，或选择「无颜色」取消高亮。取消颜色保留批注记录、文字、模型回执和来源信息；不会删除历史。旧批注没有颜色字段时继续按原样读取。

## 显示与保存

- 覆盖普通 Markdown 阅读视图、插件 Markdown 阅读器和中英文双栏；Markdown＋PDF 模式只标记 Markdown 一侧。PDF 原页高亮另做一阶段。
- 颜色显示在原来的选区上，链接和上下标保留。双语颜色属于实际选择的文件，交换左右不改变来源，不自动把颜色复制到对应译文。
- 颜色和文字一起保存在当前知识库的 `wiki/annotations/` Markdown 文件中。每条记录增加可选的 `color` 字段，并显示中文颜色名称。无需模型调用。
- 新建颜色标注使用独立来源锚点，不向原文插入高亮标签。已有行内批注可以加色，原有链接保持。
- 高亮使用显示层范围，不改写文字节点、不滚动、不改变原生选区。阅读视图关闭、重开及插件重载后从已保存记录恢复；编辑模式不显示该高亮层。
- 原文无法准确定位或渲染对应不唯一时不绘制颜色，历史记录仍保留。颜色只是个人阅读标记，不代表翻译核验、证据强度或科学结论。
