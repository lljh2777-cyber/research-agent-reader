# 入库与深读完善

## 阶段一：入口衔接

入库结果中有原文包时，可点击「开始／继续交互深读」。弹窗预填原文和已验证的入库模型，仍由读者开始生成；打开弹窗不调用模型。来源经过阅读器重新校验后，指纹一致时复用已有会话及其模型，变化时新建，原会话保留。失败任务已成功生成的原文也可使用这一入口。

首页 PDF 深读显示正式阅读的主线进度、待重试状态和论文标题；后台支线生成也会显示「生成中」。演示、测试和已归档会话不计入。点击进入对应会话，停止仍使用阅读界面的独立按钮。没有正式会话时显示「打开论文开始阅读」。

验证使用内存会话覆盖近期会话、后台支线、失败、归档与演示隔离；原有同源复用、并发打开和来源变化由阅读回归覆盖。完整旧测试入口含递归清理，不执行。

## 阶段二：入库 PDF 正文

轻量入库支持从身份确认时的同一 PDF 快照读取正文，独立的 pdf_read 工具不能改动路径。每次读取核对 SHA-256，20 秒超时并传播停止信号。overview 读取前 3 页文字，每页最多 8,000 字符；可以按页补读。无文字时拒绝生成并提示 OCR。成功笔记记录来源类型、路径及原 PDF 指纹；处理深度仍为 abstract-level。

内存回归覆盖真实读取回执、跨来源和标题不匹配、页码越界、扫描件、快照变化、取消，以及严格来源选择。未调用线上模型或修改真实论文。

## 阶段三：登记预览与续办

新版轻量入库在开始前将参数保存到插件目录 ingest-records/，不保存密钥。失败结果的「继续完成入库」可在重载后使用，重新核对身份，复用已验证的现有产物，只补缺失输出。旧版任务没有参数记录时明确提示不能恢复。身份核验仍重新运行，未承诺断点前的模型调用全部跳过。

结果中的「预览入库登记」不调用模型，显示每个文件修改前后的全文。当前库更新文献索引、原文包位置索引和日志；原文包位置使用非链接路径。工具包的 knowledge-base 确实指向当前库时，再更新既有列结构的 papers.csv 和 references.bib；缺失条目按已有元数据生成通用 BibTeX 条目，不猜测期刊或出版类型。既有条目发现身份冲突则停止，不覆盖。独立库的 registry_status 为 indexed，完整书目登记为 registered，depth 保持原值。

确认后先保存前后快照，再串行写入；中断保留 recovery 记录，重新打开相同结果可恢复，只跳过全文完全相同的已写入文件。手工编辑导致内容不符时停止。已完成记录再次打开只展示保存的修订；配置另一个书目范围会使用另一份记录。

验证：纯内存覆盖 CSV 引号、登记范围、来源链接边界、重复登记、原有正文保留、书目冲突、部分写入恢复和篡改拒绝。测试没有写入真实 Wiki 或书目文件。

## 阶段四：核对版本与原文覆盖

回答工具栏和划选菜单增加「核对／重新解释」。填写问题后重新选择并读取本文证据，生成单独的核对支线，保持原回答、选区和历史关系。打开「比较核对版本」可对照前后全文；选择「用于后续背景」才影响新主线与新支线的背景。此前已经创建的支线继续使用自己的背景快照。采用核对版本不是科学事实验证；导出明确保留历史回答与核对版本编号，正式知识整理仍由读者选择节点发起。

更多阅读选项中的「证据覆盖」汇总实际生成调用提供的文字／图像 ID 和个人核对记录。旧记录没有完整输入清单时显示历史引用，不能把部分引用冒充全文覆盖。尚未提供的补充材料不计入分母。打开面板不调用模型。

「重新定位原文」在文件移动后重新验证来源；相同内容指纹才更新路径及对应证据位置，保留位置历史。来源内容不同、正在生成或磁盘保存失败时保留旧会话。只支持原类型，不能把 PDF 会话绑定成 article.md。

新增内存回归覆盖核对版本保存、采用与旧分支隔离、覆盖状态、来源变化拒绝、重新定位及存储失败。已有阅读、助手和整理回归通过。本轮未声称事实质量已经全部通过；此前记录的科学错误仍用于对照，原历史回答不自动改写。

## 阶段五：显式联网支线

Direct API 阅读模型的追问输入区增加「联网补充」，按草稿目标独立保存，发送后自动关闭，仅作用于该问题。主线推进不联网。Codex CLI 的交互阅读本阶段仍保持原来的只读离线适配器；需要联网时选择 Direct API 阅读模型。

联网沿用已配置的供应商模式。原生搜索随本轮讲解请求发出，不增加关键词规划模型调用；Tavily 在本文证据读取后执行一次浅层搜索，最多 3 条网页摘录，然后交给原讲解请求。供应商不可用、检索失败、引用编号错误等会保留失败节点，用户可重试，不自动改用其他后端。

网络资料单独保存在节点 web 字段、正文下方的网络补充区和学习导出中。Tavily 展示实际查询、链接与摘录；原生联网链接明确标为供应商回答提供，未独立核验，缺失来源时保留提示。网页不混入本文证据目录或主线记忆。联网支线可导出学习笔记；要整理进正式知识，先从不联网的核对节点重新读取本文依据。

内存回归覆盖本文先于搜索、单查询和三来源限制、来源编号、伪造链接、无结果、取消、保存恢复、主线隔离、原生请求参数和正式知识整理边界。Tavily 未配置真实 Key 时不运行线上调用，模拟通过不代表联网服务实测通过。

## Obsidian 验收与边界修复（0.40.2）

实际界面验证了来源预填、核对入口、证据覆盖、重新定位、联网开关草稿持久化和双模式切换。打开这些面板未调用模型。首页显示正式会话进度，隔离保存的测试会话不覆盖首页的论文状态。

使用已配置的 qwen3.7-flash 完成一次原生联网支线验收。首次结果因正文引用与证据清单不一致被拒绝；重试复用证据选择缓存后完成，保留同一节点与主线。供应商仅返回本文已经包含的官网地址，因此插件显示「联网核验未完成」，不能将该测试称为独立网络证据核验成功。重试现在会带上对应的引用格式反馈，不自动追加修复调用。网络查询使用论文原始标题，不受会话重命名影响。

复用已有正式笔记的旧入库结果显示「既有笔记，无需轻量登记」。登记检查统一 DOI URL、doi: 前缀和大小写，拒绝 BibTeX 中同 DOI 不同键及同键重复。实际 Wiki、CSV 和 BibTeX 未在验收中改写，登记写入与故障恢复由内存测试覆盖。原始 PDF 初始笔记路径、Codex CLI 和 Tavily 本阶段未追加线上模型验收。
