# 入库与深读完善

## 阶段一：入口衔接

入库结果中有原文包时，可点击「开始／继续交互深读」。弹窗预填原文和已验证的入库模型，仍由读者开始生成；打开弹窗不调用模型。来源经过阅读器重新校验后，指纹一致时复用已有会话及其模型，变化时新建，原会话保留。失败任务已成功生成的原文也可使用这一入口。

首页 PDF 深读显示正式阅读的主线进度、待重试状态和论文标题；后台支线生成也会显示「生成中」。演示、测试和已归档会话不计入。点击进入对应会话，停止仍使用阅读界面的独立按钮。没有正式会话时显示「打开论文开始阅读」。

验证使用内存会话覆盖近期会话、后台支线、失败、归档与演示隔离；原有同源复用、并发打开和来源变化由阅读回归覆盖。完整旧测试入口含递归清理，不执行。

## 阶段二：入库 PDF 正文

轻量入库支持从身份确认时的同一 PDF 快照读取正文，独立的 pdf_read 工具不能改动路径。每次读取核对 SHA-256，20 秒超时并传播停止信号。overview 读取前 3 页文字，每页最多 8,000 字符；可以按页补读。无文字时拒绝生成并提示 OCR。成功笔记记录来源类型、路径及原 PDF 指纹；处理深度仍为 abstract-level。

内存回归覆盖真实读取回执、跨来源和标题不匹配、页码越界、扫描件、快照变化、取消，以及严格来源选择。未调用线上模型或修改真实论文。

## 阶段三：登记预览与续办

新版轻量入库在开始前将参数保存到插件目录 ingest-records/，不保存密钥。失败结果的「继续完成入库」可在重载后使用，重新核对身份，复用已验证的现有产物，只补缺失输出。旧版任务没有参数记录时明确提示不能恢复。身份核验仍重新运行，未承诺断点前的模型调用全部跳过。

结果中的「预览入库登记」不调用模型，显示每个文件修改前后的全文。当前库更新文献索引、原文包位置索引和日志；原文包位置使用非链接路径。工具包的 knowledge-base 确实指向当前库时，再更新既有列结构的 papers.csv 和 references.bib；缺失条目按已有元数据生成通用 BibTeX 条目，不猜测期刊或出版类型。既有条目发现身份冲突则停止，不覆盖。独立库的 registry_status 为 indexed，完整书目登记为 registered，depth 保持原值。

确认后先保存前后快照，再串行写入；中断保留 recovery 记录，重新打开相同结果可恢复，只跳过全文完全相同的已写入文件。手工编辑导致内容不符时停止。已完成记录再次打开只展示保存的修订；配置另一个书目范围会使用另一份记录。

验证：纯内存覆盖 CSV 引号、登记范围、来源链接边界、重复登记、原有正文保留、书目冲突、部分写入恢复和篡改拒绝。测试没有写入真实 Wiki 或书目文件。

后续阶段：深读纠错与证据覆盖；显式联网支线。每阶段独立检查、提交推送并交付测试库。
