# deepseek-flash 主题教学试用

2026-09-11，插件保持 `0.56.1`。本轮使用测试库已有且通过连接测试的 `deepseek-flash` 配置，与此前 `qwen3.7-flash` 在相同教学规则下的首次回答比较。

**开发者判断：在已完成的机器学习与神经网络九题中，deepseek-flash 的核心概念解释整体更好，值得优先作为下一轮学习预览的候选模型。** 改善主要来自概念关系、步骤职责和条件说明；仍有能力承诺过度与代码条件遗漏，不能认定教学验收通过。统计与 Python 迁移题组首题未收到响应，本轮没有这两类主题的有效新答案。

## 实际测试范围

| 题组 | 计划 | 实际结果 | 可以判断的内容 |
|---|---:|---|---|
| 机器学习、神经网络 | 9 题 | 9 次请求均获得首次回答，格式有效，结束原因为 `stop` | 可与 qwen 同题原答逐项比较 |
| 统计、Python 迭代器 | 8 题 | S01 已记录请求并调用传输，但没有收到响应；其余 7 题未开始 | 无法判断本模型的迁移题回答质量 |

共记录 **10 次请求尝试、9 份回答、1 次未收到响应、7 题未开始**。没有重试、补答或挑选较好的版本。失败由运行器保存并停止后续题目；记录不足以判断失败发生在本机代理还是上游，也不能确认服务端是否生成过答案、是否计费。它不作为概念错误计分，但必须保留为本次使用未完成的事实。

两套计划均在调用模型前冻结。目标、基础、路线、题目、祖先选择规则、判断要点与 qwen 对应题组完全相同，教学规则均为 `topic-teaching-v2`。配置比较只发现模型名和配置 ID 不同：同一已有 OpenAI-compatible 本机代理、相同结构化输出设置、输出上限 5,000、超时 120 秒、非流式、零自动重试、未联网。没有给模型发送参考要点、网页、知识库或运行环境信息。

这是两次模型配置运行的比较：未固定随机种子，后续题各自继承该模型真实生成的祖先回答，因此不是所有提示词字节相同的严格重放。模型身份来自配置及成功响应中的名称，上游身份未独立核实。题组规模小，且已在既往开发中使用，不是随机抽样、盲评或未见题评测；结论限于本批回答。

## 九题逐项观察

下表为开发者阅读原答后的判断。冻结参考要点未更改，额外发现的问题单独说明，不据此追改通过率。qwen 的完整旧观察见 [T1.3C](topic-teaching-t13c.md)。

| 题目 | deepseek 本次表现及与 qwen 的差异 | 残留问题或判断边界 |
|---|---|---|
| M01 输入、目标、预测 | 房价例子短且明确标为虚构，三种量区分清楚；没有沿用 qwen 将输入与目标之差当作训练误差的混淆 | 未直接说明监督学习范围；“缺少目标，模型不知道该学什么”仍容易被读成所有机器学习都必须有标签，末尾只提分类不足以消除歧义 |
| M02 训练误差与泛化 | 正确否定必然关系，将过拟合视为可能原因，同时提出分布变化；两个误差都低也不保证未来所有数据 | 房价误差使用万元但未先定义具体度量；后续 M06 才明确采用平均绝对误差 |
| M03 全量归一化 | 正确区分训练集拟合与对测试集应用变换；相较 qwen，删去必然造成高分的机械解释，说明影响大小取决于条件 | 仍是常见留出评估的入门说明，不覆盖全部特殊学习设定 |
| M04 空库引用 | 没有编造论文或页码；比 qwen 更明确要求可访问正文和版本信息 | 仍暗示提供论文后就能在本学习模式中读取和定位；当前主题接口尚无资料读取链路 |
| M05 今日第一 | 没有编造具体排名，说明榜单、任务、日期和指标缺口；不再断言外部平台当前运营情况 | “允许我联网查证，我可以去核对”仍是当前接口不具备的能力承诺 |
| M06 独立评估 | 沿用房价和同一误差单位，明确训练、验证、测试的职责，比 qwen 漏掉模型选择环节的回答完整 | 该题较清楚；不据此证明模型在所有评估设计问题上可靠 |
| N01 预测与损失 | 数值例子可核算，区分预测、目标和损失，也区分损失与准确率；没有 qwen 用损失单个数值直接决定更新强度的说法 | 对有一些 Python 基础但缺少神经网络基础的用户，矩阵运算、交叉熵等内容仍较密；把无监督与自监督一并说成没有直接目标不够精确 |
| N02 梯度与更新 | 梯度正负、上升方向与减去梯度一致；分开梯度计算和参数更新，数值例子前后连贯，明显好于 qwen 的上下坡混淆 | 开头将普通梯度下降公式写成优化器通用动作，后文才补充动量与缩放差异；零梯度等情况下预测和损失未必变化，“下一次会不同”说得过满 |
| N03 backward | 正确说明 `backward` 累积梯度、`step` 更新参数、`zero_grad` 清梯度；纠正了 qwen 把是否调用 step 当作是否累积的条件 | 自检连续两次 `L.backward()` 未说明重新前向或保留计算图；数值例子也应限定普通 SGD，并说明需要重新前向计算新预测与损失 |

M03 的训练集拟合与测试集变换依据 [scikit-learn 数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html)核对；M06 的模型选择与最终评估区别依据[交叉验证说明](https://scikit-learn.org/stable/modules/cross_validation.html)核对。这些网页用于开发者复核，没有送入被测模型。

N03 的三个职责可对照 [PyTorch 优化教程](https://docs.pytorch.org/tutorials/beginner/basics/optimization_tutorial.html)。其自检有实质性条件缺口：在所举含平方损失的计算图上，默认反向后再次对同一个 `L` 调用 `backward()`，会因所需中间结果已释放而失败；应说明重新前向构图，或在前一次反向时保留图。[PyTorch 自动微分教程](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)明确解释了同一计算图重复反向的条件。本轮只核对文档与解析计算，没有执行模型示例或将推演冒充实测。

M04／M05 的问题依据产品调用链判断：[`teaching.ts`](../src/topic-learning/teaching.ts) 只构造目标、路线、当前问题和祖先回答；[`study-service.ts`](../src/topic-learning/study-service.ts) 调用教学后端；[`plugin.ts`](../src/plugin.ts) 创建主题后端时关闭联网。当前模式无法因为一句“用户允许”就获得网页或论文读取能力。回答承认本轮未读取资料是进步，但未来步骤也需要符合真实功能。

## 教学体验与用量

机器学习部分比 qwen 更精练，房价例子与单位基本连续；神经网络部分使用同一个单参数例子，便于追踪损失、梯度和更新。N02 的自检只要求判断正负方向，更符合当前讲解范围。N03 的自检则引入未交代的计算图条件，仍可能让初学者把实际报错当作自己理解错误。

九题正文字符总数从 **6,117 增至 6,384**，约增加 4.4%；不能概括为模型普遍更简洁。神经网络三题分别从 685／1,035／555 字符增至 1,064／1,250／1,114 字符。长度只是教学负担的线索，不作正确性评分。

| 九题成功运行 | qwen3.7-flash | deepseek-flash |
|---|---:|---:|
| 接口报告输入 token | 11,756 | 12,063 |
| 接口报告输出 token | 24,080 | 20,686 |
| 接口报告合计 token | 35,836 | 32,749 |
| 接口报告缓存输入 token | 0 | 4,992 |

这批成功回答的接口报告合计约少 8.6%，不是费用下降或稳定节省的证明。代理用量未独立校准，缓存条件也不同；正文与推理细项不相加。S01 未返回用量，因此 **32,749 不是整轮试用的已知总消耗**，费用保持未知，也不据本轮判断速度优劣。

## 后续决定

优先把 deepseek-flash 作为机器学习／神经网络学习预览的下一轮候选，保留人工核对。先将剩余迁移题的有效首次运行和独立教学审阅补齐，再判断是否扩大推荐范围；新的运行必须单独保存并关联本次失败记录，不能覆盖后宣称本次十七题全部成功。

本轮不增加教学规则 v3，不切换默认模型，也不解除主题预览限制。已有 R1 人工阅读状态与主要笔记选择的开发顺序保持不变；资料读取、联网与精确定位仍需按真实能力开发，不能靠更换模型或文案承诺完成。
