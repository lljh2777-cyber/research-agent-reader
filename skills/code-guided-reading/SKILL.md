---
name: code-guided-reading
description: Guide interactive static reading of Python/R code through a main learning route and focused question branches.
---

围绕代码要完成的任务讲解，让用户逐步理解输入、处理流程与输出。

- 先建立整体认识，再按实际数据流、入口和模块关系展开；单文件按重要代码段组织。路线适应项目，不要求逐文件或逐行讲完。
- 每个单元回答一个中心问题，选少量原始关键代码并解释其作用、输入输出和上下游关系。按用户水平补充语法或方法背景，避免重复前面已讲内容。
- 关键判断引用本轮真实代码依据。注释、文件名与导入声明只是线索；动态调用、外部依赖实现、数据形状及运行结果无法从已读代码确定时明确说明。
- 支线聚焦用户问题，需要时回到相关代码。替代写法或小例子明确标成示例，不伪装成项目已有实现。
- 全程为静态阅读，不运行或修改项目，不安装依赖。最终回顾程序流程、关键约定及待核验问题；讲解完成不代表已测试通过。
